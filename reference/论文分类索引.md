## 01_RL信道均衡与检测

分类依据：这些论文直接讨论强化学习或深度强化学习用于信道均衡、符号检测、MIMO 检测、RIS 辅助均衡等任务。它们与“RL 做信道均衡/检测”这个研究点最直接相关。

- `Robust Data Detection for MIMO Systems with One-Bit ADCs - A Reinforcement Learning Approach.pdf`
  - 内容：one-bit ADC MIMO 数据检测；RL 用于 likelihood function learning，缓解信道估计误差导致的 likelihood mismatch。
- `Deep Reinforcement Learning Aided Monte Carlo Tree Search for MIMO Detection.pdf`
  - 内容：DRL policy/value network 辅助 MCTS 做 MIMO detection。
  - 同名 `.txt` 为论文文本摘录。
- `RIS-Enabled Wireless Channel Equalization - Adaptive RIS Equalizer and Deep Reinforcement Learning.pdf`
  - 内容：RIS 辅助无线信道均衡；比较 classical adaptive RIS equalizer 与 DDPG/TD3/SAC 等 DRL 控制方法。
  - 同名 `.txt` 为论文文本摘录。
- `Improved Channel Equalization using Deep Reinforcement Learning and Optimization.pdf`
  - 内容：WOA + Q-learning 风格的信道均衡优化，覆盖 AWGN/Rician/Rayleigh/Nakagami 等信道。

## 02_RL辅助信道估计与伪标签选择

分类依据：这些论文不是直接让 RL 输出均衡结果，而是让 RL 控制 data-aided / semi-data-aided channel estimation 中的样本选择或伪标签使用策略。对当前项目后续“RL 控制 pseudo-pilot 门控”最有参考价值。

- `Data-Aided Channel Estimator for MIMO Systems via Reinforcement Learning.pdf`
  - 内容：RL 选择检测后的数据符号作为额外 pilot，改进 MIMO LMMSE 信道估计。
- `Semi-Data-Aided Channel Estimation for MIMO Systems via Reinforcement Learning.pdf`
  - 内容：RL 在数据块前半部分选择可靠 detected symbols，降低 data-aided channel estimation 的延迟和错误传播风险。

## 03_在线持续学习与神经接收机

分类依据：这些论文重点是神经接收机的在线/持续学习、单步适配、pilot/DMRS 驱动更新。它们与当前项目 `Online Stage: Pilot Loss -> PEFT/RL Adaptation` 的工程框架高度相关。

- `Learning During Detection - Continual Learning for Neural OFDM Receivers via DMRS.pdf`
  - 内容：利用 OFDM DMRS 同时做解调和在线持续学习，实现零额外开销的 neural receiver adaptation。
  - 同名 `.txt` 为论文文本摘录。
- `Online Learning of Modular Bayesian Deep Receivers - Single-Step Adaptation with Streaming Data.pdf`
  - 内容：把 DNN receiver 在线学习建模为参数空间 Bayesian tracking，实现单步低延迟适配。
  - 同名 `.txt` 为论文文本摘录。

## 04_PPO自适应滤波与信号增强

分类依据：该类论文不是严格通信信道均衡，但使用 PPO 控制自适应滤波器，重点在 reward 设计、低延迟在线滤波和非平稳噪声适配。对当前项目的 PPO reward 设计有参考价值。

- `Composite Reward Design in PPO-Driven Adaptive Filtering.pdf`
  - 内容：PPO 驱动自适应滤波，reward 同时考虑 SNR improvement、MSE reduction、residual smoothness。
  - 同名 `.txt` 为论文文本摘录。
- `Composite Reward Design in PPO-Driven Adaptive Filtering (alternate source).pdf`
  - 内容：同题论文的另一个来源/版本。因文件哈希与主 PDF 不同，未删除，保留为 alternate source。

## 05_神经均衡与Pilot高效信道估计

分类依据：这些论文以深度学习/基础模型做信道均衡或 pilot-efficient channel estimation，不一定使用 RL，但对当前项目的 Neural Equalizer、pilot-conditioned architecture、低 pilot overhead 实验设计有直接参考价值。

- `P-FTNet - Pilot-Conditioned and Feature-Augmented Transformer Network for Equalization Under Extreme Delay Spread.pdf`
  - 内容：pilot-conditioned Transformer equalizer，用多维特征和 pilot 信息处理极端时延扩展下的长程 ISI。
- `Reducing Pilots in Channel Estimation with Predictive Foundation Models.pdf`
  - 内容：用 predictive foundation model 降低信道估计 pilot 开销，强调跨场景泛化和低开销 CSI 获取。

5. 当前分类以“文章具体内容”而不是来源或年份为准。
