# 神经状态参数到实际 CIR 的作用幅度审计

四臂在线区间未通过后，先审计参数半径的实际物理作用。0.05 的参数 L2 半径
不是坐标无关的状态距离；不能默认它在旧符号 head 与新状态 head 上作用相同。

- 固定新 channel_state B256；offline_train 77000–77002，四 SNR，各连续生成
  128 帧，仅检查预设年龄 0/7/31/63/127，共 60 当前上下文。
- 每次从同一 B Frozen 起点生成三档：small=(lr .005,1步,半径 .05)，
  medium=(.02,3步,.2)，large=(.05,3步,.5)，共 180 候选。不累计参数。
- 内循环仍只用 Adapt 前向残差，原 Reward BER/信号 loss guard 不变。
  所有候选和 guard 固定后才读取 Data 标签评分，不据 Data 排序或选择动作。
- 除实际 BER/BCE，记录 gate、相对 acquisition 的 CIR 改变、更新前后 CIR
  距离和 head 参数距离，区分幅度不足、门控饱和与方向失配。
- 这不是更大步长的新主配置。旧四臂结果保留，不修改其预算或结论；不把本诊断
  与旧留出混为独立确认，不因某一档表现较好就宣称正式安全动作成立。

只有看到作用幅度和合法反馈同时支持的方向，才固定下一轮匹配训练/留出协议。
若较大幅度只增加有害更新，则停止扩大该方向，不能以继续放宽半径替代机制证据。
