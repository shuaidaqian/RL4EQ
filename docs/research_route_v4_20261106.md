## 1. 核心目标

**离线学习神经块均衡器；在线用合法观测做贝叶斯物理状态（CIR）适配；相对同源 acquisition-CIR Frozen 网络，获得可归因、可重复的 Data BER 增益；并证明该增益随同一会话传输帧数增加而总体扩大，直到饱和。**

2026-11-06 用户确认的核心主张调整：原"在线神经参数微调必须优于 Frozen"降为**独立、尚未成立的子主张**；当前核心是"离线神经均衡器 + 合法在线贝叶斯物理状态适配"。信道、Pilot、SNR、数据角色与标签隔离不变。

三个不可混淆的对象：

1. **物理状态**：CIR、CFO、公共相位、soft-tail。由合法 Pilot 与已接收波形跟踪。Frozen 与 Online 使用同一协议。
2. **神经在线参数**：低维状态 `z_t`、Adapter/FiLM/LoRA/head 等。当前物理主张中神经权重冻结，在线只更新物理 CIR 状态；神经参数在线更新是独立、尚未成立的子主张。必须记录参数数、更新次数、计算量与延迟。
3. **离线共性**：残差表示、适配子空间、初始化、状态先验与更新规则。由离线元训练学习，不要求上线从零学习。

研究点成立的必要条件不是"参数动了"或"Pilot 损失下降"，而是：存在可修正失配、合法观测能辨认它、在线参数能作用于它、Pilot/Data 自监督方向能迁移到当前及后续 Data。

## 2. 用户已确认的在线自由度（2026-11-06）

以下四项全部允许，但必须逐项报告资源与归因，不能把"更多算力/更大参数"冒充"在线微调机制"：

|自由度|允许内容|必须报告的对照|
|---|---|---|
|Data 位置无标签自监督/判决反馈|用已接收波形、模型自身 soft 判决/置信度构造目标；不读 Data 发送符号或 Data 比特|与 Pilot-only 的同预算对照；错误传播与确认偏置诊断|
|更多在线算力/内循环步数|每帧多步优化、更大 batch、二阶/自然梯度；Frozen 不跑无用梯度|实际计算量、延迟、更新次数、每帧耗时|
|更大在线参数集|从当前低维/head 扩到 Adapter/LoRA/FiLM/全 head|参数量、Fisher/可辨识维数、与同预算小参数集对照|
|跨帧会话级记忆/重放|保存并重放本会话已接收帧；会话级批训练或贝叶斯后验|历史长度、遗忘、状态持久化/回滚、内存与延迟|

不变约束：信道配置、116 符号长回波、Pilot=256（Adapt=224、Reward=32）、0/5/10/15 dB、数据角色与 seed 隔离均不改。不得新增短/中记忆 profile，不得调整 PDP/漂移/同步分布或 Pilot/接收窗口来制造收益。

## 3. 成功判据（保持现契约）

用户 2026-11-06 明确保持现契约。核心成功必须同时满足：

1. **主效应**：四个主要 SNR 等权平均的绝对 BER 改善
   `mean_s(BER_frozen,s − BER_bayes,s)`
   在预注册的统计方法下**显著大于 0**。Frozen 为同源 checkpoint + acquisition CIR + 同一 dd_soft tail 规则；Bayes 为同一 checkpoint + 贝叶斯递归 CIR 后验。神经权重在两臂都冻结。
2. **安全护栏**：每个主要 SNR 的配对差 `BER_bayes,s − BER_frozen,s` 的点估计不得为正；具体置信界、多重比较与"实际等价"定义在正式确认前冻结。允许退化量为 0。
3. **持续增长**：按固定长度窗口计算 `gain_w = BER_frozen,w − BER_online,w`；用会话级斜率、末窗减早窗、末窗增益检验"总体扩大"。允许随机误码导致局部窗口回升，不以逐帧严格单调为门槛。
4. **归因**：同源、同物理状态跟踪、同观测/探测资源的 Frozen 对照；实际神经参数变化；A/B 四臂区分"普通监督续训"与"适配导向训练"；Data 标签只用于离线外层与事后评分。
5. **可持续性**：稳态 BER、漂移后恢复、失稳/有害更新、更新次数、计算与延迟；传统基线在同资源下的竞争力比较。
6. **范围**：结论限于"EME 启发的长回波仿真"；真实 EME 链路结论需另行标定频段/带宽/PDP/延迟—多普勒。

**神经参数微调子主张（独立、尚未成立）**：若要在同一确认中检验在线神经参数更新的额外增量，Frozen 与 Online 必须共享同一 Bayes CIR；只有 Online 相对共享 Bayes Frozen 仍有可重复正增量，才能写成神经微调成功。当前开发证据只支持物理 Bayes CIR 主张，不支持该子主张。

**"没有变差"或"未检出差异"不是成功。** 在线必须优于同源 Frozen；安全护栏只是必要条件。

## 4. 已验证的瓶颈（截至 2026-11-06）

### 4.1 soft-tail 训练/评估不一致（已修复，P0）

- 离线课程训练使用 `online_soft`：当前帧最后 `max_delay` 个 Data 位置的模型软判决递推下一帧 tail（[curriculum.py:563](../training/curriculum.py#L563)）。
- 评估函数 `next_pilot_tail` 只允许 Pilot 位置更新；`prefix` 布局帧尾 116 位全是 Data，因此是空操作；主在线路径 `online_adaptation.py` 的 `pilot_visible_mask[-tail_len:]` 同样为空。
- 后果：10/15 dB 的 Adapt Pilot BCE 从 `0.0067/0.0003` 被抬到 `0.0282/0.0357`；在线梯度长期拟合帧边界伪影。
- 修复：新增 `tail_update_mode="dd_soft"`，Frozen/Online 共用；只读接收波形与模型输出，不读 Data 标签。详[tail 对齐归档](results/tail_alignment_v1_20261106/README.md)。
- 边界：Data BER 对 tail 不敏感（除 0 dB 略好）；它不直接制造在线增益，不能替代数据辅助信号。

### 4.2 高 SNR Pilot 梯度消失

- 10/15 dB 的 Adapt/Data 梯度余弦仍约 `−0.05/−0.04`（dd_soft 后 `−0.07/−0.04`）。
- 模型在 Adapt Pilot 上已几乎无误，`p(1−p)` 与 BCE 梯度同时趋零；继续调学习率/门控/半径没有信号。
- 768 个 Data 符号是唯一额外合法信息源；必须用无标签、非硬伪标签的目标接入。
- [Data 软边缘化 ELBO 诊断](results/data_aided_elbo_diag_v1_20261106/README.md)显示：5/10/15 dB 的 `cos(ELBO, Data)` 约 `+0.15/+0.14/+0.24`，而 Adapt/Data 在 10/15 dB 约 `−0.05/−0.01`；但 ELBO 梯度范数在 15 dB 仅约 `9e-4`，一次固定半径步进没有稳定 BER 收益。ELBO 是辅助信号，不是单独的替代目标。

### 4.3 统计功效不足

[功效与错误构成](results/power_error_composition_20261106/README.md)给出：

- 3 session × 16/32 帧设计严重欠功效；历史 `1e-5` 量级点估计通常只是 1 个净错误（32 帧单 bit 分辨率 `4.07e-5`）。
- 主矩阵 0/5 dB 没有在线更新；逐帧错误数设计效应在 0/5/10/15 dB 约 `90.7/2.25/2.58/1.77`，必须用 session 级经验方差。
- 建议最小设计：至少 10 个独立 session × 128 帧；0 dB 30–35、5 dB 10–15、10 dB 20–25、15 dB 10–15。
- 对应可预注册的最小 ΔBER 约 `1e-3/5e-4/2e-4/1e-4`；`1e-5` 在 0/5 dB 不可判定。

### 4.4 离线饱和与可修复空间（已归档）

[离线饱和诊断](results/offline_saturation_20261106/README.md)（新开发 seed 91001–91005，开发诊断，非确认）：

- **训练预算/宽度接近饱和**：从同一 checkpoint 续训 32/64 步、同预算 `iterations` 4→6、`d_model` 64→96，Frozen Data BER 与原始 checkpoint 基本重合；最大点估计约 `-1.8e-4`（5 dB，64 步），对应 12 帧约 1–2 个比特，其余为 0 或区间跨零。
- **同帧 oracle head 有空间，但主要是逐帧的**：Data 标签 K=64 在 5/10 dB 显著，`-2.34e-3`（95% CI `[-3.50e-3,-1.19e-3]`）与 `-7.81e-4`（CI `[-1.38e-3,-1.85e-4]`）；0 dB `-6.19e-3` 但区间跨零。会话内留出帧复核后，5 dB `-1.43e-3`、10 dB `-3.26e-4`，区间均跨零，0 dB 反而变差。说明**持久静态 head 修正不能稳定迁移**。
- **CIR 估计误差是 5/10 dB 的主要剩余误差**：把条件 CIR 换成该帧真实 CIR 后，Frozen BER 在 5 dB `0.05283→0.04199`（`-1.08e-2`，CI `[-1.57e-2,-5.94e-3]`），10 dB `0.00700→0.00465`（`-2.34e-3`），相对 BER 约 20%–33%；15 dB 近似 0；0 dB 点估计 `-4.60e-2` 但 seed 间方差大。
- **结论**：离线网络不是"容量/训练不足"，而是剩余误差主要来自 CIR 估计与逐帧条件；优先做合法 CIR/相位精化（Pilot-only 与 Data-aided 对照），不要把持久 head 当作主机制。若做神经 PEFT，应做逐帧条件化读出/状态修正，并用留出帧验证。

### 4.5 贝叶斯 CIR 的物理在线增益（2026-11-06，新）

[贝叶斯递归 CIR 诊断](results/bayesian_cir_diag_v1_20261106/README.md)（3 新开发 seed × 16 帧）：

- acquisition 帧构造 CIR 先验均值/协方差；每帧先 Adapt Pilot 后验，再 Data soft 判决后验；Data 行噪声含符号方差经 CIR 能量传播；后验协方差跨帧持久。
- 相对 acquisition-CIR Frozen，四个 SNR 均 3/3 seed 同向为正：0 dB `+0.0297`、5 dB `+0.00697`、10 dB `+0.00185`、15 dB `+0.000027`；NMSE 在 5/10 dB 降低约 55%–57%。
- 5/10 dB 的逐帧增益前 5 帧增长、随后在约 `0.008–0.012`（5 dB）与 `0.002–0.004`（10 dB）饱和；与用户的"随帧增长直到饱和"方向一致。
- 5/10 dB 的 Bayes 增益已达到该 3×16 因果 oracle 真实 CIR 的水平；说明 CIR 相关 BER 头room 基本被吃掉。
- **归因边界**：这是物理状态增益，不是神经参数微调增益。共享 Bayes CIR 后，Adapt-Pilot head 只增加约 1 个比特（[共享 head 诊断](results/bayes_head_diag_v1_20261106/README.md)），神经增量未成立。
- **5 seed × 32 帧（97001–97005）**：5/10 dB 的配对增益 5/5 seed 同向且描述性 95% 区间不跨零：5 dB `+0.00561 ± 0.00223`、10 dB `+0.00141 ± 0.00084`；0 dB `+0.03178 ± 0.0282`（区间跨零，8 帧分箱 `+0.018→+0.018→+0.039→+0.051` 在 32 帧内仍增长）；15 dB 中性。5 dB 第 2 箱后饱和，0 dB 尚未饱和，10 dB 近似稳态。
- 物理增益可重复；共享 Bayes CIR 后 Adapt-Pilot head 只增加约 1 个比特，神经增量未成立。
- 仍属开发筛查：5 dB 需 10–15 session × 128 帧，10 dB 20–25，0 dB 30–35；不进入正式确认。

### 4.6 已有失败路线（保留原结论）

v14–v27、rank-1 GN/状态滤波、全 head trajectory、soft-BER、持久 Adam、历史重放、半径消融、风险门控等均未建立可重复在线 BER 收益或随帧增长。它们证明"调学习率/门控/半径/历史长度/单帧小维子空间"不足以完成核心目标；不推断一般在线微调不可行。

## 5. 方法方向：S-DANSA

> **2026-11-06 更新**：当前确认阶段先冻结**贝叶斯递归 CIR 物理状态适配**（4.5 与 5.4 的物理部分）。5.1–5.4 的低维神经状态是独立、尚未成立的子主张；在物理确认完成前不混合。

**S-DANSA（Session-level Data-Aided Neural State Adaptation，会话级数据辅助神经状态适配）** 是 v4 的主方法族，不是已完成的算法。其设计目标是同时解决 4.2 的"高 SNR 无信号"和 4.3 的"效应太小/不可重复"。

### 5.1 结构

1. **共享物理状态**：`dd_soft` tail、Pilot 条件 CIR/CFO/相位；CIR 用贝叶斯递归后验（acquisition 先验 → Pilot 后验 → Data soft 后验）。Frozen 与 Online 完全一致；Frozen 不执行无用梯度，但保留同一跟踪。
2. **数据辅助 CIR/相位精化**：Adapt Pilot 给出 CIR 初值；Data 位置的模型 soft 判决用加权 LS 精化 CIR（只读接收波形与模型输出，不读 Data 标签）；Frozen 只用 Pilot-only CIR，Online 用 Data-aided CIR。必须与纯 Pilot CIR、Oracle 真实 CIR 和纯 RLS/Kalman 对照，单独归因物理状态与神经参数。
3. **低维神经状态** `z_t ∈ R^d`（首轮 d=8，可 4/16）：跨帧持久；用零初始化 FiLM/LoRA 或 head 低秩基进入前向；初始严格等价 Frozen。
3. **状态动力学**：`z_t = z_{t-1} + w_t`，`w_t ~ N(0, Q)`；后验用对角 + 低秩协方差（Lo-Fi/EKF 或自然梯度）。`Q>0` 防止后验塌缩，并提供"随帧累积后饱和"的时间尺度。
4. **在线内循环**（每帧，只用合法观测）：
   - Adapt Pilot BCE（干净 tail）。
   - **Data 位置软边缘化模型似然**：不取硬伪标签，保留冻结均衡器的后验 `q(s)`，最大化接收波形的期望重建似然：
     `E_q[||y − H s||²] = ||y − H μ||² + Σ_l ||h_l||² Var_{t−l}`，
     其中 `μ = tanh(z_logit/2)`、`Var = 1 − μ²`；只对低维状态反传。
   - 置信度加权判决反馈/熵正则（可选，权重由离线外层学习）。
   - Reward Pilot 硬门控 + 信赖域/累计半径；拒绝时参数与协方差按协议回滚或只更新方差。
5. **离线元训练**：
   - 内循环完全复现在线时序：多帧连续、持久状态、同 tail 规则、同门控、同优化器状态、同投影/回滚。
   - 外循环用 Data 标签学习：状态初始化、低秩基、过程噪声 `Q`、损失权重、门控温度。
   - 四臂：A 普通监督续训 / B 适配导向训练 × Frozen / Online；同数据、同预算、同物理跟踪。

### 5.2 为什么可能优于 Frozen

- 离线饱和诊断显示 CIR 估计误差在 5/10 dB 占约 20%–33% 相对 BER；Data-aided CIR 精化直接作用于这个可归因残差，比持久 head 更有希望。
- Frozen 只用 224 个 Adapt Pilot 形成当前帧条件；Online 额外使用 768 个 Data 符号的**接收波形**，通过物理似然获取信息。
- 信道准静态（1200 s 相干），会话级状态可跨帧累积；后验方差随帧下降，BER 下降后饱和，符合增长假设。
- 软边缘化让错误符号的贡献被后验方差自然降权，避免硬伪标签的确认偏置。
- 数据辅助 CIR/相位精化作为物理侧补充：Pilot 估计 CIR，Data 软符号只用于精化物理状态；可靠性分类器/置信阈值只放行高置信符号。

### 5.3 失败分支

- 若 Data-aided CIR 精化不能闭合真实 CIR 差距：检查置信阈值/错误传播，改用可靠性分类器或纯 Pilot CIR 对照；若仍无增益，再回到表示/容量。
- 若简单 LS/ridge 仍有偏（已在 3 seed × 16 帧观察到 0 dB 发散、5 dB 中性）：改用**离线学习的去偏映射**，输入合法特征（acquisition CIR、Data LS、置信度、相位特征），输出 CIR 残差；真实 CIR 只用于离线训练/评分。先用 held-out NMSE 验证，再上 BER。
- 若软似然梯度被模型误差主导：改用数据辅助 CIR/相位精化 + 可靠性分类器 + 小神经校正。
- 若 oracle 显示当前表示无可修空间：换更大/更结构化表示（LoRA/Adapter/全 head）或改作用位置。
- 若高 SNR 仍无信号：检查软似然尺度、噪声方差归一化、`Q` 与门控；必要时用多帧批训练/重放降低梯度噪声。
- 若只有物理跟踪收益、没有神经增益：按四臂归因拆开，不能把物理跟踪改善写成神经微调成功。

### 5.4 神经 CIR 状态修正（N-DACC，候选；P1 证据通过后实施）

- **共享物理跟踪**：Pilot-only sparse CIR 更新（Adapt Pilot，不读 Data），Frozen 与 Online 共用。
- **数据观测**：Data 位置 soft 判决的加权 LS 或 ELBO，给出 CIR 残差 `r_t = h_ls,t − h_pilot,t`。
- **神经状态**：`z_t ∈ R^K`（首轮 K=8–16），`δh_t = B z_t`；`B` 由离线 CIR 误差协方差主方向初始化，并可离线元训练。在线参数是 `z_t`；`B/Q/R` 是离线学习的神经/超参数。
- **在线更新**：Kalman 形式
  `z_t = z_{t−1} + K_t (r_t − B z_{t−1})`，
  `K_t = P_{t−1} B^H (B P_{t−1} B^H + R_t)^{-1}`，`P_t = (I − K_t B) P_{t−1} + Q`。
  `R_t` 由 Data 置信度与 LS 残差估计；0 dB 数据不可靠时自动降权，不按真实 SNR 调度。
- **四臂**：A = 固定/PCA 基 + 固定 Q/R；B = 元训练基/Q/R；每臂都有 Frozen（`δh=0`）与 Online（N-DACC）。核心看 B-Online 对 B-Frozen，以及 B−A 交互。
- **增长机制**：`P_t` 随帧下降、`z_t` 收敛，CIR 误差下降后饱和；与"随帧增长直到饱和"的假设一致。
- **归因边界**：必须同时报告纯 Pilot sparse、纯 Data LS（物理）、N-DACC（神经状态）三者；若 N-DACC 不优于纯 Data LS，不能把物理 LS 的收益写成神经增益。

## 7. 信息与公平性约束（不可放松）

- 在线只允许读取：已接收波形、Adapt Pilot 符号、模型自身输出/置信度、Pilot 驱动的 CIR/CFO/相位/soft-tail 估计。
- 禁止在线读取：Data 发送符号、Data 比特、仿真真实 CIR/相位/CFO、Reward Pilot 回流内循环、未来帧标签。
- Adapt Pilot 用于更新；Reward Pilot 只用于动作后验收/门控/评估；Data 标签只用于离线外层目标、离线选择/校准与事后评分。
- 真状态接收机只作隔离离线诊断；`Perfect-CSI`、`Fixed CG-BPSK-DD` 不进入可部署主方法比较。
- 同波形比较必须匹配 Pilot 预算、接收窗口、acquisition、同步补偿与物理跟踪协议；报告在线参数数、更新次数、计算量和延迟。Frozen 不必执行无用梯度，但实际计算差异必须报告。
- 传统 baseline 不使用神经网络/RL，只用法观测与传统规则，独立校准；允许合理的同步/自适应补偿。
- 不恢复旧 A2C、逐符号 PPO、Data Oracle、多载波、MIMO、RIS 路线；非线性、编码、高阶调制当前不扩展。

## 11. 决策（2026-11-06 已定）

用户选择：**接受物理在线适配，调整核心主张。**

- 当前核心：**离线神经均衡器 + 合法在线贝叶斯物理状态（CIR）适配**。
- 原"在线神经参数微调必须优于 Frozen"降为**独立、尚未成立的子主张**；不再要求纯 CIR 跟踪不能单独完成核心。
- 已定证据：5×32 开发筛查中 5/10 dB 物理增益 5/5 seed 同向且描述性区间不跨零；0 dB 点估计大、32 帧内仍在增长；15 dB 中性。
- 下一步：
  1. 按物理主张重冻结确认判据与样本量（5 dB 10–15 session × 128 帧，10 dB 20–25，0 dB 30–35，15 dB 10–15）。
  2. 跑 10–15 session × 128 帧的物理开发筛查；0 dB 视算力扩到 30–35。
  3. 开发筛查稳定后启动独立确认；确认集 seed 与开发集隔离。
  4. 神经子主张另行验证：共享 Bayes CIR 后做后验条件化 FiLM/LoRA 或学习式噪声模型；不与物理确认混合。
- 在物理确认完成前：不宣称原"神经参数微调"目标完成；不把开发筛查写成确认。
