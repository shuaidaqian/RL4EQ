# 前缀短窗及安全半径内幅度诊断：候选迁移仍未成立

本轮在符号残差 A256 上构造真实短接收窗，检验前缀 Pilot 能否提供更接近
Data 帧尾的适配任务。短窗改变了部分 Reward 验收决定，但没有得到可靠的
Data BER 增益。随后在同批开发样本上检查两档更大步长，候选仍未稳定迁移。
不扩大同设置留出矩阵，不放松验收阈值，不超过既定更新半径。

## 固定与后续提出的部分

[短窗计划](prefix_task_plan_20261102.md)在首轮输出前固定：offline_train 新
seed=47000–47002，各 4 帧、四 SNR、48 上下文。源 SHA256 为
`605281acef3e9efe61e8d8354f6feb61b3324737eabff0a5ba3f75f43a6b7ecc`。

更新比较整帧 Adapt BCE 与实际截到 224 点、仅评分 116–223 的 Adapt BCE；
验收比较整帧 Reward 与实际截到 256 点、评分 224–255 的 Reward。
所有逐符号字段和 H/H^H 都按实际长度缩短，不向缺失位置填零并维持完整正规方程。
两个更新候选各复用给两个验收任务，共 192 条记录，每帧重置。

首轮 lr=5e-4 的最大实际参数增量仅为 0.002064，即安全半径 0.05 的约 4.13%。
因此在首轮结果后另固定[幅度检查计划](symbol_step_response_plan_20261102.md)：
新增 lr=5e-3 和 2e-2，各一步，半径与验收规则不变。它们复用相同开发样本，
不能将 576 条记录当作三批独立证据。新增两档的最大实际增量分别为 0.020643
和约 0.05（浮点报告 0.05000000075），均在投影数值容差内。

所有协议、三档幅度的接收波形与 Frozen 指标逐帧一致；同一候选复用验收时
其 BER/BCE、范数一致。Data 标签只在候选及验收完成后评分，不按 Data 最优
组合生成控制策略。原权重不变，不注册 RL 动作。

## 结果

下面完整列出两端协议：整帧更新+整帧验收，以及短窗更新+短窗验收；交叉组合
和所有区间保存在机器摘要。单位为相对同 Frozen 的 BER 改善百分点，正值较好。

| 学习率 | 更新/验收任务 | 0 dB | 5 dB | 10 dB | 15 dB |
|---:|---|---:|---:|---:|---:|
| 0.0005 | 整帧/整帧 | −0.01085 | +0.01085 | 0 | 0 |
| 0.0005 | 短窗/短窗 | +0.01085 | +0.01085 | 0 | 0 |
| 0.005 | 整帧/整帧 | −0.02170 | −0.01085 | 0 | 0 |
| 0.005 | 短窗/短窗 | −0.01085 | +0.03255 | 0 | 0 |
| 0.02 | 整帧/整帧 | 0 | −0.04340 | 0 | 0 |
| 0.02 | 短窗/短窗 | +0.01085 | −0.01085 | −0.01085 | 0 |

没有组合显示可信的正向增益区间。每项仅有 3 个独立信道 seed，探索性区间
很宽；少数理论相等的差异约在浮点舍入量级，不能将其作为收益。

关键区分如下：

- lr=0.0005 时，10 dB 短窗更新+整帧验收接受 0 帧，短窗验收接受 5 帧，
  两者都没有修复 Data 错误。改变接受率不等于改变目标。
- 15 dB 短窗验收在三档中均接受 1 帧，但候选与验收后 BER 都不变；
  该批样本中，单纯让验收更有响应没有创造有效候选。
- lr=0.02 的 5 dB 整帧组合接受 6 帧，其中 5 帧有害；修复 7 个错误、
  引入 11 个。更大作用幅度能改变判决，但方向不稳定。
- lr=0.02 的 10 dB 短窗组合修复 1 个、引入 2 个错误。不能把候选能改变
  BER 等同于可泛化的更新。

源 checkpoint 的离线训练使用普通全帧 Adapt 内循环，没有针对短窗任务做
匹配训练。因此本轮只否定“直接改任务或步幅就足够”的证据，不证明匹配离线
训练也无效。短窗模拟覆盖不足也不等同于所有真实 Data 尾部误差。

## 工程与下一步

定向测试 **45 passed，10.05 秒**，覆盖非零新 head 下的标签污染不变、基础
权重不变、字段长度一致，以及短窗正规算子与补零完整算子不等价的数值检查。
最终全量回归 **737 passed，253.45 秒**，使用 CPU、FFT 后端与单线程环境。
定向与全量测试有重叠，不相加；真实组件实验使用 CUDA。

下一阶段应直接检验离线表示能否支持匹配的边界任务更新，而不是继续单独
增加候选数量、head 步长或 PPO 学习率。需要固定普通监督/更新后训练对照、
同 checkpoint Frozen、原模型代价参照及新的独立 seed；若仍无在线迁移，
再据梯度与错误分布判断该 head 的作用族是否覆盖可由 Pilot 辨认的状态。
