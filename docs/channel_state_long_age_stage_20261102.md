## 反馈失配线索

5 dB、4095 帧的三个候选 Data 改善分别为 +5.72917/+0.39062/+1.17188 pp。
两个较大的改善都被拒绝：Reward BER 各增加 1/32，虽然前向信号 loss 分别
下降 .37528/.14180。原 guard 按预定优先级拒绝，不能事后用 Data 推翻它，
但这一结果说明单帧 32 bit 的 Reward 排序有实际限制。

这还不足以支持直接改成信号 loss 验收，因为前面已有信号 loss 与 Data
方向相反的例子。下一步应在新的训练轨迹分离短窗口 Adapt 聚合与 Reward
聚合的作用，使用同一窗口动作、窗口级留出反馈，符合最终窗口 RL 的机制。
当前模型尚未在长年龄训练；该分布问题与反馈问题分别保留，不能混为确定原因。

## 复现与验证

总诊断耗时 **427.50 秒**，含 49152 帧物理模拟与多候选研究评分，不等于
在线每帧耗时。定向回归 **84 passed，16.91 秒**；最近完整回归为
**775 passed，270.34 秒**，在新增逐年龄汇总测试前完成。
单次动作、种子、四 SNR、五年龄及无在线 Data 标签核验通过。
逐年龄汇总拒绝重复/缺失 seed，避免把不同时间平均后当作持续优势。

[机器摘要](results/channel_state_long_age_stage_20261102.json)保存逐帧记录、
原始 SHA、协议、checkpoint SHA、实测耗时和外推限制。正式 RL、校准传统
主比较及数百秒连续神经会话仍未完成。
