# 复数记忆的历史Pilot机制筛查

依据是复数记忆在10/15 dB有独立在线收益，但0/5 dB和尺度学习额外价值未确认；单帧Adapt的108个复约束不足以单独辨认117个复tap。当前/+8的两个Pilot堆叠在20个训练样本中达到满列秩，但状态变化与噪声影响仍待实证。

先不扩大留出或训练预算。固定使用 `channel_memory_map_control64_20261102/model_best.pt`（SHA `153ccc68515fe77996f822924f0056d25a283ca0fd7b185c19a030bfe2871f08`）的零记忆、固定尺度，明确不是根据某SNR留出最优结果改选。新尺度分支尚无额外价值，故先使用更简单的控制。

复用该控制原训练缓存每SNR/年龄第一个样本，共20对，每对为当前与当前+8两个已收到帧；**在较晚那一帧才做决策与Data评分**，绝不把较晚Pilot用于较早帧的在线动作。不是连续两个帧，也不是正式RL窗口。

- 固定memory组，lr .02、三步、raw半径.8；signal/MAP两个目标分开。
- Adapt历史数1/2 × Reward历史数1/2，共每目标四个组合、总160记录。
- 同一候选作用于对应两个收到的上下文；验收只使用对应Reward Pilot BER/信号loss原guard；所有组合始终只评分同一个最后帧Data。
- MAP表示各帧原MAP目标的平均，是现有正则化更新，不声称是严格状态空间联合后验。没有依据Data修改先验权重。
- 只报告训练缓存描述统计与同上下文差值，不产生独立泛化或长期成功结论；再次确认旧参数不改写、Data标签污染不改变候选或guard。
- 如果增加Adapt观测有实际作用，再登记新offline_train轨迹的连续历史验证；如果没有，重审状态参数化与先验，不直接增加窗口或PPO。

旧17参数gate上的窗口失败不能直接推断234参数复记忆窗口失败；本轮明确检验这一变化，不改原信道或acquisition协议。
