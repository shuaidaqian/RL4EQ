按[固定计划](channel_state_tracking_plan_20261102.md)，heldout_edge 84001–84003、
四 SNR、每条 128 帧，共 1536 上下文、3072 条 A/B 记录全部完成。A 是普通
离线监督，B 增加更新后 Data 目标；每个 Online 均与自己的同 checkpoint Frozen
配对。参数接受后跨帧保留，每 seed 重置，累计 head 半径 .2。
此轮内层为 likelihood、lr=.02、3 步，训练内层原为 .005、1 步、半径 .05，
故不能将差异单独归因为匹配元训练。128 帧为 13.1072 秒，尚非数百秒验收。

## 参数延续与反馈边界

每格共 384 帧，下表有益/有害接受仅指动作当帧相对动作前参数的 Data BER，
均在决策后统计，不用于策略。

| SNR | A/B 接受帧 | A/B 有益接受 | A/B 有害接受 | A/B 触及累计半径帧 | A/B Reward BER 前后均零帧 |
|---:|---:|---:|---:|---:|---:|
| 0 | 6/6 | 1/1 | 1/1 | 380/380 | 3/3 |
| 5 | 5/4 | 0/1 | 2/1 | 379/379 | 179/179 |
| 10 | 38/24 | 1/1 | 1/0 | 381/381 | 371/371 |
| 15 | 76/83 | 4/3 | 3/2 | 320/317 | 384/384 |

10 dB 的 B 分支没有当帧有害接受，却在全部三个 seed 上累计劣于 Frozen。
这说明“当前动作不恶化当前帧”不能替代“保留参数对未来帧有效”。本实验尚未
区分固定偏置随条件变化失配、反馈排序失配与半径限制各自的因果贡献。
参数大部分时间触边也不能独自支持放大半径。15 dB 的 Reward BER 全零，
必须检查信号 loss 的排序信息，不能将接受次数视为改善证据。

核验通过：两分支波形一致、每 seed 参数起点重置、相邻帧累计范数连续、半径
上限、逐条无在线 Data 标签，以及原始 summary 的统计重算一致。摘要脚本
[summarize_channel_state_tracking.py](../scripts/summarize_channel_state_tracking.py)
还拒绝缺失、重复或超出预设 seed/帧数的输入。

原始日志的 `data_waveform_used_for_guard=false` 是元数据错误：信号 loss 只读
Pilot 波形，但优先验收的 Reward BER 由整帧均衡计算，实际读取 Data 区接收波形。
这是用户允许的信息范围，不含 Data 标签。原始日志保留，机器摘要显式更正，
后续入口已修复；更新本身仍只读 Pilot 波形。旧四臂日志如使用相同协议，也应
按这一说明解读。该修复不改变任何候选、验收或 BER 数值。

该修复定向 **70 passed，15.93 秒**；完整 CPU FFT 回归 **762 passed，248.82 秒**，
两者重叠。测试同时覆盖整帧与 Pilot-only 验收，并通过毒化 Data 标签和发送符号
验证候选、Reward 评分、验收和跨帧累计范数不变。

本轮启动时未加完整运行计时器，不能可靠报告本次总墙钟或生产延迟。后续诊断
显式计时。用户已确认先验证统计收益，再做实时优化。

## 结论与下一步

当前支持 0 dB 的局部机制，仍不满足四 SNR、后期优势、正式窗口 RL 与校准传统
比较的最终目标。暂不扩大同一留出矩阵或启动数百秒主验收。

下一步在新的训练轨迹上固定首帧合法动作，检验其随帧龄变化的 Data 效果，
并同时记录当前 Reward BER/BCE/信号 loss 相对 Frozen 的排序。先判断反馈
能否识别持续状态失效，再决定是否训练期限感知的离散安全动作。Data 仅作
离线事后解释，不能把事后最优选择写入在线控制器。
具体预算与停止条件见[固定首帧有效期计划](channel_state_retention_plan_20261102.md)。
