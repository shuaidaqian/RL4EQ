## 数学与实验结果

新增 MAP 目标与状态方向使用相同 acquisition/过程先验。在未截断后验方向、
常数 gate=1 的测试里，MAP 参数梯度接近零，而 likelihood 梯度非零。
这确认两个目标不同，不能由此推导 MAP 一定改善 bit 判决。

下表是 medium 档经原 Reward guard 后的 Data BER 改善，单位百分点，
每格 15 当前帧、三个 seed。区间按 seed 计算 95% 配对 t 区间。

| SNR | likelihood 改善［区间］ | MAP 改善［区间］ |
|---:|---:|---:|
| 0 | +0.76389 [+0.11268, +1.41510] | −0.04340 [−0.17807, +0.09126] |
| 5 | −0.03472 [−0.13354, +0.06410] | +0.00868 [−0.02867, +0.04603] |
| 10 | 0 [0, 0] | +0.05208 [−0.11907, +0.22324] |
| 15 | 0 [0, 0] | −0.01736 [−0.09206, +0.05734] |

0 dB 的 likelihood medium 有探索性正区间，三个 seed 的点估计均为正；
MAP medium 相对它更差约 −0.80729 pp，配对区间 [−1.42440, −0.19018] pp。
其余 SNR 的两目标差值区间均跨零。不能把 MAP 在 5/10 dB 的正点估计当作
可靠收益，也不能以个别接受率上升替代 BER 验收。

small/large 的 MAP 经 guard 后改善区间全部包含零；large likelihood 在
0 dB 点估计约 +0.97222 pp，区间 [−0.18742, +2.13186] pp，其余没有正向区间。
不根据最大点估计改选 large。完整各档结果和同帧目标差值见机器摘要。

## 结论与后续

一致的先验目标不是当前 BER 瓶颈的充分解法。实际残差还可能含相位误差、
先验协方差失配等成分；MAP 估计 CIR 也不等于最小 BER 判决。
本轮保留可复现实现，不替换默认目标，不立即启动 MAP 匹配训练。

likelihood medium 在新的训练轨迹上有 0 dB 正向证据，值得预先冻结一次独立
128 帧持续会话检查。具体见[持续状态动作计划](channel_state_tracking_plan_20261102.md)。
它不代表四 SNR 已通过；原 8 帧四臂结果不变，新验证也不混入原均值。
只有取得持续收益和合法反馈区分证据后，才推进正式窗口 RL 与数百秒/传统比较。

研究诊断总耗时 **59.81 秒**，包含多候选、参照和统计；不是生产延迟。
