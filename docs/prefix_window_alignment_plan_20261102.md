# 多帧 Pilot 聚合的只读机制计划

128 帧单帧梯度持续更新未通过后，先区分估计噪声与系统方向失配。
本阶段只在 offline_train 运行，不进行正式留出选优或在线 Data 标签控制。

- 固定 prefix B256 checkpoint：SHA256 `735864bb99c9670298d87dff74d5b98865af9870cc071864c21a2b63040f8b91`。
- 新 seed 74000–74002，各 16 帧，四 SNR；每个轨迹前 7 帧仅积累历史，
  对第 7–15 帧固定比较 1/4/8 帧 Adapt 平均损失，共 108 当前上下文、324 候选记录。
- 每个候选从同一离线起点生成，lr=0.005、一步、半径 0.05；不累计参数。
- 历史仅包括当前及此前接收帧；每帧用自身合法 CIR/相位条件与真实 Adapt 短窗。
  不引入等待未来帧的延迟，也不把不同 seed 的 Pilot 混合。
- 候选只由 Adapt 标签产生；离线随后分析当前完整 Data 与尾部的梯度余弦、
  一阶损失预测、实际 BCE 与 BER 改变。不据 Data 排序动作、更新权重或选 checkpoint。
- 窗口共用同一当前帧，不是独立样本；统计按独立 seed 聚合。
- 不调整 guard；本阶段不作 Reward 验收后的在线成功声明。

若聚合显示可重复的方向改善，再固定匹配的跨帧离线训练；若仅降连续损失而
不改变 BER，仍未通过作用门槛。不能用本诊断替代未来正式 RL、校准传统比较
或数百秒会话验证。
