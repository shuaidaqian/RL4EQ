# 现有神经相位组作用能力三臂诊断

本阶段在现有网络中发现了比 head 更强的作用位置，但没有证明稳定在线 BER
收益。网络结构和正式 RL 动作集合均未修改。计划及三臂预算见
[预先固定设置](existing_phase_capacity_plan_20261101.md)。

三臂使用同一 head post-adapt 256 步终点、offline_train 新 seed=35010–35012、
每条 4 帧、四主 SNR。共 144 条记录；逐帧接收波形 SHA256 和 Frozen BER
均匹配。head 有 65 个参数，现有神经 phase 组有 6469 个参数；相同 AdamW
单步和上限不等于相同实际参数位移或计算量。

按全部候选计，phase 全前缀评分在 0/5/10/15 dB 分别修复/引入

它没有被选作下一轮默认评分规则。

## 信息与实现验证

候选只读取 Adapt 视图；Reward 决定接受后才计算 Data 梯度、输出与 BER。
后记忆评分仍保留完整 Adapt 输入，只改变损失评分位置。因为模型含全局注意力
及 Pilot 条件，这不等价于证明所有历史尾误差均被消除。

可微 phase/BCE 候选与现有通用 PPO 更新函数数值一致；污染 Reward/Data
波形、发送符号和标签不改变候选。17 项定向测试通过，其中新增小规模端到端
检查证明诊断不原地修改基础权重、不注册正式动作，并记录实际参数组和评分起点。
完整数值及原始文件 SHA256 见
[机器可读摘要](results/existing_phase_capacity_stage_20261101.json)。

## 下一步推导

该诊断区分了两个问题：head 的连续作用偏弱，而现有 phase 分支具有更强作用；
更强作用仍未自动转化为跨 seed 稳定 BER 改善。下一轮可在现有结构内测试
phase/BCE 更新后的离线 Data 泛化训练，使用新的训练 seed 和独立留出 seed。
这不需要新增结构；它仍是组件机制验证，不把未注册候选当作正式 RL 方法。
若外层目标有收益，还必须加入无内循环的同权重 Data 目标对照，排除重加权解释。
