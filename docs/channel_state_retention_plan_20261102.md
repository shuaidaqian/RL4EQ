# 固定首帧状态动作的有效期与反馈排序诊断

128 帧留出结果显示：0 dB 有局部持续收益，10 dB B 有累计负向区间，但没有
当帧有害接受。因此下一项问题是保留参数在未来条件下是否仍有效，以及当前
Pilot 反馈能否识别其有效性。本诊断不改正式在线 runner，不在留出集选参数。

- 固定 channel_state B256 checkpoint，SHA
  `0fdd233cd406dced2ec3ec75f18933671ec42651f88a0c37dd70ae081156c490`。
- 新训练范围 offline_train 79000–79002，四 SNR，各生成 128 帧，只在帧龄
  0/7/31/63/127 评分，共 60 当前上下文。没有额外种子或调参网格。
- 首帧只做一个固定 medium 动作：lr=.02、3 步、head 半径 .2、likelihood。
  原 Reward BER/信号 loss guard 接受后固定保留；后续不再更新 head。
  这是有效期分解，不能代替原来每帧更新的持续跟踪结果。
- 在五帧龄，同波形评 Frozen 与保留参数，记录 Reward BER/BCE/信号 loss
  对两者的排序。候选参数和所有 Pilot 决策结束后，才计算 Data BER/BCE。
- 预先固定两个只读诊断：当前帧按原 guard 重新验收保留参数；或者只在原
  guard 支持退回 Frozen 时撤销保留。二者均只用当前 Reward，不用 Data 排序，
  不改变下一帧的保留参数。所有分支一起报告，不能事后只展示最好的一种。
- 按独立 seed 统计，报告原始保留及两个过滤规则的 Data 改善、后期减早期
  （仅评分帧龄，不等同连续区间），以及反馈与实际改善的符号计数。
- 若当前 Pilot 排序也无法区分有益/有害状态，不将反复验收或增加 PPO 预算
  当作充分解法；再定位状态作用族与可观测性。若有线索，也须训练范围确认，
  之后才预注册独立持续验证，不能直接宣称最终目标完成。

脚本显式计时并保存协议、checkpoint SHA 和原始记录；总诊断耗时含模拟、
多个前向、梯度和统计，不冒充生产均衡延迟。
