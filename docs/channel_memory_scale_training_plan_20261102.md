# 复数记忆尺度学习的固定预算实验

新训练轨迹 97000–97002 的 36 上下文、144 候选未建立任何平均收益正区间，不能声称机制已成立。medium MAP 四 SNR 的验收后均值为正，signal 大更新普遍退化；不追加相同留出矩阵或直接进入 PPO。

随后只读原 20 个训练缓存的当前/+8 标签导数：普通监督对尺度梯度严格为零，更新后尺度梯度有限且非零，但 MAP 当前/未来方向存在相反情况。更大表示只解决可达空间，Pilot 目标与判决风险差异仍需检验。此处离线 Data 导数不参与候选产生或在线控制。

本轮唯一新假设是：离线学习有界坐标尺度，可改善原先使用统一尺度的合法在线更新。它不以未经训练的候选已可靠获益为前提，因此是新的机制检验，不是既有门槛通过的延伸。以 34 个尺度参数、固定 64 步检验，禁止通过改变 Frozen 扩大适配差值。

## 预先固定的训练

- 配置 `configs/eme_long_memory_v2_channel_memory_map_transfer.json`。
- A 为固定尺度控制，B 为更新后目标；共同从原 long_age B64 严格显式迁移，不能从两步 smoke 接续。
- offline_train 98000–98063，四 SNR 轮换；年龄 0/127/1023/2047/4095 轮换；同样当前/+8 两帧外层标签暴露。
- A/B 各 64 步、batch1、outer lr .01。该学习率是本轮预定值，不按留出调节；输出尺度因 `exp(tanh)` 有界。
- inner 固定 MAP，lr .02/三步/raw 半径 .8；Reward 固定 signal loss/BER 原 guard；Adapt/Reward/Data 边界不变。
- 只允许 34 个 memory_scale 参数离线更新，234 个 memory 参数在离线 checkpoint 中必须保持零；其余全部与源相同。
- A 普通监督对尺度无梯度，必须诚实称为固定尺度控制。保存完整样本和输入指纹，A/B 缓存逐项相同。

## 预先固定的验证与停止规则

训练完成先审计参数与相同输入 logits。审计通过后只运行一次 heldout_edge **99001–99005 × 四 SNR × 8 帧**四臂实验，物理 burn-in=1023，无历史神经更新，验收后跨帧保留；仍是约105秒处启动的机制，不是从首帧持续在线。

主要看 B Online 对 A Online 的 seed 配对区间及 B 对同 checkpoint Frozen 的区间；因 Frozen 必须精确相同，不能把离线基线下降当改善。同时报告所有 SNR、后期减早期与有害接受，不挑最佳 SNR。未改善则不追加本配置步数或 seed，先重审任务/状态先验；有明确改善才规划独立 128 帧连续机制，之后才接正式窗口 RL 与数百秒/传统主比较。

一次 acquisition 协议、1200秒相干时间、原扰动范围保持不变。所有耗时为研究墙钟，不替代生产每帧时延。
