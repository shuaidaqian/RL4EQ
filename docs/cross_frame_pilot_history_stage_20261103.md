# 多帧 Pilot 方程满列秩，直接平均现有 MAP 目标仍未改善 BER

## 诊断协议

在[离线尺度候选未通过门槛](cross_frame_offline_pair_stage_20261103.md)之后，用 `scripts/diagnose_cross_frame_pilot_history.py` 做只读候选诊断。固定普通监督64步checkpoint、实际环境seed110060–110062、Level B四个主SNR、物理帧龄1023之后各8帧，比较最近1帧和8帧Adapt上下文。每个候选从同一冻结参数出发，使用原三步AdamW、学习率.02、MAP目标和半径.8，接受当前Reward Pilot的相同BER/loss守门。

所有候选的优化、Reward计算和验收结束后，才计算当前Data BER。历史Data与当前Data标签均不进入控制；未知发送符号不用于设计矩阵。这里没有提交候选参数、没有PPO、没有持续记忆，因此是物理方程与更新目标诊断，不是正式在线接收机结果。

完整[机器结果](results/cross_frame_pilot_history_4snr3s8f_20261103.json)包含配置、权重和原始日志SHA256、候选与验收后指标。192条记录、12个SNR/seed配置完整结束，权重逐项保持不变；完整进程205.960秒。

## 确认的基本事实

所有样本中，单帧完全已知的Adapt设计矩阵均为 **108×117、复数秩108**；8帧拼接均为 **864×117、复数秩117**。单帧Pilot本身对稠密117复数tap的识别欠定；acquisition先验、稀疏性和MAP正则能约束解，但不等于增加独立观测。复用历史合法Pilot确实能改善矩阵秩。

“矩阵满列秩以后直接平均现有单帧目标就会改善Data BER”没有得到支持。以下BER均为百分数；候选是验收前输出，验收后包含拒绝更新时返回Frozen的结果：

8帧验收后相对单帧的平均改善，在0/5/10/15 dB分别为 **−0.24957/−0.10851/−0.15191/−0.07053 pp**，四个SNR的seed级配对区间均跨零。8帧验收前的候选BER点估计在四个SNR也都高于Frozen；0/5/10 dB的平均Reward信号loss同样变差。因此不能把失败仅归因于Reward守门拒绝了优良候选，更不能删除守门来宣称成功。

单帧在本组0 dB探测中相对Frozen有正区间，但这既不是持续RL结果，也没有复现为四SNR通过，不能据此替换既定总体成功标准。未按结果追加seed或改变窗口。

## 不能继续当作事实的假设

- 不同帧经各自Pilot相位估计与神经调制后，复数tap残差必然处于同一坐标系。
- 一组共享记忆参数经过不同帧的神经尺度映射后，就等于一个共享物理CIR。
- 对各自含MAP先验的单帧目标取平均，等于按一次先验和多帧联合似然得到的后验。
- 只需增大窗口、微调学习率，或者取消Reward守门，便能把矩阵秩改善转成Data收益。

上述都是需要独立验证的建模假设。本轮没有从Data事后指标反向修改在线选择或把Data更好的候选写回正式方法。

## 从模型定义重新开始的下一步

下一步先明确“共享状态”是什么，再增加正式代码：分别定义复CIR、公共相位、CFO及其从acquisition到当前帧的坐标变换和过程先验。先用合法Pilot验证不同帧残差是否可在该坐标下聚合，再构造一次先验与联合似然，核对它与逐帧递推是否等价。

例如，当所有帧真的共享同一个CIR、噪声相同且每帧有n行方程时，平均单帧MAP目标的先验项仍约为 `P/n`；联合似然按Kn行归一化且只计一次同一先验时应为 `P/(Kn)`。当前模型的帧龄先验和神经尺度随帧变化，所以不能直接把这条简化公式当成修改依据；必须先定义对应的物理随机变量与条件关系。

第一步应是小型合成机制验证：在已知生成参数仅供离线核验、绝不注入在线控制的条件下，验证相位坐标变换、联合MAP正规方程和逐帧递推的等价性，同时毒化所有隐藏Data标签。随后才决定如何让离线网络学习这种状态到Adapter/FiLM/记忆的调制，并让RL继续选择离散安全动作。主方法仍为神经块均衡与RL调制，不能以传统估计替换Proposed来绕过目标。

当前正式默认仍为原单帧更新；8帧直接平均只保留为诊断。完整传统重新校准、四SNR多seed主比较、数百秒真实连续收益和RL归因仍未完成。
