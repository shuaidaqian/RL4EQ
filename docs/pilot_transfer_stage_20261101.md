# Pilot 更新后泛化：首轮四臂机制实验（2026-11-01）

## 当前结论

新增真实信道的可微内循环和离线更新后 Data 目标已经运行，但 **64 步训练尚未证明
比同预算普通监督更适合在线微调**。两分支的在线 BER 基本重合，不能据此宣称
适配友好 checkpoint 已经成功，也不能进入正式 PPO/传统 baseline 主比较。

0 dB 的两分支相对自身 Frozen 都出现正向 seed 级区间；5/10/15 dB 区间均跨零。
这是 5 seed 的探索性机制实验，没有多重比较校正，不作为论文正式显著性结论。

## 协议与完整性

- 原 checkpoint SHA256：`8cd3912d1c957c9689c51730aff9d27a8f74942186c802a7483e5781af65aec4`。
- A：继续整帧 BCE；B：整帧 BCE + Adapt 更新后 Data BCE。两组各 64 步、batch=1，
  lr=1e-5，seed=31000–31063，四个主 SNR 轮换，使用 `offline_train`。
- 内循环沿用原 `peft_phase_signal_moderate`：相位趋势 PEFT、信号重构、AdamW、
  lr=0.0025、5 步、梯度范数限制 1、增量范数上限 0.05。
- 测试：Level B、`heldout_edge`、gap=0、delay=116、prefix Pilot=256，
  Adapt/Reward=224/32，seed=41001–41005，每 SNR 每 seed 8 帧。
- 四臂默认每帧从零 Adapter 重置；仅当帧 Reward Pilot 验收。没有 PPO 调度、
  窗口回滚或跨帧 PEFT 累计，不能用本实验检验“累计学习使后期更好”。
- 原始日志共 320 行；两分支按 SNR/seed/frame 配对，接收波形 SHA256 逐帧一致。
  条件来自 acquisition CIR 与当前 Adapt-only 相位统计；未使用真实 CIR。
- 更新和 Reward 决策均先结束，再计算 Data BER/BCE；Data 不参与在线控制。
- 当前首轮使用 `direct` 线性算子。新加入的可选 FFT 后端没有改变本轮数值路径。

## 四臂结果

BER 为百分数，改善与区间为 BER 百分点；正改善表示在线优于同分支 Frozen。
每条 seed 轨迹先平均 8 帧，再计算 5 个 seed 的配对 t 区间。

| SNR | A Frozen | A Online | B Frozen | B Online | B 相对自身 Frozen 改善（95% CI） |
|---:|---:|---:|---:|---:|---:|
| 0 dB | 22.5423% | 21.8555% | 22.5260% | 21.8457% | +0.6803 pp [0.1980, 1.1627] |
| 5 dB | 5.9473% | 5.8464% | 5.9505% | 5.8496% | +0.1009 pp [-0.0129, 0.2147] |
| 10 dB | 0.9082% | 0.8887% | 0.9115% | 0.8919% | +0.0195 pp [-0.0383, 0.0774] |
| 15 dB | 0.2018% | 0.1986% | 0.2018% | 0.1986% | +0.0033 pp [-0.0058, 0.0123] |

B 相对 A 的额外适配增益，即 `(B Frozen−B Online)−(A Frozen−A Online)`，
四 SNR 约为 `−0.0065 / 0 / 0 / 0 pp`，没有可靠正增量。B Online 相对
A Online 的绝对改善为 `+0.0098 / −0.0033 / −0.0033 / 0 pp`，也没有可靠优势。

B 的 Reward 接受次数为 33/19/23/13（各 SNR 40 帧），其中有害接受为
7/5/4/0 次。验收通过仍不能保证 Data 改善。

## 前缀边界诊断

另在 `offline_train` 的独立 seed=32000–32002、每条轨迹 4 帧、原 checkpoint 上，
预先固定比较全部 Adapt 位置评分与跳过前 116 个位置评分。后者仍保留完整 Adapt
已知符号作为卷积输入，仅修改重构误差的评分窗；有效评分样本从 224 降至 108。
这避免把“删除重构所需的已知 Pilot”与“排除受历史尾部影响的误差”混为一谈。

| SNR | 全 Adapt 评分改善 | 跳过边界评分改善 | 有害接受：全 / 跳过 |
|---:|---:|---:|---:|
| 0 dB | +0.9549 pp | +1.0417 pp | 1 / 1 |
| 5 dB | +0.3147 pp | +0.3581 pp | 1 / 0 |
| 10 dB | +0.0868 pp | +0.0977 pp | 0 / 0 |
| 15 dB | +0.0109 pp | +0.0109 pp | 0 / 0 |

所有 3-seed 区间均跨零，不能认定边界评分已经解决迁移。测试证明，在物理条件
固定时，跳过记忆长度后的重构梯度不再依赖历史 tail；它仍不能消除条件估计误差。

## 接下来的可证伪问题

首轮只沿用原相位趋势动作，实际活跃的更新方向主要是公共相位与 CFO 两个标量，
没有检验“离线表示能否支持实际神经 head/Adapter 的 Pilot 微调”。下一轮应先
把可微内循环扩展到现有神经 PEFT 动作，并核验它与正式 PPO 动作的数值一致性；
随后在相同信道、独立训练 seed、预先固定预算下重新比较四臂。

如果神经 PEFT 的更新后泛化仍不成立，继续分解可观测性、物理状态误差与可更新
参数范围；如果成立，再进入跨帧累计、PPO 调度和独立确认。传统 baseline 的长记忆
容量及 SC-FDE 线性/循环卷积适配问题仍须在正式主比较前校准。
