# 复数状态记忆：实现与首轮容量筛查

本阶段已经完成零输出记忆 Adapter 和 80 个合法候选筛查，但**没有确认整体目标完成**。更大的 CIR 可达空间并未自动使 Adapt 更新可靠；下一步是固定协议的新训练轨迹复核。

## 结构与信息边界

在原神经状态 gate 之后增加 117 个复数记忆项（234 个在线参数）。记忆为零时新增输出严格为零；34 参数的尺度映射只改变更新后的坐标尺度，不改变原 Frozen。离线只允许训练该尺度，旧权重冻结，在线只更新记忆。普通未更新监督对尺度的梯度为零，因此对照准确称为“固定尺度控制”，不能称为成功学习了尺度的普通监督。

残差每个实/虚分量为 `0.25 * tanh(memory) * exp(tanh(scale(hidden)))`。单帧 raw 参数半径与真实 CIR 步长分别报告；当前不是正式 PPO 动作。配置、迁移均显式启用，不扩大旧 `channel_state` 参数别名，也不改变旧 checkpoint 的参数键。

Adapt 目标只使用完全已知的前缀卷积行；MAP 在此基础上加入原 acquisition/过程先验。Reward 沿用动作后 Reward Pilot BER 和信号 loss，不包含 prior penalty。所有候选和 guard 完成后才计算 Data BER，不据 Data 排序或选择候选。始终允许整帧接收波形参与均衡和 Reward BER。
