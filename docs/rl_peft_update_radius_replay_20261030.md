# Pilot-only PEFT 更新半径筛查（2026-10-30）

## 结论

在 Reward=64、固定离线 checkpoint、Level B `heldout_edge` / `cfo_phase_mid` 和同一组信道 seed 下，比较 PEFT 最大更新半径 0.01、0.025、0.05。**没有任何一个半径在四个 SNR 上证明了统计可信的在线 BER 改善**；每个 SNR 的 seed 级 95% 区间都跨零，半径之间的配对区间也跨零。

三个半径在这 5 个新 seed 上的四 SNR 等权平均 BER 改善分别为 +0.62、+1.22、+1.35 个百分点。0.05 的均值最高，0.025 次之，0.01 最低；但收益主要集中在 seed 3003、3004，5 个 seed 的总体区间仍很宽。更小步幅没有稳定保留或提升中高 SNR 收益，也没有显示出可靠的低 SNR 安全优势。

因此，不继续盲目扫更新半径，也不把这一小样本正均值当作成功证据。当前在固定 checkpoint 下反复微调在线损失、参数范围、Reward 样本数和更新幅度，仍未达到“在线微调稳定超过 Frozen”的目标。

## 实验设置

- 固定 checkpoint SHA256：`8CD3912D1C957C9689C51730AFF9D27A8F74942186C802A7483E5781AF65AEC4`，未重训、未修改。
- Level B `eme_long_memory_v2`，`heldout_edge`、`cfo_phase_mid`、最大时延 116、gap=0；前缀 Pilot 总长 256，Adapt/Reward=192/64。
- 更新 16 个 state-mapping 与直接 phase/CFO PEFT 参数；Adapt 信号重构损失、lr=0.0025、5 步；Reward 在两帧未来 Pilot 上使用 BCE 和硬错误数门控。
- 三个半径共用 seed 3001–3005、0/5/10/15 dB 和同一批 Data 测试帧。每种设置 20 条 seed/SNR 轨迹、40 条逐帧事后 Data 记录。
- 对照间的信道状态元数据和 Frozen Data BER 完全匹配；所有在线更新和门控没有使用 Data 波形或标签，Data 仅用于事后统计。
- 每个 seed/SNR 的统计值是最后两帧 Data BER 改善的平均，置信区间以 5 个 seed 为统计单位。

四 SNR 等权合并后的 seed 级均值（95% CI）为：0.01 半径 +0.62 pp（-0.38, +1.62），0.025 半径 +1.22 pp（-0.70, +3.15），0.05 半径 +1.35 pp（-0.80, +3.51）。配对比较 0.025−0.05 为 -0.13 pp（-0.40, +0.14）；0.01−0.05 为 -0.74 pp（-1.89, +0.42）。结果不足以选出一个可靠优于其他半径的设置。

本轮 0 dB 的五个 seed 恰好没有 Reward 接受后的有害 BER 更新，但前一批 seed 的 0 dB / 0.05 半径仍出现过被 Reward 接受的 -13.7 pp 退化。因此不能把本轮 0 dB 的零有害接受解释为安全性已经解决。15 dB 三个半径都接受了一条轻微有害更新，说明单纯缩小步幅也没有完全消除风险。

## 下一步需要对齐的事项

当前固定 checkpoint 上的 Pilot-only 梯度更新已经检查了不同 Adapt 目标、PEFT 参数范围、Reward 长度和更新半径，仍没有通过多 seed / 多 SNR 的稳定增益门槛。更直接对应研究目标的下一条路线，是离线构造“Pilot 更新后在后续 Data 上表现更好”的训练任务，得到一份 PEFT-friendly checkpoint；随后在线仍严格只用 Adapt Pilot 更新参数、Reward Pilot 验收，Data 不进入在线决策。

这会改变此前“离线 checkpoint 保持不变”的实验约束，所以本报告只记录为待对齐方向，没有启动新 checkpoint 训练。现有 checkpoint 应继续作为 Frozen 基线保存。
