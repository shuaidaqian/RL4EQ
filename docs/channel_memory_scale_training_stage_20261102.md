## Frozen与数值审计

训练审计确认旧权重完全相同、记忆为零，零残差结构保证相同输入条件下未更新输出相同。独立实验160个配对上下文的接收波形SHA、Frozen BER与真实年龄完全一致，参数起点、跨帧累计范数连续、半径.8内、在线标签隔离检查通过。

原始运行的64个上下文Frozen BCE有微小差异，最大 **2.6822×10⁻⁷**，不能把该字段写成逐浮点完全相同。额外GPU重放中：20个训练上下文在相同输入/条件下两模型CIR与logits均逐项相同；另在99001/0 dB的一条1031帧轨迹上，对1023–1030帧执行候选替换再恢复，前后Frozen及两模型logits也全部逐项相同，未发现参数污染。重复构造20个训练条件亦无差异。原运行未记录完整condition指纹，因此没有把微差武断归因于某一算子，原始记录保持不变。

BER结论来自完全相同的Frozen判决；没有靠Frozen退化制造增益。后续机制运行应直接复用同一收到的上下文，进一步排除重复轨迹/条件构造的数值差异。
