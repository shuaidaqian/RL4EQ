# 神经符号 head 的安全半径内作用幅度检查

本计划在短窗首轮结果之后提出，属于同批开发样本的后续诊断，不是独立确认。
首轮 48 上下文中实际参数增量最大约 0.002064，只有既定安全半径 0.05 的
4.13%。因此零 BER 改变还不能区分候选方向不足与当前一步作用太弱。

在读取新幅度输出前固定：

- 复用短窗首轮的 source、seed=47000–47002、每条 4 帧、四 SNR、四任务组合。
  三档结果仍然只算 48 个独立上下文，不累计为三批证据。
- 保留已有 lr=5e-4 为参考；新增 lr=5e-3、2e-2 两档，各一步。
- 所有候选仍由 Adapt BCE 产生，增量投影半径统一为 0.05；验收代价和阈值不变。
- 仅评估已有神经 head，不添加自由物理系数，不用 Data 梯度寻找方向。
- 输出相对同 Frozen 的候选/验收后 BER、实际增量范数及修复/引入错误。
- 不按每帧 Data 指标选择动作，不把最优 Data 候选组成方法；所有固定设置完整报告。
- 如有跨四 SNR 的可重复候选收益，再冻结独立验证；若没有则停止同方向的
  学习率扩张。不能超过半径或改验收规则来追逐正区间。

首轮实际半径不足是进行该诊断的具体依据；这不是把调学习率当作完整研究路径。
即使某档有效，也仍需匹配离线训练、正式 RL、累计收益和传统主比较。
