# 数百秒会话条件下的固定动作可修正性诊断

用户选择的是持续跟踪、数百秒会话。已完成的连续机制只有 128 帧（13.1072 秒），
相干时间仍为 1200 秒。跨帧外层目标没有通过短会话门槛，但这不足以判断数百秒
状态误差是否给出不同的适配机会。本轮只诊断这一条件，不把主信道改快、不改
成功标准、不把年龄外推冒充经过对应分布训练。

- 固定最新 future B256，SHA
  `751eaa8278cfaf32982f5371df842f9f4fdce0ab83dda5c19c6891dd88ea336e`。
- 新 offline_train 91000–91002、四 SNR；生成 4096 帧连续物理轨迹，只评分帧龄
  0/127/1023/2047/4095，即首帧与约 13/105/210/419 秒附近，共 60 上下文。
  不执行 4096 次神经更新，不生成连续在线主结果。
- 唯一候选为 medium：.02、3 步、半径 .2、likelihood。每个评分帧从相同离线
  参数生成候选，原 Reward guard 不变，不依据 Data 选择动作或追加档位。
- 报告每个 SNR×年龄的 Frozen BER、候选改善、guard 后改善、接受数、实际 CIR
  步长；按 seed 配对。必须同时展示早晚，不只展示最长年龄。
- 如出现特定年龄的正向证据，后续需在该年龄范围匹配离线训练与连续参数保留，
  再注册独立持续实验；如仍无收益，不能只靠延长会话宣布解决。
- 当前 checkpoint 离线最大评分年龄仅 135，因此后期结果明确为年龄外推。
  本轮不是正式 RL、不是数百秒完整验收、没有传统 baseline 主比较。

实现复用已有幅度审计入口，新增显式 `--ages` 与 `--actions`，默认旧协议不变。
记录总诊断耗时，不冒充生产延迟。GPU 实验串行，数据标签只在候选和验收之后评分。
