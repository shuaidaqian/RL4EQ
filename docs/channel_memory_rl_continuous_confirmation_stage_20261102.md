# 210 秒独立连续会话复核：后期收益复现，全程门槛未通过

本阶段按[固定复核计划](channel_memory_rl_continuous_confirmation_plan_20261102.md)运行三个未参与离线训练、动作尺度训练或传统校准的 `heldout_edge` 信道。每个会话 2048 帧、209.7152 秒，10 dB，开始 acquisition 一次，后续每帧使用 prefix Pilot；所有方法只接收当前整帧，没有读取下一帧样本。固定 checkpoint SHA256 为 `153ccc68515fe77996f822924f0056d25a283ca0fd7b185c19a030bfe2871f08`。

机器可读结果见[配对统计](results/channel_memory_rl_continuous_confirmation_3s2048f_10db_20261102.json)与[纯 Pilot 窗口记账](results/channel_memory_rl_continuous_confirmation_reward_accounting_20261102.json)。原始 JSONL 共 12288 行，按帧配对校验通过，Frozen/RL 每个配对接收波形 SHA 相同；数据标签隔离、prefix 布局和连续物理帧龄检查均通过。三个 seed 是 `60030–60032`，对应实际环境 seed `110030–110032`。完整进程墙钟为 3391.55 秒（56.5 分钟），包含初始化、两方法处理、评估和写入；不是在线每帧时延。

## 预设门槛

正改善表示 RL 的 BER 低于同轨迹独立 Frozen。区间按三个独立会话的配对差值计算。

|指标|均值|95% 区间|判定|
|---|---:|---:|---|
|全程 Frozen−RL BER|0.13875 pp|[-0.02417, 0.30167] pp|未通过，全程收益不确定|
|后 682 帧改善减前 682 帧改善|0.28059 pp|[0.17252, 0.38866] pp|通过，后期优势更明显|

四个连续 512 帧分段的 Frozen−RL 改善依次为 `-0.01195 pp`、`+0.08392 pp`、`+0.17014 pp`、`+0.31289 pp`；最后一段的区间在正侧，但它不能替代全程门槛。按预注册规则，两项都需通过才扩展到四 SNR、数百秒主比较。因此本阶段**未达到登记主矩阵条件，也未完成研究目标**。

## 在线控制审计

正式 RL 完成 192 次 PPO 更新，768 个窗口中 424 个窗口 Reward 为正、32 个窗口触发回滚。纯 Pilot 重建还发现 7 个窗口在扣除既定动作成本后，正的 Pilot utility 不再对应正 Reward。动作帧统计、累计记忆范数和完整 Pilot-only reward 重建均留在机器结果中。最大保留轨迹 PEFT 范数为 `0.80000013`，符合 0.8 信赖域的 float32 容差。正 Pilot Reward 窗口只说明控制代理目标改善，不证明 Data BER 必然改善。

## 下一阶段

全程收益未过门槛，因此不把它包装成成功，也不通过追加同协议 seed 追显著性。下一步先按[跨帧接收协议](channel_memory_rl_cross_frame_observation_plan_20261102.md)建立所有方法共同使用的 116 样本后缀观测，并做小规模信息边界与算子等价性验证。只有跨帧窗口的输入、在线标签隔离和配对条件都可审计后，才跑机制试验；其结果仍需与传统非神经、非 RL baseline 比较，最终目标标准不变。
