## 1. 已确认的目标与边界

**研究目标：离线适应信道，在线持续均衡。** 更具体地说，在具有 EME 物理依据的长记忆、慢变链路中，离线学习可复用的均衡能力，在线利用合法观测改善对当前会话的认识，使这种信息积累转化为可重复的接收收益。

用户已确认以下边界：

1. 目标落在接收功能和可验证收益上。在线神经参数更新是候选手段；神经权重冻结也可以满足目标。
2. 四个 SNR（0/5/10/15 dB）均追求：饱和前 Online 自身期望 Data BER 下降，同时相对同源 acquisition-Frozen 的期望 BER 优势扩大；饱和后在预先规定的容差内保持。
3. 增长针对独立会话总体的期望表现，允许单帧、单会话随机波动。允许前几帧快速达到饱和，不要求人为拉长增长阶段。
4. 从 acquisition 后的实际 Data 接收开始完整报告，窗口、增长区间、饱和与保持判据事先确定。必要时新协议的观察长度可以超过 128 帧。
5. 衔接第一研究点，通过明确的等效过程聚焦均衡问题；边界条件由物理映射与前期诊断选择。
6. 允许重新设计离线训练和重训。当前 checkpoint 是证据锚点，不是最终模型的固定上限。
7. 允许当前 Adapt Pilot 更新物理状态后再解码当前 Data；新时序与旧跨帧时序分别验证。
8. 先建立匹配的递归 Pilot-only 对照，soft Data 按独立增量与反馈风险决定是否采用。
9. 优先验证离线训练与在线递归的协同；采用贝叶斯更新本身不足以预先确立创新性。
10. 最终主验证采用接收机有明确获取途径的噪声功率。精确仿真噪声作为理想参照；当前阶段不以采集实测噪声为前置条件。
11. 先证明合法信息下的算法收益并报告成本；实时实现另设硬件、吞吐和时延要求。

上述内容是研究目标，不是已完成结论。尤其是“四 SNR 自身改善、优势扩大、饱和与保持”仍需新证据。

## 2. 从接收问题推导方法需求

### 2.1 需要估计的量与需要恢复的量

在块内 CIR 近似不变的等效模型下，可写为：

\[
\mathbf y_b=\mathbf D(\phi_b,\nu_b)
\bigl[\mathbf H(\mathbf h_b)\mathbf x_b
+\mathbf T(\mathbf h_b)\mathbf x_{b-1,\mathrm{tail}}\bigr]
+\mathbf n_b+\mathbf e_b.
\]

这里，Data 符号是待恢复量；CIR、残余同步量、前帧 tail 和噪声统计是影响恢复的未知量；\(\mathbf e_b\) 表示未被当前等效模型解释的误差。Adapt Pilot 提供已知发送符号，Data 提供带不确定性的间接信息。

离线学习应获得跨会话可复用的接收规律；在线估计应处理当前会话的具体状态。将两者拆开有助于控制计算量，但二者的误差分布必须衔接。

### 2.2 增长至饱和需要什么条件

新增帧只有包含可复用的有效信息，才可能改善后续接收。需要验证完整链条：

> 新增合法观测 → 可辨识状态的不确定性或偏差下降 → 均衡条件改善 → Online BER 下降 → 相对 Frozen 的优势扩大 → 新增收益足够小并保持。

这条链可能被信道变化、软反馈偏差、模型失配或均衡器对条件误差不敏感所打断。滤波器内部协方差收缩不能单独证明这条链成立；信道 NMSE 更低也不保证固定网络 BER 必然更低。

稳态跟踪会在旧信息失效与新信息进入之间形成平衡。研究结论必须限定物理条件和观察时域，不能承诺任意时变信道、无限运行时间或每个噪声实现下的单调改善。

### 2.3 两种改善分别检验

设 \(F_{s,k}\)、\(O_{s,k}\) 分别为 SNR \(s\)、窗口 \(k\) 的跨会话期望 BER，\(G_{s,k}=F_{s,k}-O_{s,k}\)。则：

\[
G_{s,k+1}-G_{s,k}
=(F_{s,k+1}-F_{s,k})-(O_{s,k+1}-O_{s,k}).
\]

Frozen 退化可以使优势扩大，即使 Online 没有变好。因此需同时报告 \(F\)、\(O\)、\(G\)，并分别验证 Online 自身改善和相对优势增长。

### 2.4 在线信息契约

主接收链路只使用已经接收的波形、Adapt Pilot 已知符号、模型 soft 输出和由这些信息获得的状态及噪声估计。Reward Pilot 只用于动作后验收，不进入 CIR、同步、估噪或内循环更新；若没有候选动作，不必为它额外制造门控。

Data 标签只用于离线训练和事后评分；真实 CIR/相位/CFO 只用于隔离的诊断，未来帧标签不能进入接收链路。精确噪声参数仅在明确标注的理想参照臂或事后估计器评价中使用。离线训练的完整监督不扩大部署时的输入权限。

| 资源开销 | 每帧 Pilot 25%，另有 acquisition 与已知启动序列 | 保留 Data BER 主指标，同时报告启动、导频和吞吐开销 |

### 3.2 原建议文档中需要纠正的表述

1. 随机游走本身具有时间相关性；真正需要检验的是其状态转移与创新协方差是否匹配物理演化。
2. 最大时延 116 不等于 116 维 CIR，包含零时延后为 117 个复数 tap。
3. 允许整块接收后输出时，同帧迭代重解码可以是合法块处理；它与旧跨帧协议不同，需单独计时与归因。
4. 当前已经用估计 CIR 训练，不能把“训练中接触估计误差”当作尚未存在的机制。
5. 模型低置信符号降权不等于错误符号自动降权。
6. 协方差收缩、复标量对齐 NMSE 下降，均不足以证明完整物理状态恢复或后验已校准。

## 4. 第一研究点到均衡问题的物理映射

第一研究点的 Git 归档论文包含路径损耗与阴影衰落、准镜面/漫散射多径、轨道多普勒等分析，并指出毫秒级时延扩展构成均衡困难。当前工作区相关论文文件已有删除，本轮只读归档，未恢复。

当前 EME-inspired 生成器不能直接称为第一研究点整套模型的复用。首先建立下表，缺乏直接依据的项明确标注为建模假设。

| 物理内容 | 需要落实的映射 | 对均衡研究的处理 |
|---|---|---|
| 时延与功率分布 | 连续时延/PDP → 采样、滤波后的离散 CIR | 解释 11.6 ms、116 符号记忆和不同采样域的关系 |
| 发送波形 | 扩频、信息符号率、码片率、采样率与脉冲形状 | 明确均衡发生在哪个处理域，避免混用信息符号和码片 |
| 路径损耗与阴影 | 接收增益、AGC 或归一化规则 | 明确消除的幅度效应及其对噪声尺度的同步变换 |
| 多普勒与相位 | 可预测运动频偏、残余 CFO、相位随机扰动 | 解释 acquisition 补偿后剩余状态，避免重复解释公共相位 |
| 时间相关性 | 物理时间 → 帧间相关与创新统计 | 核查 1200 秒相干时间和过程噪声的来源及范围 |
| 长记忆边界 | 过去符号与完整卷积响应 → tail/观测窗口 | 检查帧首前史与帧尾迟到响应的接收损失 |

当前一符号一采样、整数 tap、帧内固定 CIR 是算法抽象。分数时延、定时误差、帧内选择性多普勒等是否需要额外验证，应由物理映射决定。历史雷达包络仅提供约束，不能写成目标频段的精确实测 PDP。

当前冻结的 1024 符号、116 记忆、Pilot 256（224/32）和四 SNR 保持。边界验证若涉及其他模型条件，应单列协议与适用范围，不能回填旧确认。

## 5. 推荐接收架构与匹配对照

### 5.1 新候选时序

1. 从 acquisition 构造合法的 CIR 初始估计、初始不确定性、噪声估计与已知初始 tail。
2. 将历史状态预测到当前帧。
3. 用当前 Adapt Pilot 更新物理状态；同一批 Pilot 观测在递归似然中只计入一次。
4. 使用冻结神经均衡器解码当前 Data，输出 soft 信息。
5. 按统一规则递推下一帧 soft-tail。
6. 可选：用通过可靠性诊断的 soft Data 更新物理状态，供后续帧使用。

当前 Pilot 先更新再解码与多轮 Data 同帧重解码分开研究。前者可采用一次神经前向；后者必须计入全部重解码成本。原跨帧算法保留为时序锚点。

### 5.2 四个核心接收臂

| 臂 | CIR 状态规则 | 归因问题 |
|---|---|---|
| A 固定 acquisition | CIR 保持初始值，仍使用匹配的合法相位与 tail 处理 | 在线方法相对初始 CIR 的整体价值 |
| B 当前 Pilot、无 CIR 历史积累 | 每帧从同一 acquisition 先验出发，只用本帧 Adapt 更新后解码 | 当前 Pilot 的即时价值 |
| C 递归 Pilot-only | 历史预测 → 当前 Adapt 更新 → 解码 | 跨帧信息积累相对 B 的增量 |
| D 递归 Pilot＋soft Data | C 的流程后增加 Data soft 更新供后续帧使用 | soft Data 相对 C 的增量 |

所有臂神经权重在线冻结；每次匹配比较使用同一 checkpoint、同波形、同 acquisition、同 Pilot 预算和同噪声获取条件。公平匹配信息边界与资源报告，保留算法本身应有的更新差异。

四臂均保留实际需要的 tail 递推，规则相同但模型输出可能不同。由此产生的 tail 差异属于闭环方法效应；若需隔离纯 CIR 中介作用，可另做共享合法 tail 来源的诊断，不能使用真实 Data tail。

新增时序的首个 Data 帧已经可能利用当前 Pilot 形成增益。不得用“初始 CIR 相同”虚构一个已经测得的零 BER 增益起点。若首次实际评分已饱和，只能报告即时改善和保持，跨帧增长仍需可观测证据。

### 5.3 状态复杂度按诊断增加

先以可解释的 CIR 递归为基础，核查有效增益与公共相位的定义。若保留单位范数 CIR，需要明确独立增益及噪声尺度；若估计未归一化有效 CIR，则需一致处理其协方差与同步参数。

公共相位与 CIR 复相位可能存在不可辨识自由度，联合估计前先固定参考约定。只有在残差与接收损失表明有必要时，才增加递归 CFO、复杂相位状态、结构化过程噪声或低秩状态表示。

## 6. 合法噪声估计方案

### 6.1 当前可用信息

仿真产生独立复 AWGN，\(\sigma_n^2=\mathbb E|n|^2\)，实部与虚部各占一半功率。接收机估计的是这个统计强度，无须恢复每个噪声样本。

现有 acquisition 为 1024 个全已知符号。沿当前保守规则丢弃前 116 行，可构造 908×117 设计矩阵。已知 acquisition warmup 理论上也可利用，但初期沿用现有 clean rows，避免增加边界处理差异。普通 Data 帧的真实 tail 不能读取。

### 6.2 基础估计与适用条件

固定且正确的同步补偿、完整线性信道模型、独立同方差复 AWGN、未归一化且无 ridge 的普通 LS 下：

\[
\widehat{\sigma_n^2}
=\frac{\|\mathbf y-\mathbf X\widehat{\mathbf h}_{\mathrm{LS}}\|^2}
{N-\operatorname{rank}(\mathbf X)}.
\]

若 \(N=908\)、秩为 117，则分母为 791。秩应实际检查；复残差已经表示复功率，不再除以 2。初始普通 LS 不要求已知噪声功率，可先拟合与估噪，再构造初始协方差。

当前 CFO 由同一批 acquisition 数据搜索、存在相位随机扰动，故不能直接宣称上述公式严格无偏，也不能机械扣一个自由度修正。需检查同步拟合、正则化、信道失配和估计功率尺度。残差在 CIR 强制归一化前计算。

每帧 108×117 的 Adapt 设计不能直接用无约束全 tap LS 残差估噪。未来若在线更新噪声，应考虑状态预测不确定性及模型失配；初期四臂共享 acquisition 噪声估计，先隔离 CIR 机制。

已有 `HybridCIREstimator._estimate_noise` 只计算残差均方，缺少自由度与前史等处理，不能直接视为当前主路径的合格估噪器。

### 6.3 验证与用途

- 在新开发数据上比较估计功率与生成器真值，报告偏差、离散程度及接收性能损失；真值仅用于事后诊断。
- 若残差混合了未建模相位等误差，明确称有效扰动功率，并检验其作为正则化/更新权重是否合适。
- 接收波形缩放时，噪声功率按同一幅度平方尺度变换。
- 主验证使用合法估计；精确噪声作为理想参照。离线训练也覆盖估噪误差，避免训练和评估条件失配。
- 接入估计噪声时，统一检查神经条件、物理 warm start、初始协方差、各后验和传统接收机的全部输入路径，避免只改一个模块而其余模块继续使用设定 SNR。
- 当前不增加静默采样、额外 Pilot 或实测采集前置要求；实测时可通过训练序列、无信号时段或硬件标定获取统计量，并报告开销。

## 7. 离线学习如何与在线递归协同

### 7.1 先做两种训练方式的可归因比较

参照训练围绕 acquisition 条件；候选闭环训练按实际在线时序生成 CIR 条件、估噪结果和模型自身 soft-tail，覆盖初始化、过渡和稳态。

在每个 checkpoint 内匹配 A/B/C/D；再比较不同训练方式的接收性能。控制训练数据、计算预算和选择规则，并用独立训练重复评估训练随机性，避免把单次初始化差异当作策略收益。离线监督可以使用 Data 标签，推理输入始终遵守在线信息边界。无需一开始对完整滤波流程长序列反向传播，可先用真实流程产生的状态训练，再判断是否需要截断展开或其他优化。

### 7.2 需要证明的协同关系

若闭环训练提升所有接收臂，首先证明的是更好的离线模型。若递归臂相对非递归臂的增量进一步提高，才出现离线训练增强在线信息利用的证据。应报告交互差，例如：

\[
I=(\mathrm{BER}_{B,\mathrm{闭环}}-\mathrm{BER}_{C,\mathrm{闭环}})
-(\mathrm{BER}_{B,\mathrm{参照}}-\mathrm{BER}_{C,\mathrm{参照}}).
\]

这一交互只是一个可检验指标，不预设必为正；最终贡献按实际证据表述。

### 7.3 soft 信息与后验校准

先诊断模型 soft 可靠性，再考虑温度校准、信息缩放、阻尼或鲁棒观测模型。校准参数在独立开发/验证集固定，测试期不读取 Data 标签或真实 SNR。

检查高置信错误、更新前后状态偏差与下一帧接收变化。当前近似忽略符号及卷积行相关性、同步与 CIR 联合不确定性；需要用适当创新统计、覆盖率等验证协方差解释。若状态带归一化约束，校准诊断需在相应坐标与自由度下进行。

将协方差信息输入网络属于候选增强，先验证它是否可靠且有独立价值。若加入更多表示、层数或参数，要求额外增量与成本证据。

## 8. 增长、饱和与保持的未来确认框架

以下是需要在新开发阶段数值化并冻结的框架，不是已经冻结的新确认协议。

### 8.1 观测与统计单位

- 独立会话为统计单位；会话内按事先定义窗口汇总，配对保留全部时间相关性。
- 同时报告实际首帧/早期细窗口、固定后续窗口、各臂自身 BER 和配对增益。累计曲线仅辅助展示。
- 使用独立开发数据选择窗口、观察长度、最小实质改善、非下降容差、饱和容差及保持时长，随后冻结。
- 四 SNR 分别验证；不能用等权平均掩盖某一 SNR 未满足目标。

### 8.2 三类证据分别给出

| 主张 | 所需证据 | 不足以替代的现象 |
|---|---|---|
| 自身改善 | 早期到收敛期 Online BER 下降超过预设实质阈值，且中间偏离符合预设约束 | 仅相对 Frozen 优势扩大 |
| 优势增长 | 配对增益实质增加，饱和前的整条曲线符合预设非下降约束 | 仅首末点为正或整体斜率为正 |
| 饱和与保持 | 预定晚窗间 O 与 G 的变化落入预设等价容差，并维持足够时长与正向收益 | 差异检验不显著、区间重叠或曲线视觉平坦 |

目标层面的期望非下降与有限样本可证明的精度应区分。统计确认应给出同时置信界或其他预先指定的形状检验；若采用容差，必须明确数值，不能把明显反弹包装成随机波动。

仅计算正线性斜率不证明逐窗非下降；等序拟合只能作为估计/辅助分析，不能通过强行拟合单调曲线制造证据。饱和起点不能在确认数据上自由搜索后按固定起点报告；应在开发阶段固定，或使用预注册并校正选择的程序。

若 Frozen 在晚段继续退化，Online 保持而 G 继续扩大，则自身可能已稳态、相对优势尚未饱和。两者分别报告，不能宣称共同饱和。

### 8.3 样本量与一次性确认

先用新开发数据估计会话级方差及时间相关性，依据预设最小效应和精度确定会话数、长度及检验能力；不能直接把 10×128 当作必然足够。15 dB 尤其需要报告错误数与不确定性，避免少量净错误驱动结论。

采用事先确定的配对会话统计、跨 SNR/主张的多重性控制和固定停止规则。饱和属于等价精度问题，需为容差配置样本量。观察范围内未到饱和或精度不足时，如实报告未证实；确认后不得看到曲线再延长、换窗、调参或换 seed。

所有已有结果出现过的 seed 均视为已使用，包括根规范列出的范围以及后续开发归档中的 seed。分配新 seed 前建立机器可核查登记表并检查重叠，本轮不预先分配新号段。

## 9. 分阶段工作、产出与停止条件

| 阶段 | 工作 | 产出 | 继续条件与停止条件 |
|---|---|---|---|
| P0 物理与信息定义 | 完成物理映射；定义 CIR 幅相/增益约定、噪声尺度、接收视图和时序 | 等效模型、信息流、来源与假设表 | 关键参数无依据则标假设并限缩结论；存在标签/真值越界先修复 |
| P1 接收基础与噪声 | acquisition 合法估噪；构建 A/B/C，保留旧时序锚点 | 估噪诊断、匹配接收臂、早期与后期曲线 | 估噪失配显著则先修正；C 不优于 B 时先查可辨识性，不直接扩大样本 |
| P2 递归机制 | 检查初始误差修正、状态创新、Q/持久化和幅相尺度；加入 D | Pilot 积累与 soft Data 的独立贡献 | D 无独立增量或风险过大则不升级；无需同时叠加多个复杂修正 |
| P3 离线闭环协同 | 对齐训练条件，按预算重训，验证物理支路与神经修正的贡献 | 参照/闭环训练及其交互证据 | 更低 NMSE 无 BER 改善时定位网络接口；协同不成立则收紧创新表述 |
| P4 边界与长会话 | 按物理依据选少量边界，固定早期分辨率和足够时域 | 适用范围、增长/饱和/保持候选判据、功效分析 | 达不到精度则调整新开发设计；不选择性删除不利 SNR/会话 |
| P5 新独立确认 | 冻结模型、代码、协议和统计方法，使用全新 seed | 四 SNR 完整确认报告及失败记录 | 任一核心主张不满足则按协议报告；禁止在同一确认集上修方法 |
| P6 实现优化 | 复用前向与 tail，随后按证据压缩/蒸馏/优化 | 成本—精度曲线、明确硬件下的时延与吞吐 | 按新实现重新验证；不能用同帧多轮精度搭配单次前向成本 |

阶段按问题推进，不一次性展开全部训练方式、接收臂、Q、层数、校准和边界的笛卡尔积。先用最小可归因开发实验识别有价值因素，再冻结候选方案。

低成本数值错误和信息边界问题使用定向测试；方法收益使用新实验验证。文档整理本身不触发旧确认重跑。

## 10. 论文贡献与系统报告

### 10.1 贡献按证据逐层建立

1. 具有第一研究点依据的 EME 均衡等效问题与物理适用条件。
2. 合法观测下的递归信息积累及其相对当前 Pilot、初始 CIR 的价值。
3. 若成立：离线闭环训练使网络更好地利用递归状态估计，形成可归因协同。
4. 若成立：可靠 soft Data 为递归估计提供额外信息，并在低 SNR 控制反馈风险。
5. 四 SNR 增长至饱和及保持的独立证据与成本边界。

上述均为候选贡献。若 Pilot-only 已满足目标，soft Data 可以不进入最终主方法；若协同未成立，不能把组合结构描述成已经证实的新协同机制。仅添加贝叶斯模块或在弱传统实现上获胜，不能自动证明充分创新。

### 10.2 报告应包含

- Data BER：绝对值、相对值、错误数、会话间差异与配对区间。
- 时间行为：完整 O/F/G 曲线、早期收敛、增长区间、饱和与保持，以及失败会话。
- 状态诊断：明确尺度的 CIR 误差、复标量对齐与未对齐指标、同步残差、soft 校准及后验可靠性。
- 信息预算：Adapt/Reward/Data 角色，acquisition/启动开销、前史与观察窗口。
- 成本：同步计时的每帧均值与分位数、前向次数、状态更新时间、显存和硬件；吞吐与端到端延迟分开。
- 传统接收机：匹配初始化和同步条件，在独立开发集调校并冻结；SC-FDE 未补偿时只作弱对照。
- 可复现性：源码版本、环境、数据生成与训练 seed、配置和 checkpoint 指纹、原始逐帧记录及种子登记。

已有[训练复现工程](results/reproducible_training_v1_20261111/README.md)提供当前锁定环境下的指标级重放证据，应复用其记录规范；它不等于补齐历史原运行的全部来源，也不等于新方法确认。

## 11. 当前最合适的执行顺序

**先完成物理映射、状态尺度与合法估噪，再建立当前 Pilot 与递归 Pilot-only 的匹配对照；定位信息积累确实能够改善接收的条件后，开展闭环离线重训，最后决定 soft Data 和更复杂状态是否必要。**

这一顺序保留已有成果，也能尽早发现目标链条在哪一环中断。当前阶段不优先恢复在线 LoRA/RL、不预设更深 Transformer、不靠削弱 acquisition 或选择窗口制造增长。

本轮已完成目标澄清、只读审查和路线整理。新算法、重训、开发实验和新独立确认尚未执行。
