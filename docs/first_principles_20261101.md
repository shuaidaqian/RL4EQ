# 从基本事实重建“离线适应信道、在线微调均衡”

## 已确认的事实，以及人为规定的研究边界

信道观测可以写为 `y = D(phi) (H(h)x + b(h, tail)) + n`。这里的 H 是有限
观测窗内的线性卷积，b 是前帧尾部贡献；没有 CP 时，不能直接把 H 当作同帧
循环卷积。知道 CIR 不等于知道 CFO、慢相位或前帧未知符号，仍需单独处理。

接收机只能根据可见信息更新。如果两个真实状态在前缀 Pilot 上产生几乎相同的
观测，却在后续 Data 上不同，任何仅看该前缀的控制器都不能可靠区分它们。
增加 RL 训练步数不能增加观测中原本没有的信息。前缀之后新出现的随机相位
创新也不能由前缀无误预测；这是信息边界，不是更换优化器即可消除的误差。

降低 Pilot loss 只说明在 Pilot 上改善。它不推出 Data loss 下降，更不推出
Data BER 下降：只有足够多的判决跨越零点且修复错误多于引入错误，BER 才会降低。
参数变化、更新接受率、梯度非零和连续损失下降，均不能替代这个判据。

当前项目规定的 Level B、0/5/10/15 dB、prefix、整帧非因果接收、离散安全 RL
调制 PEFT，是研究契约；它们不是自然规律，但本轮工作必须遵守。Data 标签
只用于离线监督、离线校准和事后仿真评估。历史配置及尚未切换的正式控制路径
还主动隔离 Data 波形，使 Adapt 更新与 Reward 验收只依赖各自可见的 Pilot 视图。
这是实现额外施加的输入限制，不能自动推出它是物理必需或用户明确禁止的边界。
整帧已接收波形、未知发送符号与 Data 标签必须区分。
用户现已明确允许在线读取整帧接收波形，保持未知发送符号和 Data 标签隔离。
因此后续新增的匹配训练配置可采用 full_rx；旧配置保留原协议以复现历史结果。

## 习惯上容易接受、但仍需验证的假设

1. “离线整帧 BER 很好，在线就容易适配。”更新前准确性和更新后泛化能力
   是不同性质；当前 checkpoint 不自动具备后者。
2. “把动作交给 PPO，就会比固定动作更好。”先要有可重复的有益动作，以及
   能区分动作后果的合法反馈；否则策略只是在噪声中选择。
3. “更大的 head/LoRA 更新可以修复物理失配。”只有更新确实影响了主误差方向，
   并且该方向能由 Pilot 估计时才成立。输出支路尺度和输入视图差异也会限制它。
4. “加一个更新后 Data 离线目标就足够。”三轮固定预算实验尚未支持这个假设。
   若以后有正结果，还需排除单纯增加 Data 权重和继续训练带来的收益。
5. “长信道应使用更长的传统滤波器。”更长可以增加表达能力，也会增加有限
   Pilot 下的估计方差；长度和正则必须一起在独立校准集上选择。
   DFE 的后续 36 项先验/遗忘因子网格仍在训练范围选中短 DFE，但所选设置的
   留出改善区间均跨零，不能把训练选优直接当作更强的泛化基线。
   之后固定原参数的已知 Adapt 反馈核查，在 48 个新训练范围配对帧上也没有
   改变 Data BER；没有继续用传统网格扩大替代神经候选机制验证。
6. “超过当前传统实现就完成目标。”同步、记忆覆盖和块边界没有合理校准时，
   差距可能来自对照不足。当前已有测试只证明实现，不能代替公平校准。
7. “其余接收位置置零就等于只观察 Pilot。”物理 warm-start 仍使用完整 H^H H，
   而缺失观测应对应 H^H M H；两者一般不同。24 帧训练范围审计已观察到
   Pilot 代理与整帧推理的错误数差异，但尚未证明改变输入范围会改善在线 BER。

## 真正要实现的目标

离线学到一组对信道变化有用的均衡表示；在线用有限 Pilot 更新低维神经参数，
使后续 Data 判决得到可归因、可重复的改善；离散安全 RL 根据 Pilot 状态选择
更新、保持和回滚，随在线帧积累形成更明显的后期优势。

用户已接受的统计验收是：主配置逐配置超过校准后的传统非神经、非 RL baseline；
同 checkpoint Online 相对 Frozen 的改善，在独立 seed 上有区间支持，后期平均
优势比早期更明显。暂不规定固定降幅。BER<0.01 只作辅助指标。

## 现实资源与约束

本机 GTX 1650、4 GB 显存；用户允许持续使用 GPU，按门槛逐阶段推进。模型帧长
1024、记忆 116、prefix Pilot 256，其中 Adapt 224、Reward 32。若历史 tail
不可靠，完全不受前帧未知符号影响的 Adapt 接收区间至多为后 108 个样本；这些
样本也不必是统计独立样本。不能把 Pilot 总数当作所有状态的独立观测数量。

已有同轨迹接收波形校验、严格标签隔离、seed 级配对区间、可微内循环与真实
PPO 更新数值对照。FFT 加快的是同一线性算子的计算，不改变信道假设。
当前精确高阶训练使用 float32 和 math attention，以控制数值与显存风险。

## 哪些调整仍只是在修补表面

反复修改 PPO 学习率、Reward 阈值、更新半径或增大候选数量，如果没有先确认
动作影响主误差且 Pilot 反馈能识别该影响，仍只是在既有瓶颈外围试探。它们
可以是必要的工程调节，但本身不能证明在线均衡机制成立。

同理，单纯堆大训练或测试矩阵不能解决方向失配。当前神经 head 在 48 帧训练
范围诊断中仅修复 1 个、引入 2 个 Data 错误；256 步四臂独立测试在 10/15 dB
没有任何在线 BER 变化。继续扩大相同配置不应优先于作用能力诊断。

## 从事实推导的路径、成立前提和第一步

路径按依赖顺序推进：可观测状态 → 能影响该状态造成误差的神经调制 → 离线
训练其 Pilot 更新后的 Data 泛化 → 固定动作验证迁移 → 跨帧累计验证 → PPO
窗口选择及其消融 → 独立确认和校准后的传统主比较。

这条路径需要同时满足：存在离线未充分适应、在线可由 Pilot 辨认的状态变化；
受限神经参数有能力修正相应误差；Pilot 的候选排序可外推到 Data；状态在更新
有效期内足够稳定；在线计算成本和更新方差可控。任何一项失败，都应定位该项，
不能把 RL 作为缺失前提的替代。

当前已完成 head、现有神经 phase 组的作用诊断和固定预算四臂训练；新增离线
目标仍没有可靠额外收益。传统线性校准也已接入统一 compare，同轨迹短比较
没有证明主方法在四 SNR 全部优于校准传统参考，RL BER 与 Frozen 相同。

下一步先确认 Pilot 可观测的主误差与神经调制作用族是否匹配，并在结构偏好
明确后确定是否调整调制位置或输出表示。现有 phase 网络每帧只生成仿射相位
轨迹；它的参数数量不能等同于独立物理修正方向。训练范围梯度诊断又表明，
新外层目标不能简单视作在所有 SNR 下等价于普通 Data 重加权；存在梯度差异
仍未转化为可靠额外收益。两项事实不能混成“新结构一定有效”的结论。
新路径的首次机制筛查仍须与同 checkpoint Frozen 配对，并预先固定测试 seed、
训练预算和失败退出条件。目标未达成之前，阶段性工程成果与科学成功分开报告。

接收输入的后续四组合组件实验已完成 48 个新训练范围上下文：只改变波形范围
没有获得可靠 BER 增量，15 dB 的整帧 Reward 在 12 帧中全部正确且 BCE 约
4.14e-13。输入一致性、候选有效性和反馈可分辨性是三个需要分别满足的前提，
修复其中一项不自动完成另外两项。按计划停止扩大同配置留出矩阵；正式输入
边界已获用户明确答复，现有结构的匹配整帧输入训练已完成。用户随后要求按照
结构调整建议继续推进，因此必要的神经调制重构已纳入授权范围，不再重复询问。

匹配整帧输入的 A/B 各 256 步训练现已完成。新的 5 个留出信道 seed 上，0 dB
两分支相对各自 Frozen 均有正向区间，但 B Online 比普通监督 A Online 更差，
差值区间也支持该方向；5/10 dB 收益仍不确定，15 dB 无更新接受。匹配输入是
可审计的实现改进，新增外层目标仍没有显示额外价值。不能继续默认更多此类
训练就会满足四 SNR 门槛；下一步定位误差来源与调制作用范围。

后续冻结错误定位在新训练范围 160 帧中发现：15 dB 的 26 个 Data 错误中
23 个在帧尾 116 个符号；Adapt 错误则全部在前记忆区，Reward 无错误。
这提示 Pilot 与 Data 的主要边界误差可能不同，不能把它简化为同一个相位偏差。
新候选使用有效观测覆盖、符号估计和匹配残差作为小型神经网络输入，离线训练
其表示、在线仅微调输出 head；零初始化和冻结原权重用于检验新增分支的真实
代价，不能用破坏 Frozen 制造适配收益。

符号残差分支随后在同波形留出比较中改善了 5/10 dB 的 Frozen，但在线增量
仍未成立。真实截短 Pilot 接收窗和两档更大安全步长又表明：验收可有响应、
候选也可改变判决，仍不保证改善方向稳定。因此离线表示、匹配的更新任务和
可分辨反馈必须共同验证，不能把其中任何一个工程变化当作目标完成。

匹配短窗内循环后，A/B 各 256 步的四臂独立验证仍未得到四 SNR 在线正向区间。
只读梯度解释显示高 SNR 的 Data 损失梯度主要在帧尾，短窗 Adapt 与尾部方向
没有稳定一致性的证据。不能由此推导所有跨帧适配无效：本轮每帧重置，8 帧仅
0.8192 秒，相干时间则为 1200 秒。下一阶段须明确短包或持续跟踪的实际会话
范围，再验证窗口聚合的统计收益；不得随结果移动后期区间或宣称累计学习成功。
详见[匹配短窗训练与梯度解释](prefix_transfer_stage_20261102.md)。

区间均跨零。参数确实延续且部分帧触及半径边界，不能解释为更新未执行，
也不能由此直接推导应增大半径。下一步应在训练分布分离多帧平均的降噪收益
