# 接收波形置零审计：发现输入失配，尚未证明在线收益

本阶段确认了一个与网络参数数量不同的机制问题：现有适配和验收输入会改变
Pilot 上的检测问题。整帧推理与置零输入不是同一观测模型。这个额外限制来自
当前实现，不能把它与“禁止使用 Data 标签作在线监督”混为一谈。

本轮只进行离线审计，没有改网络、在线输入边界或正式 RL 动作，没有生成
Data 梯度驱动的候选、优化权重或保存新 checkpoint。整体目标仍未完成。

Data BER。0 dB 的 Adapt BER 反而略增，也不能将“整帧输入总是更好”作为事实。

## 为什么置零不等于只观察 Pilot

对移去共同历史项后的线性观测 `r = Hx + n`，M 是接收样本的可见性对角遮罩。
只观察这些样本的线性 MMSE 正规方程为：

```text
(H^H M H + lambda I) x_hat = H^H M r
```

当前物理 warm-start 收到置零后的 M r，但仍使用全帧 H 的正规方程：

```text
(H^H H + lambda I) x_hat_zero = H^H M r
```

两者一般不同。后者仍在约束缺失位置的预测值接近零；它没有对未观察样本作
边缘化。神经注意力也没有因此自动获得正确的“观测缺失”语义。前缀 Pilot 的
长回波还会延伸到后面的接收位置，置零丢弃了其中部分信息。

上述推导依据 `UnfoldedEqualizer._physics_warm_start_logits` 的 H/H^H 路径，
解释当前实现为何可能产生失配；不把线性公式当作完整神经模型的 BER 定理。

## 梯度结论和数值边界

四个 SNR 上，整帧输入并未一致改善 Pilot/Data 梯度对齐；head 和 phase 的
对齐变化方向随 SNR 改变，小样本区间也较宽。因此不能据本诊断直接选出有效
在线动作或声称解决了迁移。

首次输出还暴露了近零梯度问题：15 dB 的整帧 Reward BCE 约为 2.38e-15，
对应 head/phase 梯度均低于数值判读阈值，而置零输入的 Reward BCE 约为
0.14557。用接近零的梯度作分母，会产生巨大的相对比值；余弦也不再代表可靠
方向。脚本因此补记 BER/BCE 和梯度范数，绝对范数不超过 1e-8 时相关方向或
比值记为 null，并显式记录可判读的帧数/seed 数。

这项增补在首次输出之后提出，属于事后数值审计。同样本重算逐帧波形匹配，
原始文件保留；24 帧仍只算一批证据。t 区间未裁剪，可能超出物理取值范围。
Reward 正确且饱和也提示：恢复整帧输入后，Reward 的可分辨信息量仍须单独
检查，不能假定取消遮罩便能解决中高 SNR 的动作排序。

## 实现与下一步

新增 `scripts/diagnose_receiver_visibility.py`，只允许 offline_train，不执行
在线控制或修改权重。测试区分 Data 接收波形和 Data 标签：污染未知发送符号
及 Data 标签，不改变任何 Pilot 梯度；改变 Data 接收波形，可以改变整帧
Pilot 梯度，但置零视图的梯度严格保持不变。另核验基础权重保持、近零方向
判读和留出划分拒绝。定向测试 **24 项通过，6.64 秒**；最终全量回归
**685 passed，243.90 秒**。两者有重叠，不相加。

下一步取决于已提出的信息边界选择，未答复前不修改实际控制器：

1. 若允许整帧已接收波形，则在相同模型中显式区分“输入波形范围”和“监督
   标签范围”，以 Adapt-only 损失生成候选、Reward-only 标签验收；先核验
   标签隔离与候选数值一致，再做新 seed 的组件测试和必要离线训练。
2. 若继续限制只看 Pilot 接收样本，则应把缺失观测遮罩传入物理算子和神经
   输入表示，并用匹配的观测模型训练；仅把其余接收值置零不够。

无论选择哪条路径，都要保留同 checkpoint Frozen、普通监督对照、独立 seed
及原 Level B/Pilot/扰动条件。只有稳定单次迁移成立后，再验证跨帧累计和离散
安全 RL 的窗口选择，最后完成与校准传统 baseline 的逐配置主比较。
