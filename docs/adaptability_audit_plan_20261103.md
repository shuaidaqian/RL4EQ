# 首轮可适配性开发审计：先分清应该修哪一层

## 角色与边界

本计划属于[研究路线v3](research_route_v3_20261103.md)的R1开发阶段，不是正式主实验，不承担最终显著性验收。用户已确认应用主要SNR/误码/吞吐与EME频段/带宽尚未确定，保留为正式确认前必填项。

先用固定开发协议审计已有长回波锚点，同时建立独立的短/中记忆机制协议。短记忆的结果不与长回波混合；新profile和新真状态同源网络诊断目前尚未实现。本文件定义工作内容，不表示审计已运行。

## 1. 第一批范围

- 完整报告0/5/10/15 dB，先同分布新信道。
- 长回波锚点沿用版本固定的`eme_long_memory_v2`：1024符号、记忆116、Adapt224/验证32、116后缀、开始一次acquisition。
- 机制协议使用独立身份，候选记忆8/20符号；先静态CIR加静态同步、再仅CIR漂移、再仅同步失配。记忆与变化时间是两个变量，不把缩短信道等同于减小变化速度。
- 新机制profile必须声明路径/弥散结构、变化的真实维数、归一化和噪声定义；不能沿用旧Level B/EME名义但悄悄改变分布。
- 先控制物理状态误差，再选择神经更新维数；初期不增加非线性、编码或调制阶数。

旧代码的`heldout_edge`同时改变多个因素，不能作为本轮“单因素外推”的替代。需新建同分布开发划分，记录实际生成参数和独立seed；首轮配置清单冻结后才能启动批量生成。

## 2. 同波形分支与各自能回答的问题

|分支|神经权重|物理状态来源|回答的问题|
|---|---|---|---|
|F：正常条件适应Frozen|同源、冻结|现有合法Pilot流程|在现有强基准上还有多少可修正失配？|
|P：结构化状态加Frozen|与F相同、冻结|合法Pilot/历史，明确过程先验与坐标|合法观测能否更好地跟踪状态？|
|N：P加确定性神经微调|同源，明确少量参数更新|与P完全相同|排除物理跟踪后，梯度更新还有何增量？|
|T：隔离真状态诊断|与F相同、冻结|仿真CIR及同步真值，仅诊断可读|在相同网络和观测边界下，状态失配是否主导错误？|

N对P是神经微调增量的主要归因；N对F混合物理跟踪变化时只能作为组合效果。若P与F实际使用相同流程，则合并这两条分支，不能把重复分支当成新证据。

T仍使用未知Data检测，不输入发送Data或真实bit，不使用真实Data tail。真状态与接收波形必须使用一致相位/CFO坐标、相同观测窗与噪声定义。它只判断本接收算法在已知状态时的表现，不是全局最优界。现有`Perfect-CSI Block`与T网络结构不同且未必含完整同步真值，不能直接替代。

真值由独立离线诊断接口提供；可部署F/P/N分支的输入结构不含这些字段。审计要毒化Data符号、比特、真CIR/同步轨迹，逐项证明F/P/N的更新、验收与后续状态不变。

## 3. 先审计可辨识性，再选在线表示

每个帧/历史窗口记录：完全已知卷积行、复数秩、奇异值谱/条件数、噪声与先验对后验不确定性的影响。低维候选额外记录Pilot对神经适配系数的Jacobian有效秩与局部条件数；这些局部诊断不自动证明全局可辨识性。

将物理变化限制在已知的小维数机制时，比较低维系数与旧稠密记忆；不使用稀疏强径数来抹掉20%–35%的弥散能量。若历史让矩阵满秩但Data不泛化，优先查坐标、状态年龄、先验及参数作用，不继续堆Pilot行数。

此阶段不以历史Data结果选择最终rank。开发阶段可筛选预先列出的候选，正式候选必须在独立确认前冻结；报告淘汰过程与所有已观察数据角色。

## 4. 当前帧与未来帧的两种实验

### A. 固定一次候选，测有效期

在明确的物理帧龄生成一次合法Adapt更新；当前验证Pilot决定是否接受。分别保留“原始候选”和“守门后候选”的只读诊断分支，后续不再追加梯度，记录当前及偏移1/8/32/128帧的Pilot连续损失、硬BER与事后Data变化。

未来验证指标只用于开发分析，不反向改变当前接受或参数；未来Data只用于离线评分。不得用未来分支挑当前动作，也不得把从某个长物理年龄开始的固定候选当成从会话开始持续跟踪。

### B. 从会话开始持续更新

参数从同一checkpoint开始，只做一次acquisition，按帧消费合法观测。N逐帧或按预先固定间隔更新并保留状态，P只做相同物理跟踪。完整记录所有帧，包括拒绝、回滚和无更新帧。

开发先用128帧检查机制/数值安全，再按变化时间覆盖较长会话；最终会话长度与漂移/恢复定义需预注册。需要区分全局初始中心、局部信赖域和过程正则，不能同时改变多种保护来解释单个效果。

## 5. 记录、统计与分支判据

至少输出：配置和checkpoint SHA256、profile版本、数据角色、独立seed、物理帧号、当前/后缀接收哈希、Pilot分割、接收端状态来源、神经更新参数名/数目、梯度/参数变化、守门前后指标、拒绝/回滚、当前/后续完整Data BER与成本。

独立信道为统计单位；当前与未来多个horizon是相关诊断，不当成额外seed。开发结果做完整描述与区间，若做多条件推断必须声明探索性质与多重比较方案。不能按结果追加同类seed或选择最好的horizon作为新成功标准。

|观察|下一步|
|---|---|
|T在坐标核验后仍不能明显改善|审查观测边界、模型误差、均衡求解与残差作用能力；不能据一个T失败宣判信道不可解|
|T改善，P不改善|优先合法Pilot信息量、状态结构、历史利用与同步估计|
|P改善，N不稳定或无增量|优先低维神经适配表示、更新目标及离线序列训练|
|N当前有益、后续失效|优先状态有效期、过程/遗忘模型、持续参数约束和未来外层目标|
|确定性N持续有效，旧RL未有效|先完成无RL的独立确认，随后才研究调度|

传统比较在同一资源定义下校准，但不以“传统较弱”筛选开发信道。若N可靠改善而仍不如传统方法，核心增量与应用竞争力分开报告。

## 6. 实施交付与当前待办

1. 冻结开发manifest：同分布生成协议、单因素变体、候选更新、seed集合、样本/计算预算、输出路径与停止规则。此时仍不得冒称正式门槛已冻结。
2. 实现统一F/P/N/T接口与真值隔离、同波形和标签毒化检查；真状态诊断独立于在线入口。
3. 接通确定性共同状态/低维神经更新。不能将旧`online_train.py --method pilot`自动视为已支持，也不能把PPO仅设置为几乎只选一个动作冒充确定性方法。
4. 先做小型机制和长回波锚点审计，交付完整轨迹、有效维数和上述分支判断。
5. 据分支选择一个适配结构，制定匹配序列训练的A/B四臂计划；开发结果用于设计，新的独立确认数据只在预注册后使用。

本轮没有启动这组审计、没有生成新checkpoint、没有新增性能结论。已有持久状态有效期诊断可作为A的一部分复用，但不能取代完整F/P/N/T分解。
