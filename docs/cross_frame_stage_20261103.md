2026-11-03 已把用户确认的 116 样本、11.6 ms 后缀接入真实连续环境、神经均衡、传统接收机、在线 PPO、Pilot 适配和离线适配训练。纯延迟边界样例证明后缀能补回原接收窗完全看不到的帧尾；这不等于在线训练收益。原 checkpoint 的 10 dB、3 seed、128 帧检查没有通过预设收益门槛，不能登记目标完成。

场景保持 Level B，主 SNR 为 0/5/10/15 dB，1024 样本帧、最大时延 116、1200 秒相干时间。Pilot 保持既定前缀 Adapt224/Reward32，开始做一次 acquisition。接收当前帧后等待下一帧前 116 个已收到样本，各方法共享波形。下一帧这 116 个符号完全属于原有 Adapt Pilot，因此其已知符号合法可见；不增加 Pilot，不暴露未来完整帧、Data 符号或标签。Reward Pilot 标签仍只用于动作后的验收、reward 和留出评估。

## 联合观测与实现

后缀满足 `y_next_prefix = H_tail x_current + H_prefix x_next_pilot + noise`。`CrossFrameLinearOperator` 把当前帧和下一帧前缀放在同一连续卷积坐标上；线性去除已知下一帧 Pilot 与历史 tail 的贡献后，对当前帧未知符号求联合观测正规方程。没有把后缀当作孤立尾部测量。全 116 样本后缀使当前每个符号的 tap 能量覆盖完整，残差特征的能量归一化也使用联合观测列能量。

当前帧与后缀的 IQ 校正共用连续时间坐标，CFO 在第 1024 个位置延续，不从后缀零点重新开始。联合求解使用当前估计 CIR；跨帧漂移仍是模型近似，未注入下一帧真实 CIR 补偿该误差。

- 环境预生成并缓存下一帧，但接收视图只返回当前帧及指定长度前缀。顺序波形、噪声、CFO 与缓存推进保持一致。
- `UnfoldedEqualizer` 在物理 warm start 使用后缀，输出仍为当前帧。未增加 checkpoint 参数，严格加载现有权重。
- 普通和冻结校准传统方法均接入同一窗口，只截取当前帧输出、更新当前帧 tail；不把下一帧 Pilot 的判决当成当前历史。
- `online_train.py` 的 Pilot/PPO、比较入口、RLS 适配和连续调制兼容入口均转发后缀。历史 `Continual PPO` 诊断入口明确拒绝后缀，避免错误声称支持。
- PPO 的 `rl_adapt_receiver_input` 显式区分 `adapt_only/full_rx`，默认保留历史协议。BCE 可用整帧接收波形，但只对 Adapt 标签求损失；信道状态信号/MAP 目标仍用专门的 Adapt 方程。实际输入范围写入逐帧日志。
- 离线 `pilot_transfer` 支持相同后缀和可微内循环；真实短 Pilot 窗诊断会清除不相邻的下一帧后缀。新配置用 `receiver_lookahead_len=116`，旧配置默认零。其他离线入口不支持后缀时明确报错。
- 两个配对汇总入口审计后缀长度、版本、帧号和同帧 SHA256，拒绝混合有/无后缀结果及不同后缀波形。`--resume` 同样拒绝接收边界变化。
