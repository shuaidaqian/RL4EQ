# 全 head trajectory 32 步训练与普通监督续训对照

## 实验条件

两臂从同一离线权重出发，在固定 Level B、116 符号长回波、Pilot=256（Adapt=224、Reward=32）与四个 SNR 下训练32步。训练seed、episode/SNR顺序、在线候选更新器、Reward门控、参数范围、轨迹窗口（4帧）与优化预算一致。A为普通监督续训；B为可微全 head trajectory 外层训练。独立开发评估使用新session 76160/76161、每SNR连续16帧；每个 checkpoint 均同波形配对 Frozen 与当前帧 Adapt Adam 在线分支。Data BCE仅在门控及提交完成后离线评分。

收益定义为 Frozen BER − Online BER，正值表示在线改善；晚−早为最后4帧窗减最初4帧窗。

Trajectory相对普通续训的Online−Frozen增量依次为 -2.85e-4、+4.07e-5、0、0。没有稳定优势：0 dB普通续训点估计更好；5 dB差异约为一个误码量级；高SNR BER不变。Trajectory的0 dB两会话收益一负一正。两session区间很宽/退化，不能进行正式统计推断。

两臂的动作后Data BCE都下降，且量级相近（0/5 dB约3.5e-4/2.0e-4）；trajectory训练没有表现出专属的在线适配收益。B臂0 dB晚窗减早窗为负，5 dB也为负，因此不支持收益随帧增长。更多外层步数没有把8步筛查中的不确定点估计转化为稳定BER趋势。

## 判定与后续

停止扩大当前BCE trajectory外层配置。下一项尝试保持线上 Adapt BCE 更新与 Reward门控不变，只把离线外层更新后Data目标从BCE改为平滑BER/边界损失，使离线初始化和表示直接优化硬判决错误附近的变化；仍需与相同预算普通续训对照，并在全新session测试。训练目标下降不能代替Online−Frozen BER证据。

完整逐帧结果、checkpoint、训练指标和配置保存在本目录与 full_head_supervised_train32_v1_20261106。统计单位为session；该开发筛查不构成确认。
