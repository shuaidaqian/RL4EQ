## 结论

1. **物理主张的核心优越性与安全护栏通过**：H1 `p=1.26e-7`；H2 四 SNR 的 Holm 校正 p 均 <0.05，10/10 seed 无负向。
2. **增长假设部分成立**：5/10/15 dB 支持"随帧增长"；0 dB 的增益大且稳定，但早期饱和/波动，按预注册判据不通过。
3. **归因**：增益来自 Bayes CIR 物理状态后验，不是神经参数微调。神经权重两臂冻结；神经子主张未在本次确认中检验。
4. **0 dB 的 H3 不通过不能被四 SNR 平均掩盖**；后续若要把 0 dB 也写成"增长"，需要新的预注册判据或更长/不同窗口定义，不能用本次数据重测。
