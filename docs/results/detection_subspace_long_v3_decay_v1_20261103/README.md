# R2 固定长回波锚点收缩开发归档

本批是 R2 第三轮单因素开发，不是 R3 正式确认。严格复用原 `eme_long_memory_v2` 信道、Pilot、接收窗口、同步和acquisition协议，`channel_changes=false`。本轮只新增固定0.5离线锚点收缩：候选先通过原验证Pilot守门，再将更新系数向会话离线初始系数收缩一半，收缩后的参数仍需通过验证守门。离线B内循环与在线共用规则。

几何审计仍选择4维表示（2/4维合格，8维淘汰），普通监督作用检查通过。A/B训练、选择和评估预算与第二轮相同；评估使用重复开发seed，768条记录只可用于机制对比，不是独立泛化证据。

结果不支持进入R3。B在0 dB的Online相对Frozen增益均值约`+4.07e-5`，95%区间跨零；B相对A交互为负。5 dB的B均值退化约`-2.71e-5`；10/15 dB无有效增益。锚点收缩让B的0 dB有害保留降至0次、5 dB有害保留为2次，但收益没有跨seed稳定复现。在线更新器增量耗时约15.4–16.3 ms/帧，不含接收、acquisition、物理跟踪和完整前向，不能作为端到端实时结论。

只读梯度方向诊断比较动作前4维Adapt BCE与Data BCE梯度：B臂5 dB平均余弦约0.055、正向比例50%；15 dB Adapt梯度范数约`2.6e-6`且中位余弦接近0。0 dB方向较一致（平均余弦约0.51），与其较好的连续Data BCE单步变化相符。Data梯度仅离线事后计算，不输入在线控制。该证据将R2瓶颈进一步定位到中高SNR下Pilot梯度方向弱对齐/幅度接近零。

该机制说明稳定性可以改善而可归因的神经增益仍未建立。核心目标“离线训练适应信道，在线微调均衡”尚未完成。下一步仍属于R2：针对5 dB低对齐和15 dB近零梯度，基于现有Pilot信号模型检查可辨识的损失尺度/归一化及外循环目标能否学出更稳健的子空间；先做信息边界和梯度数值消融，不用Data在线选动作、不扩增同一结构seed、不进入R3/R4/R5/R6。
