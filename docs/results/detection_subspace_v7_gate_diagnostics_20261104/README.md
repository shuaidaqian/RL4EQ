# 第七轮后续诊断：单帧门控、逐符号不确定性与表示可达性

本归档只读复用 v7 的 12 条开发会话和 768 条 A/B 轨迹，不产生新信道样本，不改变在线状态。所有输出均为开发诊断，Data 仅用于动作之后的离线评分；不得据此选择正式效果或把分析门槛部署。

输入绑定 v7 清单 SHA256 `7ad25dead444c063e828a87f40c112595a9d0c9eca30d51d968821ebf12657e3`、来源 checkpoint SHA256 `11e58a5d94801ae613ec8f7a55679ed2304e0864535c7b0468b316827e2bec51` 和 v7 压缩轨迹 SHA256 `d5f9047786fecbb133342376191b6e77e651ac731a84dedc074df861a13c641b`。更新候选通过接收波形指纹和归档验证 BCE 复核后才纳入分析。

## 逐符号配对验证损失

对重建候选，逐个验证 Pilot 符号计算“当前系数 BCE − 候选系数 BCE”，再用循环移动区块 bootstrap 估计长度2/4/8的敏感性。原规则是验证 BCE 至少改善 `1e-5` 且硬 BER 不升。探索两种不部署的替代判据：其一要求 bootstrap 95%下界超过 `1e-5`；其二只要区间上界未证明有害、均值改善且硬 BER 不升就接受。

| SNR | 原规则接受 | 95%下界门控（区块2/4/8） | “未证实有害”门控 | 原规则接受中的 Data BCE 有害比例 | 后者有害比例 |
|---:|---:|---:|---:|---:|---:|
| 0 dB | 30 | 11 / 15 / 19 | 69 | 6.7% | 11.6% |
| 5 dB | 35 | 15 / 14 / 22 | 67 | 40.0% | 35.8% |
| 10 dB | 1 | 0 / 0 / 0 | 16 | 100% | 75.0% |
| 15 dB | 1 | 0 / 0 / 0 | 49 | 100% | 40.8% |

每点只有三个持续开发会话，且一个帧内32个 Pilot 符号有 ISI 相关；区块 bootstrap 仅作灵敏度诊断。更严格下界显著减少可接受更新，却没有一致降低 Data 有害比例；宽松规则提高中高 SNR 接受数，同时保留大量 Data 有害候选。结论是**现有验证 Pilot 不支持仅靠改一个逐帧阈值获得可靠决策**，不能选择性部署上表中对 Data 最好看的规则。

## 跨帧暂存候选

第二项反事实把 Adapt 产生的候选及既有0.5锚点收缩冻结，从生成帧起累计连续1/2/4/8帧合法验证 Pilot BCE 和硬错误，再在窗口结束后决定是否接受。验证帧不进入候选梯度，候选窗口重叠，故结果不是独立统计。动作窗口完成后的下一帧 Data 只作离线评分。

跨帧累积没有形成稳定方向：8帧规则在0 dB接受14/72个候选，事后 Data BCE 平均略好、有害比例14%；5 dB接受17/72个，Data BCE 点估计为正但 BER 点估计无改善、有害比例29%；10 dB接受2/72个，15 dB接受0/72个。较长等待既减少可用更新，也未解决高 SNR 信息不足；不建议直接实现成部署门控。

## 子空间的离线 Data 可达性

隔离副本固定来源接收机和子空间基，每帧只优化自己的8个系数32步 Data BCE；Data 梯度不返回在线状态。96帧/点的平均 BCE 改善为：0 dB `0.00356`、5 dB `0.00193`、10 dB `0.00129`、15 dB `0.00130`。至少一帧出现 BCE 下降的比例依次为100%、100%、100%、54%；BER 改善比例为45%、33%、28%、11%。

这是一个受限参数子空间内的局部 Data oracle 诊断，不是可部署算法、全局最优界或在线收益证明。它表明子空间在低到中 SNR 尚有较明显的 Data 校正空间，而合法 Adapt Pilot 尚未稳定找到它；高 SNR 的 BCE 边际下降较常见，但符号判决翻转少，不能以连续损失下降替代 BER 增益。

## 阶段结论与下一步

当前证据不支持继续调守门阈值或单纯延长验证窗口。主要研究问题已转为离线内循环的梯度是否能穿过硬接受/拒绝分支学习有效的 Adapt 表示：线上动作必须继续使用精确的验证 Pilot 硬门控，但离线外循环可评估“前向行为与线上完全一致、反向对拒绝分支使用直通梯度”的训练代理。若该代理不能改善冻结来源与在线微调的四臂归因，就回到在线更新方向/表示；无论哪种训练都必须用四个SNR和同状态跟踪 Frozen 配对。

复现脚本：`scripts/diagnose_subspace_paired_validation.py`、`scripts/diagnose_subspace_delayed_validation.py`、`scripts/diagnose_subspace_data_reachability.py`。机器明细和逐帧/逐候选结果分别保存在本目录下三个诊断JSON。
