# 第十五轮：Frozen错判条件化Online外层目标

## 假设与隔离

第十四轮指出当前在线候选对Data错误边界的作用有限且同时改善/恶化不同错误位。本轮唯一改动是离线外层损失：用冻结输出和Data标签在**离线训练/选择**中把符号分为Frozen错判与正确两组，对Online平滑误码损失两组等权平均，并加Frozen全体符号的平滑误码锚点。目标是让元训练直接学会修复Frozen错判，同时守住Frozen原本正确位的边距。

信道、时序卷积基、8维子空间、在线Adam、Adapt历史、验证Pilot门控、锚点回退、seed和训练预算沿用第十四轮。线上更新仍只接收Adapt Pilot；Data分桶不进入部署接口。评估会话为已用于开发的3个seed，不是独立确认。固定清单见[`detection_subspace_long_v13_frozen_error_outer_v1.json`](../../../configs/audits/detection_subspace_long_v13_frozen_error_outer_v1.json)。

## 四SNR结果

v15 A/B两臂各自的冻结与在线BER在每个SNR完全相同：

| SNR | A普通监督 Frozen=Online BER | B错误条件化 Frozen=Online BER | 在线增益 | B接受数/候选接受数 |
|---:|---:|---:|---:|---:|
| 0 dB | `0.17304145` | `0.17302789` | `0` | `13/13` |
| 5 dB | `0.03344727` | `0.03344727` | `0` | `10/10` |
| 10 dB | `0.00343153` | `0.00344510` | `0` | `5/6` |
| 15 dB | `0.00055610` | `0.00055610` | `0` | `1/1` |

四点B−A在线增益交互均为0。门控接受一些候选，但没有一臂在评估中产生任何Data BER改变。B在10 dB的Frozen绝对BER略高于A；该在线外层既没优化出相对收益，也没有改变硬判决。样本仍是3个开发会话，零变化不代表等效或非劣。

## 结论

错误位与正确位分桶的离线损失没有让在线更新获得可观测BER增益，这条具体目标不保留为默认方法。配对目标两轮失败及边界诊断共同说明：只在现有8维输出残差系数上改变标量损失，暂未克服参数空间/更新方向的限制。核心研究目标仍未完成，**不启动正式确认**。

下一项先审计16维候选在合法Adapt Pilot上的Jacobian秩、条件数、不同检查帧稳定性和Data输出作用；只有满足预定可辨识门槛才继续训练。16维不是预先保证更好，审计失败则停止；信道和Pilot协议不变。
