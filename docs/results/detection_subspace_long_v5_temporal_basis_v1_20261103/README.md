# R2 固定长回波时序子空间开发归档

本批是 R2 第五轮结构开发，不是正式确认。信道、Pilot、接收窗口、同步和 acquisition 均与现有 `eme_long_memory_v2` 完全一致，`channel_changes=false`。唯一结构变化是把逐符号MLP基替换为沿符号轴kernel=5的一维局部卷积基，显式利用邻近特征；在线仍只更新低维系数。更新规则沿用第三轮的验证守门、离线锚点回退和0.5锚点收缩，没有第四轮的温度缩放。

几何审计中2/4/8维均满足满秩、梯度有限和条件数门槛，按固定规则选择8维；普通监督作用检查通过。A/B采用已有开发seed，三评估seed、四SNR、每会话32帧，共768条记录，属于重复开发数据而非独立泛化确认。

B臂0 dB在线增益点估计约`+2.71e-5`，95%区间`[-3.12e-5, 8.55e-5]`；5 dB也约`+2.71e-5`，区间同样跨零，B-A交互约`+2.71e-5`。10/15 dB未观察到在线增益，后者错误数过低不能据此判非劣。结果是值得继续核验的开发信号，但不足以宣布可靠、可重复的在线神经增益。

结论：局部时序表示比逐符号MLP更容易通过高维可辨识门槛，且当前点估计方向改善；仍需在新的独立信道会话上检验，才能判断是否进入R3。当前核心目标尚未完成。此处的“下一步”是冻结结构并制定独立确认前的统计门槛与样本量；应用主要SNR和退化界限仍需用户在正式确认前确定，不能拿当前重复开发seed替代。

完整几何、配置与模型指纹、训练记录和768条轨迹见本目录文件；`frame_metrics.jsonl.gz`解压字节由`summary.json`的`raw_sha256`校验。
