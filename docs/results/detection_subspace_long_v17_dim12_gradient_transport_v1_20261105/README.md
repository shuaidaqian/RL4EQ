# 第十七轮：离线学习全局正定梯度传输

## 假设与变量隔离

第十六轮的12维Frozen错误条件化表示没有在线BER增益，但逐帧Data oracle显示该表示在总系数半径0.8内仍有小幅修错空间。第十七轮只在v16的12维子空间、8帧Adapt历史更新器上增加一个单位阵初始化的12×12有界对称正定梯度传输矩阵，由离线外循环学习。信道、Pilot/验证Pilot、接收窗口、A/B四臂、目标、seed与训练预算都不变；Data标签仅用于离线外循环和事后评估。清单见[`manifest.json`](manifest.json)。

Pilot信息审计仍选中12维；清单seed 121000/121001的审计已重跑。评估seed仍是已用开发会话，不构成独立确认。

## 结果

| SNR | B臂 Frozen BER | B臂 Online BER | 在线增益 | 接受/候选接受 |
|---:|---:|---:|---:|---:|
| 0 dB | 0.17302789 | 0.17302789 | 0 | 11/11 |
| 5 dB | 0.03344727 | 0.03344727 | 0 | 9/9 |
| 10 dB | 0.00343153 | 0.00343153 | 0 | 5/5 |
| 15 dB | 0.00055610 | 0.00055610 | 0 | 1/1 |

A臂与v16相同，仅0 dB有`+1.36e-5`点估计，其余点为0；B−A交互没有正增益。A/B统一选择的checkpoint均为第16步。B的选择损失`0.29689125`，A为`0.29689242`，差异极小。新增传输矩阵相对单位阵Frobenius偏差约`0.0226`，条件数约`1.023`，几乎保持恒等映射，未形成有效全局预条件。在线更新约42 ms/帧，不含物理跟踪和完整接收。

## 结论与下一步

在本轮固定预算与目标下，单个全局正定矩阵没有让在线更新越过硬判决边界；它不作为有效方法保留。结合第十六轮oracle，后续重点应从“全局重标定12维梯度”转为“可由合法Pilot识别的局部影响更新”：检查各符号/时间邻域的Pilot Jacobian影响重叠，构造低维分块或局部卷积Adapter，使不同多径干扰位置可以独立修正；同时以跨帧Adapt历史稳定估计这些局部方向。先做信息秩与局部作用审计，再训练，不改变长回波信道及资源协议。在线增益未证明前不启动正式确认。
