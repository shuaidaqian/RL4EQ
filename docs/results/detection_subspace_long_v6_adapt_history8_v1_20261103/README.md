# 第六轮：八帧 Adapt Pilot 历史开发评估

## 结论

本轮在固定的 116 符号长回波配置和 `temporal_conv_v1` 8 维检测子空间上，只把 Adapt BCE 改为最近最多 8 帧合法 Adapt Pilot BCE 的均值。当前帧 Reward/验证 Pilot 仍独立用于动作后守门。四个主要 SNR 点全部报告，信道、Pilot、结构和评估预算均未改变。

该开发评估没有建立可归因的在线神经 Data 增益：B 臂在 0/5 dB 的点估计各约 `+1.36e-5`，配对 seed 95% 区间均跨零；10 dB 点估计为 `-1.36e-5`且区间跨零；15 dB 没有观察到在线 BER 变化，错误数量不足以判断增益。B-A 交互与上述点估计相同量级，不能据此声称历史窗口带来稳定收益。该结果只使用三个重复开发 seed，不是独立确认。

## 结果

每种训练臂在每个 SNR 使用 3 个开发 seed、每 seed 32 帧；summary 共记录 768 条 A/B 配对方法帧记录。在线增益定义为 `BER_Frozen - BER_Online`，正值代表改善。A 是普通监督训练对照，B 是在线匹配的更新后训练。

| 0 dB | 0 | `+1.3563e-5` `[-4.4795e-5, +7.1922e-5]` | `+1.3563e-5` | 16 / 17 / 8 |

区间只以 3 个 seed 做探索性配对 t 区间，未经多重比较校正。15 dB 的零变化不能解释为等效或无退化。各 SNR 的 B 臂有害保留次数分别为 0、0、1、0。

## 计算与信息边界

B 臂记录的平均增量子空间更新时间约为 39.6、40.0、40.1、41.5 ms（按 0/5/10/15 dB）。该计时来自缓存后真实执行的子空间更新，不包括 acquisition、接收等待、环境、来源接收机物理跟踪或冻结特征提取，不是端到端部署延迟，也不能据此判断 102.4 ms 实时约束。

在线状态只接收合法 Pilot observation；Adapt 历史只含 Adapt Pilot，当前帧验证 Pilot 不进入更新损失，Data 标签仅用于离线训练和事后评分。来源接收机权重冻结，P 与 A/B 分支共享来源 P 输出生成的 soft tail；因此自主闭环尚未验证。配置 SHA256 为 `535c1ce48a3ed194c0efc90b4d55afad371179d4d1b8415a3ba57ed40da6d149`，与既有长回波配置一致。
