# 第十九轮：127符号空洞残差基开发实验

## 假设与结构筛选

第十八轮直接堆叠空洞卷积使12维Pilot信息矩阵病态。第十九轮增加0.1缩放的残差旁路，保留局部方向，同时把理论感受野扩展到127符号，对应现有116符号长回波记忆。信道、Pilot、接收窗口、seed、A/B四臂、外层目标及在线更新规则沿用v16。清单见[`manifest.json`](manifest.json)。

审计仍以Pilot信息条件数不超过100为门槛：2/4维合格，检查器选中最高合格的4维；8/10/12/14/16维最坏条件数约166/345/633/800/2553。12维仍不合格，因此本轮验证的是4维残差空洞结构，不是12维结果。详见[`inspection.json`](inspection.json)。

## 四SNR开发结果

| 0 dB | 0.17306858 | 0.17305502 | `+1.36e-5` | `[-4.48e-5, 7.19e-5]` |

B臂0 dB的改善点估计只来自三个开发会话中的一个会话少一个误码；5 dB有同量级反向变化。10/15 dB虽无变化，但这不是在线优于Frozen的证据。A臂0 dB为退化点估计`−1.36e-5`、5 dB近零，B−A交互在0 dB约`+2.71e-5`、5 dB约`−1.36e-5`，不构成跨SNR稳定效果。B臂更新约53–56 ms/帧，不含物理状态跟踪和端到端接收。

## 结论与下一步

扩大感受野并加残差旁路使最高合格维数从深空洞结构的2维提高到4维，但12维仍远超条件数门槛；4维在线结果方向不一致且配对区间跨零。这一结构没有证明在线增益，不进入正式确认。下一步应从在线上下文函数入手：用Adapt Pilot推断低维更新状态，再让已接收的Data位置波形特征条件化该状态的逐位置修正；先单独审计上下文到输出的Pilot Jacobian秩和稳定性，再配对训练，避免继续堆叠全局共享系数。
