实验 `p1_phase_first_frame_12sessions`：新 seed 211001–211012，四 SNR，每会话首个 Data 帧；仅开发诊断，不证明 BER 改善或持续增长。噪声、CIR 和 CFO 均从 acquisition 合法估计。

旧方法对带噪相位解缠绕后取中位数。候选在给定 CFO、CIR 和参考波形时使用复相关的相角，避免依赖解缠绕分支。`circular_all` 使用全部合法 Adapt 参考，`circular_clean` 只用完整已知卷积行。首帧 tail 来自已知 acquisition。所有估计结束后才读取发送真值作预测误差评分；Reward/Data 标签没有参与拟合。
