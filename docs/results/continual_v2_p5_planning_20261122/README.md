# P5 功效规划（只读，2026-11-23）

## 状态

- 只读规划：用已完成的 P11（6 个开发 session × 4 SNR × 11,719 帧）估计 session 级方差，推算确认阶段所需会话数；**不生成新 seed、不改协议、不构成确认**。
- 脚本：[`scripts/plan_p5_power.py`](../../../scripts/plan_p5_power.py)；原始输出：[`power_planning.json`](power_planning.json)。
- 定义：早期窗 `[64,256)`，平台窗 `[1024,2048)`，晚窗 `[4096,8192)`（均为 P11 预登记窗口）。
  - `own_gain = O(平台) − O(早期)`，负值表示 Online 自身改善；
  - `adv_gain = G(平台) − G(早期)`，`G=F−O`，F 为 acquisition Frozen；
  - `adv_gain_vs_current = (B−O)` 的同窗变化，B 为匹配老化当前 Pilot；
  - `hold_own / hold_adv = 晚窗 − 平台`，作为饱和/保持等价检验的方差输入。
- 统计：单样本 t 检验（双侧 α=0.05，功效 0.8）与 TOST 正态近似；n=6 的 sd 同时给出 80% 单侧置信上界（约 1.45× sd，对应所需 n 约 ×2.1）。

## 主要结果（会话数）

| SNR | own_gain 均值 / sd | 观测效应所需 n | 0.005 绝对所需 n | 10% 相对所需 n |
|---:|---:|---:|---:|---:|
| 0 dB | −0.00713 / 0.02912 | 134 | 269 | 58 |
| 5 dB | −0.00255 / 0.01458 | 260 | 69 | 433 |
| 10 dB | +0.00002 / 0.00160 | 40,125 | 4（绝对 0.001 需 23） | 9,405 |
| 15 dB | +0.00008 / 0.00020 | 53 | 2（绝对 0.001 需 3） | 662 |

- **绝对量在 10/15 dB 不能作为主要判据**：BER 本身约 0.002/0.0006，0.001 的绝对边界相当于 50%/160% 相对变化；表中“所需 n 很小”没有科学意义。
- 10/15 dB 的**相对**量也不稳定：早期 BER 接近零时相对变化被少量错误主导（rel_own_gain 均值分别为 +103% 和 −28%，sd 为 3.46 和 0.92），需要更长会话或基于错误计数的估计量。
- `own_gain` 的 session 间 sd 主要由轨迹异质贡献；n=6 无法稳定估计分层方差，但至少说明单组轨迹不足以做四 SNR 自身改善的确认。

- 相对 Frozen 的优势只需很少 session 即可“显著”，但路由文档已说明它会被 Frozen 后段退化放大，不能替代 Online 自身改善。
- 与当前 Pilot 的配对优势更接近真实增量，0/5 dB 观测效应需 6/11 个 session，半效应需 16/37 个。
- 保持等价：0/5 dB 在 0.002 BER 边界下需 413/133 个 session；0.005 边界下需 67/22 个。10/15 dB 的绝对边界同样需要按相对量重新定义。

## 限制

- 方差来自 6 个开发 session，估计很宽；真实确认若沿用这些 sd，所需 n 可能约 ×2.1。
- `own_gain` 的窗口选择是规划代理，不等于冻结判据；窗口、最小效应和等价边界必须在开发阶段、看确认数据前冻结。
- 真实 ESNR 仅事后诊断；轨迹平衡必须基于生成器/动力学文件在开发阶段预登记，不能依据确认 BER 挑选。

## 对 P5 的直接含义

1. 0/5 dB 的“自身改善”是可行的确认目标，但按观测效应需要约 134/260 个 session；若把最小实质效应预先定为 0.005 绝对 BER，则约需 269/69 个 session。
2. 10/15 dB 应改用相对/错误计数判据，并显著增加每会话帧数或 session 数；否则无法与零区分。
3. 任何“保持”判据的等价边界必须与 BER 量级匹配，且用 session 级配对方差规划，而不是帧数。
4. P5 设计应预登记多轨迹并平衡晚段走向，否则晚窗方差会吞掉所有效应。
