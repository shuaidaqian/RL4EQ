# 第二十五轮：配对Online增益外层目标与阻尼GN内循环

## 假设与变量隔离

v24确认GN与离线内循环匹配本身没有优于普通监督的收益。本轮只将外层目标从Frozen错误条件化切换为配对 `online_gain`：相同样本/当前与下一帧分别计算Frozen和Online smooth-BER，并对Online落后加惩罚。GN更新、温度、步长与总半径、验证守门、初始点回退、持久状态、A/B训练预算、信道/PDP/Pilot/接收窗口和四个SNR均沿用v24。数据角色完全由清单固定，新评估seed为`121600/121601/121602`，仍属开发数据。

## 只读诊断

B臂验证Pilot最终接受的更新，在0/5/10 dB合计54帧中没有一帧降低同帧Data硬BER，51帧不变，3帧恶化；15 dB没有更新。标签只在更新完成后用于本诊断。明细见[`gate_alignment.json`](gate_alignment.json)。

同一2维非线性模型的逐帧Data-only oracle仍显示部分可达空间，但误码率与BCE不总是一致：

| SNR | Frozen BER | Data oracle BER | BER增益 |
|---:|---:|---:|---:|
| 0 dB | 0.14363607 | 0.14316135 | +0.000475 |
| 5 dB | 0.024915907 | 0.024997287 | -8.14e-05 |
| 10 dB | 0.0010443793 | 0.00086805556 | +0.000176 |
| 15 dB | 9.4943576e-05 | 1.3563368e-05 | +8.14e-05 |

例如5 dB的Data BCE oracle虽降低连续损失，硬BER反而轻微退化；oracle仅用于离线可达性分析，绝不属于部署算法。完整记录见[`context_data_oracle.json`](context_data_oracle.json)。

Adapt/Data梯度平均余弦在A臂0/5/10/15 dB为`0.715/0.319/0.046/−0.027`，B臂为`0.769/0.334/0.069/0.016`；B在低SNR的梯度对齐略好，但并未转为BER改善。验证/Data梯度余弦在B臂约`0.133/−0.069/0.052/−0.663`，验证信号与Data目标仍不稳定。15 dB B臂Adapt梯度范数约`5.38e-7`，验证梯度约`1.28e-9`。全部Data梯度只用于事后诊断。A、B详细记录见[`gradient_alignment_A.json`](gradient_alignment_A.json)和[`gradient_alignment.json`](gradient_alignment.json)。

## 结论与下一步

配对Online增益外层目标在固定GN更新下未形成正向在线增益；且A/B交互为负，说明目标函数单独替换不足以解决在线信息与验收之间的缺口。现有证据不支持继续扩同一GN目标或把这些开发seed当确认集。下一步优先校准合法验证Pilot的动作风险：用离线训练角色拟合“仅根据候选前后Pilot统计量预测有害更新”的保守门控，并与当前固定BCE/BER门控做同预算匹配消融；在线输入只含已接收Pilot与候选变化，Data只允许用于离线拟合和事后诊断。新门控须在未参与拟合/选择的开发会话上检验；如果仍无法将Pilot改善转化为Data增益，转回更新目标可辨识性，不进入正式确认。
