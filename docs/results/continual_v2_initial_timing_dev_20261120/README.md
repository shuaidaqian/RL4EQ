# P7：首帧时序修复与合法 Pilot 诊断短会话验证

本轮已完整完成，验证了修复后的时序及诊断保存链路。它没有证明四 SNR 的总体 BER 改善、长程保持或增长至饱和，也不能解释 P6 的晚段 BER 回升。

## 预登记设计

[协议](../../protocols/continual_v2_initial_timing_diagnostics_dev_20261120.json)在实验前冻结：新 seeds 235001–235003，四 SNR，64 帧，五臂。主要配对为 AR(1) 历史首帧零间隔与修复的一间隔；其余接收臂为 acquisition-CIR Frozen、当前 Pilot、递归 RW。神经 checkpoint、物理解码器、冻结动态参数、噪声来源、波形和处理时序均匹配。两种 AR(1) 均保存相同的新诊断字段，诊断不回流更新。

训练/解码与信息边界保持原研究约束。主噪声来源是 acquisition 合法残差估计。四个预定窗口为 [0,1)、[1,4)、[4,16)、[16,64)；另报告固定全会话汇总，不事后选窗。

## 完整性与实际时序

进程正常退出，主结果状态为 completed。12 个会话、60 个 session-arm 组合、3840 行及 768 个配对帧全部核验通过；每组恰为 64 帧，臂齐全、索引完整、无重复，同帧波形哈希及噪声估计相同。主结果、协议、配置、checkpoint 和全部记录的算法源码指纹匹配。

所有逐帧行都实际保存了 schema 2 字段，合法 Adapt 观测数恒为 108；prior/decode/posterior 协方差迹、观测残差功率、预测方差及噪声功率均为有限合法数。五臂各每帧一次解码，Transformer 前向计数为 0，无 soft Data 更新。Frozen 无 Pilot 更新，其他臂每帧一次 Pilot 更新；Pilot 后协方差迹不大于先验迹，无 Data 更新时 posterior 与 decode 迹相同。

逐会话首帧实际先验迹变化与 `(rho²−1) tr(P_acq)+(1−rho²) sum(D)` 在绝对 1e-6 的数值核验精度内一致；这验证实际接线，不是后验校准或 BER 收益证明。

## 配对性能与限制

表中增益为历史首帧设置 BER 减修复设置 BER，正值表示修复后 BER 较低。统计单位为会话，每 SNR n=3；区间为未校正描述性 95% t 区间，没有预先冻结的实质或等价阈值。

10 dB seed 235002 的首帧错误数从历史设置的 4 降到修复后的 3。其他首帧错误数相同，也不能直接推断全部判决或 logits 相同。修复并非严格不影响 BER，整体方向仍异质、精度不足，不能宣布普遍收益或等价。15 dB 的零经验差及退化 t 区间只表示三个短会话的错误率差相同，不证明总体影响为零。

当前 Pilot 对修复 AR(1) 的全会话配对增益为 0/5/10/15 dB：0.015767、0.005534、0.000448、0.0000475。只有 0/5 dB 的本次未校正描述性区间高于零；不能据此宣布四 SNR 递归增量全部确认。

修复 AR(1) 的平均 decode 协方差迹从首帧到 [16,64) 分别由约 0.12640→0.02617、0.04008→0.00933、0.01277→0.00368、0.00413→0.00164，表明接收器近似模型中的不确定性缩减。合法残差功率与预测方差量级接近；相位由同批 Pilot 拟合，且未包含联合同步不确定性，所以这不构成协方差校准、误差覆盖率或卡方创新检验。

修复 AR(1) 的接收步骤均值约为 45.6–48.6 ms/帧，包含新诊断开销。与 P6 相比实现和运行条件均已变化，不把跨实验耗时差全归因于某一模块，不作端到端实时验收。

## 下一步

保留修复后的时序和诊断实现。下一项机制问题是：在长会话中，Online BER 后段回升时，合法残差、预测不确定性、同步误差和等效信道状态是否同时失配。64 帧无法回答它；需要新登记的长程诊断，并保留必要的事后评分量与合法输入统计，避免再次只收集 BER 而无法归因。依然保留四 SNR 目标，不以短诊断通过代替研究完成，也不复用 P6/P7 seed 作确认。
