# R2 固定长回波子空间回退开发归档

本批是 R2 第二轮单因素开发，不是 R3 正式确认。严格复用现有 `eme_long_memory_v2` 信道、1024 符号帧、116 符号记忆、Adapt224/验证32、116 样本后缀和会话开始一次 acquisition；`channel_changes=false`。清单、几何审计、训练摘要和完整帧轨迹分别见本目录的 JSON 与 gzip 文件。

唯一新增规则是验证 Pilot 驱动的离线锚点回退：Adapt Pilot 完成候选更新后，比较当前保留系数与每会话离线初始系数；只有初始系数验证损失严格低于保留值至少 `1e-5` 且验证硬 BER 不升时才回退。候选接受和回退分别计数，Data 标签只在动作完成后评分。稠密记忆诊断保持第一轮旧规则，不执行这一回退。

几何审计在两个检查 seed、四个 SNR 和帧0/7上选出4维子空间（2、4维合格，8维淘汰）；普通监督作用检查通过。A为普通监督外层训练，B为匹配在线更新的外层训练；两者各64次外层更新，在独立选择会话上选checkpoint，随后在3个评估seed、四个SNR、每会话32帧上生成768条配对记录。全部仍是开发数据。

结果不支持进入 R3：0 dB 的 B 在线增益均值约 `+5.43e-5`，95%区间跨零，且 B 相对 A 的交互为负；5 dB 和10 dB在线均值退化，15 dB无有效错误。回退实际触发（A/B分别为33/36次），但没有形成可归因、可重复的 Data 检测收益。当前核心目标“离线训练适应信道，在线微调均衡”仍未完成。

本轮证据说明：增加一个合法的状态年龄安全分支可以改变在线状态轨迹，但不能解决验证 Pilot 与 Data 泛化不匹配的问题。下一步留在 R2，围绕验证目标/留出设计和离线先验的可迁移性做单因素修正；不追加当前结构的 seed 矩阵，不进入 R3、R4、R5 或 R6。

本轮 GPU 运行已完成；`summary.json` 中记录了源代码、信道配置、checkpoint、缓存和原始轨迹指纹。`frame_metrics.jsonl.gz` 为完整768条记录的确定性 gzip 归档。
