# 第二十四轮：匹配阻尼Gauss–Newton的离线元训练

> 本报告只采用修正验证回退规则后的最终重跑。较早的v24临时输出因回退分支与既有在线逻辑不一致而作废；最终训练目录为`logs/detection_subspace_training_v24_gauss_newton_meta_v2_20261105/`。

## 假设与固定协议

v23显示GN求解稳定但直接迁移到旧表示没有在线增益。本轮检验离线内循环与在线更新算子匹配后，元训练能否学到更适配GN的表示。唯一方法变量是B臂是否经过单帧、可微的阻尼GN在线更新作外层训练；A臂普通监督。两臂使用同一2维Pilot上下文网络、初始化、数据预算、Frozen错误条件化外层目标、更新信赖域与验证/回退逻辑。长回波信道、PDP、Pilot、接收窗口和0/5/10/15 dB均保持不变。

评估seed为新开发seed`121500/121501/121502`；只作开发对照，不是独立正式确认。清单见[`manifest.json`](manifest.json)，Pilot几何与作用审计见[`inspection.json`](inspection.json)。

## 事后诊断：验收、梯度与可达空间

Data只在更新和验证守门全部结束后评分。验证守门通过的更新大多没有改善同帧Data硬BER：

| SNR | B臂接受数/96帧 | 接受后Data BER改善 | 不变 | 退化 |
|---:|---:|---:|---:|---:|
| 0 dB | 28 | 0 | 27 | 1 |
| 5 dB | 31 | 0 | 31 | 0 |
| 10 dB | 2 | 0 | 2 | 0 |
| 15 dB | 0 | 0 | 0 | 0 |

尤其5/10 dB接受的帧没有改变硬BER；0 dB有少数变化且同时包含改善与退化。说明Pilot BCE守门偏向连续Pilot损失变好，但与Data判决边界改变的对应关系很弱。明细见[`gate_alignment.json`](gate_alignment.json)。

同一B checkpoint、同一2维非线性模型在固定半径`0.8`内逐帧用Data BCE做只读oracle优化时，仍有Data可达空间：

| SNR | Frozen BER | Data oracle BER | Oracle增益 | 有更少错误的帧/96 | 有更多错误的帧/96 |
|---:|---:|---:|---:|---:|---:|
| 0 dB | 0.16210938 | 0.16194661 | +0.000163 | 31 | 25 |
| 5 dB | 0.022650825 | 0.022596571 | +5.43e-05 | 22 | 20 |
| 10 dB | 0.00075954861 | 0.00055609809 | +0.000203 | 15 | 1 |
| 15 dB | 2.7126736e-05 | 1.3563368e-05 | +1.36e-05 | 1 | 0 |

该oracle直接访问Data标签，只是表示能力的乐观上界，绝不属于可部署方法或在线控制。它表明问题不只是2维表示完全没有纠错容量，合法Pilot更新尚未可靠逼近可用方向。逐帧数据见[`context_data_oracle.json`](context_data_oracle.json)。

B checkpoint处的梯度诊断进一步显示，Adapt与Data梯度平均余弦在0/5/10/15 dB约为`0.330/0.136/0.046/0.201`；GN候选步与Data下降方向余弦约`0.331/0.136/0.037/0.237`。验证梯度与Data梯度余弦约`0.166/0.041/−0.035/−0.427`。15 dB Adapt梯度范数均值约`3.46e-6`，验证梯度接近零。Data梯度只作事后诊断，没进入任何线上步骤。详见[`gradient_alignment.json`](gradient_alignment.json)。

## 结论与下一步

本轮否定“只把离线内循环替换成可微GN，就能让已有2维表示产生可重复在线收益”的假设。当前证据指向更新方向信息和Pilot验收对Data边界的预测能力不足，且高SNR Adapt梯度信号极弱；同时Data oracle显示仍有有限纠错空间。下一步保持GN、Pilot、守门、状态保留、半径和信道不变，只把离线外层目标从Frozen错误条件化换成配对`online_gain`目标，检验是否能直接学到Online相对Frozen的正差值。继续用独立开发seed，完整报告四SNR和A/B交互；若仍无可重复增益，再回到Pilot目标/更新可辨识性，不进入正式确认。
