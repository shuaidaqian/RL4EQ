# 第十六轮：12维子空间的错误条件化训练

## 假设与隔离

第十五轮在8维时序卷积子空间上没有观察到B臂在线BER变化。此前信息矩阵审计显示12维满秩、最坏条件数约84.40，满足固定的100门槛；10/14/16维不满足。第十六轮因此只把维数从8改为12，沿用Frozen错判条件化外层目标、四臂预算、在线更新、验证Pilot守门、数据划分和原有116符号长回波信道。没有改信道、Pilot或接收窗口。Data标签仅在离线训练、选择及本轮只读诊断中使用。

清单见[`detection_subspace_long_v16_dim12_frozen_error_v1.json`](../../../configs/audits/detection_subspace_long_v16_dim12_frozen_error_v1.json)。本轮evaluation的三个seed已用于开发，不是独立确认。

## 只读边界可达性诊断

诊断使用B checkpoint重放同一evaluation开发特征；Data标签只用于离线计算边距和错判，不参与在线控制。每帧三步的累计系数位移上界为0.45。

| SNR | Frozen/当前错误数 | 三步半径内理论可达错误比例 | Pilot候选改善错误边距 | 候选翻转错误数 |
|---:|---:|---:|---:|---:|
| 0 dB | 12757 | 1.16% | 56.35% | 0 |
| 5 dB | 2466 | 3.97% | 57.38% | 0 |
| 10 dB | 253 | 11.46% | 46.64% | 1 |
| 15 dB | 41 | 12.20% | 36.59% | 0 |

“理论可达”是逐符号按基向量行范数得到的宽松局部上界，忽略同一组系数必须同时服务整帧符号的冲突；它不是整帧可达到的BER上界。诊断显示12维候选经常朝有利方向移动一部分错误边距，但同样会伤害另一部分错误位，且实际变化幅度没有跨越硬判决边界。因而维数可辨识并不等于Data错误可修复：当前瓶颈同时涉及输出表示的局部杠杆/共享系数冲突，以及Pilot梯度如何形成不伤害已正确位的更新。

## 结论与下一步

随后完成逐帧Data oracle诊断，方法是在每帧同一12维基、以零系数为起点，在清单固定的总半径0.8内用Data BCE投影Adam优化160步。这是使用未来Data标签、每帧独立优化的乐观上界，不能部署，也不能证明合法Pilot能够找到该系数。结果为：

| SNR | Frozen BER | Data oracle BER | oracle表观改善 |
|---:|---:|---:|---:|
| 0 dB | 0.17304145 | 0.17283800 | `+2.03e-4` |
| 5 dB | 0.03344727 | 0.03335232 | `+9.49e-5` |
| 10 dB | 0.00343153 | 0.00329590 | `+1.36e-4` |
| 15 dB | 0.00055610 | 0.00047472 | `+8.14e-5` |

四点oracle都降低了逐帧聚合BER，但每帧也可能增加错误；绝对改善很小，且逐帧使用Data标签，信息条件明显强于在线。与真实Pilot更新四点零增益对照，当前12维表示仍有少量修错空间，主要待解问题转为如何从合法Pilot估计对Data有用且跨符号协调的更新方向，同时避免伤害其他符号。下一轮优先研究Pilot驱动的预条件/梯度传输与局部影响结构，不改信道、Pilot预算或评估协议。

12维改善了可辨识维数，却没有产生在线BER增益；不保留为已验证的有效机制，也不进入正式确认。下一步依据上述oracle结果，把工作聚焦到合法Pilot梯度如何逼近Data可达方向，并解决同帧符号更新冲突；所有在线分支仍不得访问Data标签。
