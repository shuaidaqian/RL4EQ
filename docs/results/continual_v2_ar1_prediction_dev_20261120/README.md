# P6：离线冻结 AR(1) 状态预测的长会话开发结果

本轮全部完成，数据完整性通过；尚未满足四 SNR 的 Online 自身改善、优势增长至饱和并保持目标。AR(1) 对随机游走有小幅接收增量，但不能用该增量代替目标达成。

## 设计与完整性

预登记协议：[候选与窗口](../../protocols/continual_v2_ar1_prediction_dev_20261119.json)。使用新开发 seeds 234001–234010，四 SNR 各十个独立会话，每会话 11,719 帧，约 1200 s。三臂为 acquisition-CIR Frozen、递归 Pilot 随机游走（RW）、递归 Pilot AR(1)，共享波形、合法噪声估计、解码器和当前 Pilot 先更新再解码的时序。解码器为 `known_adapt_real_physics`；本轮不证明神经修正或在线神经参数更新的贡献。

AR(1) 的 rho 与 117 维逐 tap 功率从独立 offline_train seeds 233001–233010 估计并冻结，在线不读取真实 CIR 更新这些参数。两递归臂的差异包括状态均值转移和过程协方差形状，不能把整个增量进一步归因到其中一个因素。

原进程正常退出（退出码 0），主结果为 `completed`。逐条全量审计确认 40 个会话、120 个 session-arm 组合、1,406,280 行及 468,760 个配对帧；每组索引连续覆盖 0–11718，bits 恒为 768，无重复、缺失、乱序、非法计数或同帧波形哈希错配；40 条 acquisition 齐全。协议、配置、checkpoint、离线动态文件及算法源码指纹均已核验。比较入口曾为显式续跑修复，原始指纹与恢复指纹分别保存在主结果的 protocol 和 recovery_events 中。

Windows 主 JSON 原子替换曾失败一次；续跑重放 5 dB seed 234003 的帧 0–7423，匹配已保存的波形哈希、errors、bits 后续写，没有覆盖既有结果。恢复的计算耗时不作为未重复计费的整体墙钟成本。

## 可归因增量与目标差距

统计单位为独立会话，n=10/SNR；先在每个会话内汇总，再等权跨会话计算。下述区间均为未作多重性校正的描述性 95% t 区间，只用于开发判断。各 SNR 共评估每臂 90,001,920 个 Data 比特。

| SNR | 全会话 RW BER | 全会话 AR(1) BER | 配对 BER 降幅 RW−AR(1)，95% 区间 | 正向会话 |
|---|---:|---:|---:|---:|
| 0 dB | 0.123289 | 0.122333 | 0.000956 [0.000887, 0.001025] | 10/10 |
| 5 dB | 0.029166 | 0.028600 | 0.000566 [0.000486, 0.000647] | 10/10 |
| 10 dB | 0.001928 | 0.001844 | 0.0000846 [0.0000498, 0.0001194] | 10/10 |
| 15 dB | 0.0003034 | 0.0002993 | 0.00000402 [0.00000047, 0.00000757] | 10/10 |

15 dB 全会话经验增量共减少 362 个错误，描述性区间很接近零；其末窗 RW−AR(1) 为 0.00000580，区间 [−0.00000265, 0.00001424]。全会话平均差与后段改善能否保持必须分开判断，不能称四 SNR 的保持均已证实。

0/5 dB 在早期固定窗口中存在 BER 下降形态，随后回升；不能据此报告全程持续改善。四 SNR 的 ΔO 点估计都为正，15 dB 的描述性区间也为正，而 ΔG 大幅增长伴随 F 退化。故本轮没有证明四 SNR 的 Online 自身改善与优势增长的统一目标。

从倒数第二窗 [4096,8192) 到末窗，AR(1) 相对 Frozen 的 G 分别继续增加约 0.03966、0.05635、0.06496、0.06721，对应描述性配对区间均高于零。仍未预先冻结并验证饱和等价容差，不能宣称已饱和，也不能用 Online 某些晚窗近似平坦替代 G 饱和。

## 噪声与计算成本

每会话 acquisition 合法残差估噪与仿真噪声真值的比值，在四个 SNR 的会话均值均约 1.0005–1.0007，所有观察值约在 0.955–1.041。真值仅用于该事后诊断；该结果不证明后验协方差或同步联合不确定性已经校准。

全会话按接收步骤计时的均值约为：Frozen 20.1–20.5 ms/帧、RW 34.2–34.7 ms/帧、AR(1) 35.1–35.6 ms/帧。AR(1) 相对 RW 约增加 0.9–1.0 ms/帧。硬件为 GTX 1650，PyTorch 2.11.0+cu128。此值是固定臂执行顺序下的开发测量，不含完整 acquisition、结果落盘及端到端接收开销；不作实时实现验收，也不与历史神经接收机的耗时直接等同。

## 证据限制与下一步

1. 当前源码在 acquisition 已演化一次 CIR 后，首个 Data Pilot 前跳过了过程预测，第二帧才开始预测。RW 和 AR(1) 都受影响，不能假定配对影响抵消。见[时序审计](../../continual_v2_initial_prediction_audit_20261120.md)。本轮尤其不能用首帧比较证明修复版本的早期改善。
2. 本轮 JSONL 未保存合法观测残差和协方差迹，无法从现有记录解释晚段回升的物理或数值原因；不能事后追补成已经观察到的诊断。
3. 神经修正、完整传统接收机调校、边界验证和 P5 独立确认均未由本轮补齐。
4. 下一步先整合隔离分支的首帧时序及合法观测诊断修复，以新登记数据检查初始化与后段状态/同步失配，再决定必要的模型和离线训练改动。不能只扩大样本量来替代机制修正，也不把本轮 seed 用于独立确认。
