# Fisher 初始化 rank-1 GN 外层训练：32帧独立会话复核

## 设置

沿用既有 Level B `eme_long_memory_v2`、116符号长回波、Pilot=256（Adapt=224、Reward=32）和0/5/10/15 dB。基础强离线 checkpoint SHA256：`8cd3912d1c957c9689c51730aff9d27a8f74942186c802a7483e5781af65aec4`。rank-1 basis 从独立训练角色的 Pilot-Fisher 主方向初始化，外层训练32步、每条轨迹4帧；在线每帧使用Adapt-only一维GN，Reward独立硬守门，参数跨接受帧持久。评估使用新会话76101、76102，每SNR每会话32帧。相同接收波形比较Frozen、固定Fisher方向GN和外层学习方向GN。

逐帧结果与完整指纹见 `result.json`。唯一统计单位为session；两个评估seed尚不足以支持正式确认。

## 决策

固定rank-1方向与Fisher初始化后学习的rank-1方向都没有给出可归因、可重复的Online−Frozen增益。停止扩大相同机制矩阵。下一轮转向全head连续轨迹外层训练，并用同样样本与预算的普通监督续训作对照；评估仍以同源Frozen为主基线，检查离线训练是否学到更适合在线更新的表示，而不只学到敏感方向。
