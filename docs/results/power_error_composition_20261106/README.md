## 0. 一句话结论

当前“每 SNR 2–3 个 session、16–32 帧”的开发设计，在 10/15 dB 的 80% power 最小可检出效应约为 `3e-4`–`1.5e-3` BER，在 0 dB 约为 `9e-3`–`1.9e-2`、5 dB 约为 `2e-3`–`4.7e-3`；而历史上反复出现的 `1.36e-5`、`4.07e-5` 等点估计，恰好等于 3 session × 32 帧共 73,728 bit 上的 **1 个或 3 个净错误**。因此“没有可重复收益”不能只归因于算法失败：以现有样本量，**1e-5 量级的真实效应在统计上不可检出**。要把 1e-5 作为正式目标，10/15 dB 需要约 `10^2`–`10^3` 个独立 session；0/5 dB 需要 `10^4`–`10^5` 个，实际不可行。

- 0 dB 的 session 均值很稳定（三个 seed 为 21.73%、21.34%、23.51%），但**单帧错误数从 104 到 650**，跨度 6 倍；帧间 lag-1 自相关接近 0。也就是说，帧级信道实现差异很大，但 session 平均在 60 帧后已经比较稳定。

- 因此：**不能用 Poisson 或独立 bit 二项分布做样本量预算**；必须用 session 级经验方差或设计效应校正。

### 3.2 开发实验的配对噪声量级

`power_error_composition.json` 的 `per_snr.*.per_dataset` 给出每个实验的 session 级 Δ 均值、SD 和帧级 Δ 方差。几个代表性值（中位数场景的帧级 Δ 方差，单位 errors²）：

| SNR | 最小（温和） | 中位数 | 最大（激进） |
|---|---:|---:|---:|
| 0 dB | 59.5 (p10) | 144.4 | 559.2 (p90) |
| 5 dB | 2.9 | 7.0 | 25.2 |
| 10 dB | 0.19 | 0.76 | 3.41 |
| 15 dB | 0.062 | 0.133 | 0.797 |

0 dB 的帧级 Δ 方差可达 `10^2` errors²：某些更新器每帧会随机改变几十个判决。**方法越“激进”，噪声越大；但温和方法也未必更好，因为它的效应同样小。** 关键不是单独看效应或噪声，而是看 `效应/噪声`。

补充来源 `v27_32f` 是已观察到的最温和更新之一：0 dB 活跃 session 的平均帧级 Δ 方差约 0.23 errors²（MDE@n=3,F=32 ≈ `3.6e-4`），5 dB 约 0.14（MDE ≈ `2.8e-4`）；10/15 dB 没有接受更新，无法估计。即便用这个最温和口径，3×32 设计仍只能检出 `~3e-4`，检不出 `1e-5`。

## 4. 统计功效与最小可检出效应（MDE）

### 4.1 方法

- 统计单位：**独立 session**，不是帧，也不是 bit。
- 对每个 session 先算 `ΔBER_s = mean_t (e_online,t - e_frozen,t)/768`，再对 n 个 session 做双侧单样本 t 检验（α=0.05）。
- 80% power 的 MDE 用非中心 t 精确求解，而不是正态近似。n=3 时 df=2、`t_crit=4.303`，正态近似会明显高估功效。bootstrap 百分位区间在 n=3 时与 t 区间同量级，不会改变样本量结论；本文统一报告解析 t 口径。
- Session 级方差模型：`Var(ΔBER_s) = σ²_frame/F + τ²`。主表取 `τ²=0`（配对设计消除 session 间信道差异）；`τ²` 由 3 个 seed 矩估计，极不稳定，只作敏感性上界。
- 当前日志的帧间 lag-1 自相关接近 0（主矩阵 Frozen 约 -0.12–0.03），故按 F 计算、不额外做有效样本量折扣；若未来引入慢漂移导致正相关，必须把 F 换成 `F_eff`，否则会高估功效。
- 方差场景：
  - `empirical_median`：各活跃 session 帧级 Δ 方差的中位数（本文主口径）。
  - `empirical_typical`：按自由度加权的池化方差（受激进方法影响，偏保守）。
  - `empirical_gentle_p10` / `empirical_aggressive_p90`：10/90 分位。
  - `binomial_reference`：未配对 bit 级二项参考 `768·p·(1-p)`，**不是严格下界**，因为配对差方差可能低于或高于它。

### 4.4 每 session 净错误波动：为什么需要这么多 session

在 F=128 时，把 `1e-5` 的 ΔBER 换成净错误数：

`1e-5 × 768 × 128 ≈ 0.983` 个净错误/session。  
也就是说，**1e-5 的效应就是每个 128 帧 session 平均少/多约 1 个错误**。

当前方法在该尺度上的 session 间净错误波动（`sqrt(σ²_frame·F)`，中位数口径）为：

| SNR | 每 session 净 Δ 错误 SD (F=128) | 目标 1e-5 的净错误 | 约需 session 数 |
|---|---:|---:|---:|
| 0 dB | 135.9 | 0.98 | 150,000 |
| 5 dB | 30.0 | 0.98 | 7,330 |
| 10 dB | 9.9 | 0.98 | 795 |
| 15 dB | 4.1 | 0.98 | 141 |

这解释了为什么 1e-5 在低 SNR 不可行：目标的净错误数（约 1）远小于方法本身的 session 间净错误波动（几十到上百）。在理想的“每 session 恰好约 1 个净错误、且计数近似 Poisson”情形下，约 8 个 session 即可检出；但当前观察到的更新器都远未达到这个精度。

### 4.5 分辨率：为什么“1.36e-5”往往只是一个 bit

每帧 768 bit，session 级最小非零 ΔBER：

| F | 3 session 总 bit 数 | 1 个净错误对应的 ΔBER |
|---:|---:|---:|
| 16 | 36,864 | 2.71e-5 |
| 32 | 73,728 | 1.36e-5 |
| 60 | 138,240 | 7.23e-6 |
| 128 | 294,912 | 3.39e-6 |

历史上常见的 `+1.36e-5`、`-1.36e-5`、`+4.07e-5`、`+5.43e-5` 分别正好是 3×32 帧上的 1、1、3、4 个净错误。**这些不是连续的“效应量”，而是离散错误计数的整数倍。** 单帧最小非零 ΔBER 为 `1/768=1.302e-3`；即使平均到 32 帧，单 bit 也是 `4.07e-5`。因此任何小于 `4e-5` 的 32 帧结果都应直接按“几个 bit”解读。

## 5. 错误构成与逐帧离散变化

### 5.1 逐帧 Δ 错误分布（主矩阵）

| SNR | P(Δ=0) | P(\|Δ\|=1) | P(\|Δ\|≤2) | P(\|Δ\|≤5) | max\|Δ\| |
|---|---:|---:|---:|---:|---:|
| 0 dB | 1.000 | 0.000 | 1.000 | 1.000 | 0 |
| 5 dB | 1.000 | 0.000 | 1.000 | 1.000 | 0 |
| 10 dB | 0.317 | 0.317 | 0.789 | 0.961 | 10 |
| 15 dB | 0.472 | 0.339 | 0.917 | 0.989 | 6 |

开发实验汇总（含激进方法，1,188 帧/SNR）：

| SNR | P(Δ=0) | P(\|Δ\|=1) | P(\|Δ\|≤2) | max\|Δ\| |
|---|---:|---:|---:|---:|
| 0 dB | 0.437 | 0.056 | 0.548 | 103 |
| 5 dB | 0.363 | 0.174 | 0.652 | 61 |
| 10 dB | 0.553 | 0.247 | 0.907 | 10 |
| 15 dB | 0.837 | 0.122 | 0.987 | 6 |

主矩阵 10/15 dB 中，大多数帧是 0 或 ±1 个错误；但单帧最多可差 10 个错误。**单帧离散变化足以主导 3-session 的 session 均值**：一个 60 帧 session 只要多/少 2–3 个错误，就会让 session ΔBER 变动 `4.3e-5`–`6.5e-5`，与历史“增益”同量级甚至更大。

### 5.2 过离散：不是 Poisson，也不是独立 bit 二项

主矩阵 `方差/均值` 和设计效应见第 2 节：0 dB 分别为 70.6 和 90.7，5 dB 2.12/2.25，10 dB 2.55/2.58，15 dB 1.76/1.77。  
Poisson 要求方差/均值 ≈ 1；独立 bit 二项要求设计效应 ≈ 1。两者都被拒绝。15 dB 还出现零膨胀（27.8% 零错误帧，Poisson(1.66) 只有约 19%）。因此：

- 不能用 `sqrt(p(1-p)/N)` 或 Poisson 误差棒做 session 结论；
- 必须用 session 级经验方差，或至少用设计效应放大；
- 0 dB 尤其严重，单帧 BER 波动约 6 倍，必须靠 session 平均，但 session 数仍是独立的限制。

### 5.3 |logit|、空间位置、run-length

不可用（见 1.3）。仅作上下文，历史 `error_geometry_stage_20261101.json`（不同 checkpoint，5 seed × 8 帧）给出的 data 区域错误符号平均 `|logit|`：

| SNR | data_head | data_middle | data_tail | `wrong_abs_logit_ge_5` 合计 |
|---|---:|---:|---:|---:|
| 0 dB | 0.660 | 0.680 | 0.657 | 0 |
| 5 dB | 1.027 | 1.134 | 1.106 | 0 |
| 10 dB | 1.609 | 2.193 | 2.920 | 3 + 9 |
| 15 dB | — (0 errors) | 5.369 | 7.338 | 2 + 12 |

趋势是：低 SNR 的错误符号 `|logit|` 较小（边界附近，可能可翻转），高 SNR 的错误符号 `|logit|` 很大（深度错误，难以翻转）。这与“低 SNR 有更多边界可修错误、但噪声也更大”一致。但阈值占比、正确符号对照、空间直方图和 run-length 仍需逐符号 logit 才能计算，本轮无法给出。

## 6. 结论

1. **“没有可重复收益”有相当大的样本量成分。** 3 session × 16/32 帧在 10/15 dB 的 MDE 约 `3e-4`–`1.5e-3`；历史点估计 `1e-5`–`5e-5` 比 MDE 小 1–2 个数量级。以该设计反复得到“区间跨零”是预期结果，不能据此判定机制无效。
2. **但也存在真实的方法噪声瓶颈。** 0 dB 的帧级 Δ 方差中位数约 144 errors²，session 间净错误波动约 136 errors/128 帧；目标 1e-5 只有约 1 error/128 帧。即使样本量足够，当前激进更新器的效应/噪声比也极低。需要同时降低“更新引起的判决抖动”，而不只是增加 seed。
3. **1.36e-5 等点估计是离散 bit 计数，不是连续小效应。** 3×32 帧共 73,728 bit，1 个净错误 = 1.36e-5；`+1.36e-5/-1.36e-5/+4.07e-5` 分别对应 1/1/3 个净错误。任何小于 `4.07e-5` 的 32 帧结果都应直接报告“几个 bit”，不能当作稳定的 BER 改善。
4. **主矩阵在 0/5 dB 没有在线更新。** Frozen 与 Online 的 180 帧逐帧 BER 完全相同，`adapt_params=0`、`adapt_steps=0`。历史主矩阵的低 SNR 结果不能支持“在线神经参数微调有效”；10/15 dB 的配对差异也不显著（p≈0.33–0.34，95% CI 跨零且宽度约 1.4e-3–3.5e-3）。
5. **统计单位必须是独立 session，帧不是独立重复。** 帧间 lag-1 自相关接近 0，但帧级信道实现差异极大（0 dB 单帧错误 104–650），设计效应 1.8–90.7。把 16/32 帧当 16/32 个独立样本会严重高估功效；把 bit 当独立样本更会错几个数量级。
6. **配对是必要的，但仍不够。** 同一 session 内 Frozen/Online 配对可把 10/15 dB 的方差降到未配对二项参考的约 1/5–1/7，但剩余 session 间净错误波动仍远大于 1e-5 目标。配对不能替代独立 session 数。

## 7. 建议的最小 session / 帧数

以下建议按“预注册一个可解释的效应”给出；**不建议继续把 1e-5 作为主确认目标**，除非接受 0/5 dB 不可行、10/15 dB 需要数百 session 的代价。

### 7.1 若目标是 1e-4

| SNR | 建议最小设计（median 口径） | 保守口径（typical） | 说明 |
|---|---|---|---|
| 0 dB | 1,500 session × 128 帧 | 3,159 × 128 | 不现实；建议把 0 dB 目标放宽到 1e-3 |
| 5 dB | 76 × 128 | 209 × 128 | 可行但成本高 |
| 10 dB | 11 × 128 | 23 × 128 | 建议 ≥20–25 session |
| 15 dB | 4 × 128 | 9 × 128 | 建议 ≥10–15 session 以稳估方差 |

### 7.2 若目标是 1e-5

| SNR | median 口径 | typical 口径 | 结论 |
|---|---:|---:|---|
| 0 dB | 150,080 × 128 | 315,661 × 128 | 不可行 |
| 5 dB | 7,330 × 128 | 20,673 × 128 | 不可行 |
| 10 dB | 795 × 128 | 2,074 × 128 | 成本很高，仅在机制效应确实达到 1e-5 时考虑 |
| 15 dB | 141 × 128 | 626 × 128 | 可行但需百级 session；建议 ≥150–600 |

### 7.3 一个务实的分 SNR 最小方案

若必须做正式确认，建议预先冻结如下“可检出下限”，并据此设计：

| SNR | 预注册最小 ΔBER | 建议独立 session 数 | 每 session 帧数 | 依据（median/typical） |
|---|---:|---:|---:|---|
| 0 dB | 1e-3 | 30–35 | 128 | 18 / 34 |
| 5 dB | 5e-4 | 10–15 | 128 | 6 / 11 |
| 10 dB | 2e-4 | 20–25 | 128 | 5–8（1e-4 为 11/23） |
| 15 dB | 1e-4 | 10–15 | 128 | 4 / 9 |

同时建议：

- **至少 10 个独立 session**，不要用 3 个 session 做“确认”；n=3 时 df=2，即使标准化效应 d≈2.4 也只有约 58% 功效。
- **每 session 至少 128 帧**。若 session 数受限，增加帧数只能按 `1/√F` 降低会话内噪声，无法消除 session 间 τ²；不要用 16 帧做小效应结论。
- **预注册效应量和 MDE**，而不是事后解释“区间跨零”。若目标效应小于该 SNR 的 MDE，应直接判定“本轮设计不可判定”，而不是“无差异”。
- **报告每个 session 的配对 Δ 和其 SD**，以及净错误数（整数），不要只报平均 BER。这样读者能直接看到“1.36e-5 是几个 bit”。

## 9. 局限

- 主矩阵与开发实验的 checkpoint、更新器、帧数不同；本文只把它们的**帧级 Δ 方差**作为噪声量级估计，不把不同方法的平均 BER 混合成主结果。
- `σ²_frame` 是“方法实际改变多少判决”的属性，不是信道的固定常数；未来更新器若显著更温和或更激进，必须用该更新器自己的开发日志重估，不能直接套用本文的中位数。
- τ² 由 3 个 seed 的矩估计得到，极不稳定；主表取 τ²=0，保守表用 τ² 上界，真实值可能介于两者之间。
- 每帧 768 bit 的相关性、帧间信道相关性未被参数化；设计效应是经验校正，不是生成模型。
- 逐符号 logit、错误位置、run-length 不可用；第 5.3 节的历史 |logit| 只作方向性上下文，不能用于本矩阵的阈值占比或可翻转比例。
- 本文的 MDE 是“固定效应、session 间独立”的 t 检验口径；若未来使用分层 bootstrap 或混合模型，数值会略有不同，但样本量量级不会改变。
