# Fisher 初始化 rank-1 GN：32帧首次独立评估

此为32步Fisher初始化basis外层训练后，在新session 76100上的首次32帧开发评估。相对Frozen，meta-GN在0 dB平均收益`+3.67e-4`（按日志聚合约`+3.66e-4`），晚窗减早窗约`-6.51e-4`；5 dB收益`+8.14e-5`且只在最后窗口有一次判决变化；10/15 dB为0。单session显示的低SNR正点估计值得复核，但不能证明持续增长。

随后两session复核（76101、76102）在0与5 dB都给出负的平均全程收益，晚早区间跨零。首次session因此保留为开发结果，不作为独立确认，也不能单独支撑方法有效。完整逐帧记录见 `result.json`。
