# 累计 PEFT 位移半径开发消融

多数32帧会话的PEFT累计位移曾触及0.05上限，因此本轮只将Online分支的跨帧累计半径从0.05扩大到0.10，其他分支仍为0.05。每帧Adam更新半径固定0.05，优化器状态两边都每帧重置，参数均按Reward硬守门持久提交；3个新会话、四SNR、每会话16帧。

累计半径0.05与0.10的整体 Online−Frozen BER改善分别为：0 dB `+0.00296/+0.00285`，5 dB `+0.00309/+0.00309`，10 dB `+0.000515/+0.000515`，15 dB `+0.000109/+0.000109`。两臂的差异区间均跨零，5/10/15 dB的结果完全相同；0 dB较大半径没有改善。0.10分支的部分会话累计位移确实超过0.05（最高约0.066），所以该消融实际生效。

这说明当前失败不能简单归因于累计位移预算太小。放宽总位移没有加强BER收益或增长趋势；不继续扩大同一半径。
