# P12：长时域离线训练与神经候选独立开发验证

## 状态与范围

P12 的训练和预登记验证均已完成，**这是开发证据，不是最终研究目标确认**。训练报告状态为 `completed`；训练进程退出码为 0。六个 checkpoint 均存在，逐一计算的 SHA256 与训练报告一致。验证进程退出码为 0，结果状态为 `completed`。

训练协议为 3 个训练重复，每个重复 16 个 episode；每个 episode 2048 帧，按预定的 16 个时间点监督。比较 acquisition 轨迹训练和 recursive Pilot 轨迹训练，得到六个 checkpoint。训练会话 seed 为 238001–238048，训练 seed 为 411001–411003。训练报告为 [`ar1_training_3x2048.json`](ar1_training_3x2048.json)。训练耗时约 3 小时 17 分钟。

验证使用全新开发 seed 239001–239006，SNR 为 0/5/10/15 dB，每个 session 256 帧，比较物理接收器、未训练神经解码器、三重复 acquisition 训练模型和三重复 recursive Pilot 训练模型，共 8 个候选臂。所有神经候选复用同一合法 recursive Pilot 物理接收上下文。噪声方差来自 acquisition residual；Data 标签只参与事后评分。每个验证 session 约 26.2 秒，故该验证没有覆盖完整长会话或饱和保持。

逐帧验证结果 [`ar1_neural_validation_6x256.json`](ar1_neural_validation_6x256.json) 保留在本地；该 73 MB 原始结果按仓库对长会话逐帧输出的惯例加入 Git 忽略规则。它的 SHA256、逐帧完整性检查和主要汇总均记录在 [`p12_validation_audit_summary.json`](p12_validation_audit_summary.json)。预登记协议在 [`continual_v2_p12_ar1_long_horizon_validation_20261121.json`](../../protocols/continual_v2_p12_ar1_long_horizon_validation_20261121.json)。

训练报告共有 96 条记录（48 个 episode × 2 种训练轨迹），三重复和两种方法均齐全；六个 checkpoint 的文件哈希与报告中的哈希全部一致。

未训练神经候选和物理接收的 BER 在四个 SNR 几乎相同。Acquisition 训练的三重复均值也与未训练候选接近，方向随 SNR 略有变化，没有显示稳定的硬判决 BER 增益。

Recursive Pilot 训练相对未训练候选没有四 SNR 一致的 BER 收益。0 dB 上三重复均值更差；按每个验证 session 先对三个训练重复取平均，再与未训练候选配对，平均 BER 增量为 `+0.0008692`，六个 session 的方向均为恶化。5/10/15 dB 的变化很小且训练重复方向不一致。作为探索性描述，按 6 个独立 session 计算的未校正 95% 配对 t 区间分别为：0 dB `[+0.000629,+0.001110]`、5 dB `[-0.000134,+0.000184]`、10 dB `[-0.000014,+0.000017]`、15 dB `[-0.000005,+0.000003]`。这些区间未校正多重比较，不构成确认检验。

在低 SNR，训练模型的概率评分有改善但没有转化成更低 BER。例如 0 dB recursive Pilot 训练三重复的平均 Data BCE 约从未训练的 `0.34617` 降至 `0.33597`，Brier 约从 `0.10105` 降至 `0.09785`，同时 BER 从 `0.11590` 升至 `0.11677`。5 dB 也出现较小的 BCE/Brier 改善而硬判决 BER 基本持平。这个差异提示，若继续研究神经分支，应查清软输出如何进入后验或后续均衡决策，并分别验证概率评分改善和接收 BER 收益；仅凭 BCE/Brier 下降不能宣称接收性能提升。

## 对研究目标的含义

P12 没有证明离线神经训练带来可复现的接收 BER 增益；目前不能把它作为“离线适应信道”的有效贡献，也不应据此进入最终独立确认。它也没有包含 Frozen 对照，不能支持在线相对 Frozen 的优势增长；256 帧约 26.2 秒的 session 更不能证明增长至饱和或后段保持。此前 P11 的 Online 后段 BER 回升仍是主目标的未解问题。

下一步建议先回到路线中的机制归因：保留匹配物理状态下的 Pilot-only 基线，单独检验合法 soft Data 是否能在 Pilot 信息之上增加可复现 BER 收益，并记录错误反馈风险；同时诊断 P12 中 soft 分数改善却没有降低 BER 的原因。若 soft Data 没有独立增量或风险抵消收益，就收紧神经/离线训练的创新主张，把工作集中到物理递归接收器及其长时域自身 BER 退化问题。待存在可复现的四 SNR 接收收益后，再确定物理边界、增长窗口、饱和容差和功效，最后冻结 P5 独立确认协议。

本结果不改变信道配置，也不把验证 seed 用作后续确认 seed。当前阶段到 P12 为止；按用户要求，以下研究实验暂停。
