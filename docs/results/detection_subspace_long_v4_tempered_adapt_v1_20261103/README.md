# R2 固定长回波 Adapt 温度开发归档

本批是 R2 第四轮单因素开发，不是正式确认。沿用原 `eme_long_memory_v2` 信道、Pilot、后缀接收窗口、同步和 acquisition 协议；`channel_changes=false`。唯一新增变量是 Adapt BCE 的 logit 温度固定为0.5；验证守门保持温度1.0和原硬 BER 条件，锚点回退/收缩、维数、A/B训练预算及数据角色保持不变。

几何审计选择4维子空间，普通监督作用检查通过。A/B沿用已有开发 seed，仅作温度机制对照；三评估seed、四SNR、每会话32帧，共768条记录。因此结果不能作为独立泛化确认。

温度0.5未改善B臂在线Data BER：0 dB增益均值约`-1.36e-5`，95%区间跨零；5 dB约`-1.36e-5`退化，区间跨零；10/15 dB没有有效错误可供增益判断。B相对A的交互在0 dB和5 dB均为负。该设置降低了部分有害保留，但没有取得可归因、可重复的在线增益，故只保留为归档消融，不作为当前方法。

核心目标“离线训练适应信道，在线微调均衡”仍未完成，R2继续。下一步回到更新表示与外循环目标的匹配，检查当前4维检测残差基是否有足够的跨帧可迁移变化方向；不会继续叠加温度或保护超参数，也不会改变信道。

完整指标见 `analysis.json`、`summary.json` 和 `frame_metrics.jsonl.gz`。摘要记录源码revision `ba46172121896e61d32843b2f27b4c190dc60767`、配置和checkpoint指纹；gzip解压后的字节应与`summary.json`的`raw_sha256`一致。
