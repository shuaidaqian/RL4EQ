# 第十八轮：127符号深空洞卷积基的信息审计

## 假设

第十七轮的Jacobian诊断显示现有5符号卷积基对远隔Data输出的共享影响高度相关。第十八轮将时序卷积感受野扩大到127符号，以覆盖现有116符号长回波记忆。信道、Pilot、接收窗口、数据划分和更新规则未变；清单见[`manifest.json`](manifest.json)。

## 审计结果

预定的Pilot信息矩阵条件数上限为100。只有2维通过，检查器按规则选中2维；4/8/10/12/14维的最坏条件数分别约为917/6614/8947/14450/23001，16维秩不足。12维目标结构不合格，**没有运行匹配训练或评估**。详见[`inspection.json`](inspection.json)。

## 结论

直接深堆叠空洞卷积扩展感受野时，Pilot方向严重病态。该结构不进入训练，不把检查器自动选出的2维结果冒称为12维实验。下一轮仅增加缩放残差旁路来保留局部方向，再按相同条件重新审计。

本轮只运行信息审计；没有在线增益结论，不启动正式确认。
