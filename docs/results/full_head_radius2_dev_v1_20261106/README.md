# 全 head 累计信赖域半径 2× 消融

固定强离线权重、当前帧 Adapt Adam、Reward逐帧硬门控、每帧最大步长0.05；仅把累计参数偏离上限由0.05改为0.10。新开发session为76150/76151，各SNR连续16帧。同一session内当前半径和2倍半径使用相同接收波形。

正的 Frozen−Online BER 表示在线改善：

| SNR | 原半径均值收益 | 2倍半径均值收益 | 原半径晚−早 | 2倍半径晚−早 | 接受数原/2倍 | 有害接受原/2倍 |
|---:|---:|---:|---:|---:|---:|---:|
| 0 dB | -8.14e-5 | +4.07e-5 | +3.26e-4 | +8.14e-4 | 23/26 | 6/5 |
| 5 dB | -4.07e-5 | -4.07e-5 | -4.88e-4 | -4.88e-4 | 9/9 | 1/1 |
| 10 dB | 0 | 0 | 0 | 0 | 10/10 | 0/0 |
| 15 dB | 0 | 0 | 0 | 0 | 5/5 | 0/0 |

0 dB的2倍半径均值点估计略正，但session级区间约为[-4.61e-3, 4.69e-3]，两session方向相反，不能视为增益。它减少了晚期步长投影压缩，却没有建立可重复的收益趋势。5 dB保持负收益，其余SNR没有 BER 改变。因此累计半径0.05确实限制了后期更新幅度，但把半径增至0.10不足以解决 BER 增益问题；不继续扩大半径。

结果JSON逐帧记录实际半径、更新步长、接受、有害提交及四窗BER。所有Data指标均为动作后评分，没有进入在线控制。开发session数量很少，仅用于机制取舍，不能支持统计确认。
