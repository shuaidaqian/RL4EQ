# 第十轮：离线学习 Pilot 梯度上下文更新器

## 单因素设计

在 v9 失败结果基础上，保留 116 符号长回波、四个 SNR、信道生成、Pilot 预算、接收窗口、物理状态跟踪、历史长度、Adam基线、半径投影、独立验证Pilot硬门控和数据角色。唯一改动是把固定线性梯度映射换为可学习的上下文非线性更新器。

8维子空间每个内循环步输入17维特征：Adapt历史平均梯度的8维单位方向、8维逐系数梯度离散度（相对平均梯度范数），以及裁剪归一化的平均梯度 `log10` 范数。MLP为17-16-8、Tanh激活、末层零初始化，共424个参数。其输出经 `tanh` 后乘固定学习率的0.5倍，作为原Adam增量的有界残差，再经过原投影与验证Pilot守门。它只使用最近8帧Adapt Pilot梯度，不读取验证标签、Data或隐藏真值。零初始化下，前向更新与普通Adam完全一致。

A/B包含相同模型参数量和初始化；A不启用新更新器，B在离线展开内循环/当前及下一帧Data外循环中学习它。两臂各64步，数据和预算相同。清单SHA256：`be417b7b4f49e32bc5c37ee93272928e783104a1a8981695c1b3ff7b6b4ce249`；信道配置与来源checkpoint的SHA256沿用v9，分别为 `535c1ce48a3ed194c0efc90b4d55afad371179d4d1b8415a3ba57ed40da6d149` 和 `11e58a5d94801ae613ec8f7a55679ed2304e0864535c7b0468b316827e2bec51`。本轮仍是开发评估，不是独立确认。

## 开发评估

几何检查再次通过2/4/8维，按预定规则选8维；独立监督作用烟测通过。四SNR、3个重复开发seed、每会话32帧、A/B两臂共768条记录。

每个SNR只有3个开发seed；零BER变化不能代表等效或非劣，15 dB尤其缺少足够错误数。B在0/5 dB比v9更常接受候选，但全评估仍没有任何在线Data BER变化。平均系数候选增量范数约0.0188；平均更新耗时约38–43 ms，不含接收和来源物理跟踪，不能当作端到端延迟。B选择损失0.105917，高于A的0.105867。

B臂在线Data BCE平均改善（Frozen BCE−Online BCE）按0/5/10/15 dB约为 `+3.52e-6/-1.23e-6/+5.67e-7/-1.76e-7`，方向不一致且量级很小。B臂Adapt/Data梯度余弦约 `0.371/0.094/0.166/0.086`；验证/Data余弦在5/10 dB约 `-0.008/-0.072`。动作后只读复盘中，原硬门控接受候选的Data BCE有害比例约为 `0.35/0.68/0.75/1.00`。这些Data值只供离线分析，未参与在线更新或选择。

因此，这个可学习非线性上下文更新器没有建立可归因在线BER增益，不能作为核心方法，也不能进入R3。结果延续了v9指向的限制：Adapt梯度历史提供了状态上下文，但它和留出验证Pilot仍难稳定指示Data的有益更新方向。下一项开发单因素应转向**离线外层目标**：对比标准Data BCE与针对误码边界的平滑判决损失，同时保持线上Pilot更新器和验证守门不变；预先固定连续损失、尺度和四SNR报告，不按结果选SNR或阈值。
