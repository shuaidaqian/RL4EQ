# 8 帧开发会话：状态、同步与物理难度

全部 4 个 SNR-session 组合、128 行及 32 个配对帧审计通过。每会话 8 帧，每个 SNR 有 1 个独立开发会话，同一 seed 在不同 SNR 的结果不额外计作独立会话。

所有表格先在每个会话内按预登记窗口汇总，再对会话等权。报告从首个普通帧开始，不选择窗口、不拟合单调曲线。尚未冻结实质改善阈值、饱和等价容差或确认功效；本报告不给总体通过、等价或饱和判定。

在线使用合法 acquisition 残差估噪；真值仅用于接收结束后的评分。神经权重冻结，当前物理解码分支不证明 Transformer 或离线闭环训练贡献。

未老化 acquisition 先验的当前 Pilot 对照为：current_pilot_static。它与递归臂的差值混合历史观测及先验模型差异，不能全部归因于新增普通帧 Pilot。

显式使用老化 acquisition 先验的当前 Pilot 对照为：current_pilot_aged_ar1。请核对配套协议中冻结动态是否与递归臂相同；各臂自己的同步和 soft-tail 仍可能随解码轨迹变化，配对差描述整个递归接收策略的增量。

## 解释限制

- 逐会话配对差与所有相邻窗口的 ΔOnline、Δ基线、Δ增益保存在配套 JSON；Δ增益=Δ基线−ΔOnline。优势增长不等同于自身改善。
- Pilot 相位由同批观测拟合，协方差未包含联合同步不确定性，能量比不能解释为已校准卡方统计。
- CIR 平方误差与能量比先逐帧计算再平均；相位 RMS 为逐帧 RMS 的算术平均。包裹相位均值不跨会话算术平均。
- 全能量下界先逐帧计算再平均，使用事后真实噪声与功率，未计帧尾截断；不是合法接收 BER，也不是精确帧内边界。
- 状态、同步、物理条件与 BER 的伴随变化不构成单因素因果证明；不能用这份开发报告宣称目标不可达。
- 接收步骤 elapsed_ms 不含事后评分和落盘；本实验不作端到端实时验收。
