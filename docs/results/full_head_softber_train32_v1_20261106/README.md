# soft-BER 外层目标32步训练与匹配续训评估

## 条件

Trajectory臂仅将离线多帧外层的更新后Data目标改为固定温度0.5的平滑BER surrogate；在线候选仍用Adapt-only BCE Adam，Reward仍用独立Pilot硬门控，累计半径0.05、轨迹4帧。匹配普通监督臂从同一离线checkpoint出发，配置、采样序列、SNR和训练步数均相同。评估使用新session 76170/76171，每个SNR每个session16帧；每臂Frozen与Online在同一波形配对。

## BER结果

收益定义为Frozen BER−Online BER；正值表示在线更好。

soft-BER轨迹相对普通续训的Online−Frozen增量点估计为0 dB `+1.22e-4`、5 dB `+4.07e-5`、10/15 dB `0`。0 dB逐session在线收益分别为`+7.32e-4/-1.63e-4`，会话方向相反；5/10/15 dB两个session内均无硬BER变化。普通续训0 dB逐session收益均约`+1.63e-4`，5 dB为`0/-8.14e-5`。因此B−A的点估计虽在0/5 dB为正，但每SNR只有两个session，不能据此判断总体交互。报告中的描述性区间仅供展示，零方差或极宽区间都不能解释为总体效应已被精确估计。两臂0 dB后窗都没有稳定占优，soft-BER臂整体晚窗−早窗为负。该结果没有证明在线BER优势随传输帧数增长，也不足以证明小幅正点估计可重复。

训练episode上的Data BCE明显下降，但在开发评估session里，两臂动作后Data BCE改善量仍接近；软目标没有在这两个评估session上转化成硬判决 BER 增益。说明更对准BER的外层目标可改变训练梯度，但当前更新参数化和Reward门控仍限制实际检测收益。

## 决策

不按这两个session调温度、门控或半径。固定soft-BER checkpoint、普通续训checkpoint和在线规则，扩展到每个SNR至少12个此前未参与训练或筛选的独立session、每session连续128帧；以session为统计单位，按固定32帧窗口及1/2/4/8/16/32/64/128帧前缀报告配对收益和增长趋势。该规模是开发筛查下限，不是正式确认。若跨session正收益仍不稳定或晚窗不增长，则终止当前全head Adam更新器路线，转向低维神经状态空间后验更新假设，先做64帧机制筛查，再决定是否延长到128–256帧。详细逐帧结果见本目录两个eval16.json及checkpoint训练记录。

## 产物说明

本评估产物由旧版通用评估脚本生成，schema仍保留当时的rank-1历史命名，且包含辅助Fisher基信息；`full_head_adam`分支不读取该basis。脚本现已改为按实际分支需要计算并记录basis，使用通用schema v2；历史JSON保持原样以维护结果指纹，数值未受元数据问题影响。训练指标、checkpoint和配置指纹均留存在对应checkpoint目录及JSON中。
