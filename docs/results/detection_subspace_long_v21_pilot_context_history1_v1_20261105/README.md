# 第二十一轮：Pilot上下文Adapter的单帧梯度历史

## 假设与隔离

第二十轮只读梯度诊断发现，5 dB当前帧Adapt/Data梯度余弦均值约`+0.139`，但8帧梯度均值余弦为`-0.095`，方向发生反转。第二十一轮仅把`inner_history_frames`从8改为1，检验最近Pilot梯度是否被历史平均抵消。2维上下文Adapter、信道、资源、训练/选择/评估seed、Frozen错误条件化外层目标、在线优化器与守门全部保持不变。清单见[`manifest.json`](manifest.json)。

## 结果

| SNR | B臂 Frozen BER | B臂 Online BER | Frozen−Online增益 | 配对95%区间 |
|---:|---:|---:|---:|---:|
| 0 dB | 0.17302789 | 0.17301433 | `+1.36e-5` | `[-1.03e-4, 1.30e-4]` |
| 5 dB | 0.03344727 | 0.03342014 | `+2.71e-5` | `[-3.12e-5, 8.55e-5]` |
| 10 dB | 0.00344510 | 0.00344510 | 0 | `[0, 0]` |
| 15 dB | 0.00055610 | 0.00055610 | 0 | `[0, 0]` |

四点正点估计只出现在0/5 dB，区间仍跨零。更关键的是A臂和B臂每个SNR的在线BER完全相同，B−A交互全为0；单帧梯度历史没有显示离线学习的上下文更新器带来额外贡献。B臂实际接受更新数为17/26/4/0，更新耗时约22 ms/帧。

只读梯度诊断见[`update_alignment.json`](update_alignment.json)：Adapt/Data梯度余弦在0/5/10/15 dB约为`+0.311/+0.150/+0.091/-0.455`；相较v20，5 dB不再被8帧平均反转，但实际更新与Data下降方向余弦在5/10 dB仍约`-0.161/-0.650`。15 dB Adapt梯度范数约`3.13e-6`且无接受更新，说明高SNR信号不足仍存在。

边界分析见[`data_boundary_reachability.json`](data_boundary_reachability.json)：候选会改善约44%–52%的当前错误边距，也伤害其余错误；最终仅在0/5 dB各减少少量误码，10/15 dB硬BER不变。结果支持缩短历史改善了部分Pilot方向信息，但没有证明能产生可归因于元训练的稳定在线增益。
