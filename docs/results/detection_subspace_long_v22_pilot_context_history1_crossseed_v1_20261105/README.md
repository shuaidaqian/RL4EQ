# 第二十二轮：单帧Pilot上下文更新的跨seed开发复测

## 复测目的与固定条件

第二十一轮在已多次用于机制开发的seed上，0/5 dB出现小幅正Frozen−Online点估计。第二十二轮冻结v21的2维Pilot上下文Adapter、单帧Adapt历史、训练/选择seed、checkpoint选择规则、更新器和验证守门，仅使用此前未参与本路线开发的评估seed `121400/121401/121402`。本轮仍标记为development，不作为正式确认；评估后不调阈值或选择checkpoint。清单见[`manifest.json`](manifest.json)。

## 结论与下一步

这次复测否定了“仅将8帧历史改为1帧即可获得可重复在线增益”的开发假设。它不是正式确认，不能证明总体非劣或优越；但足以停止把该单因素当作有效机制。下一项转向2维上下文的阻尼Gauss–Newton/近端Pilot更新：利用低维Pilot Jacobian和曲率估计直接求解小步长上下文增量，配合现有验证Pilot门控；先做局部数值和时序审计，再匹配离线外循环训练。信道、资源与标签隔离不变。
