## 观测定义

以当前帧完全已知的 Adapt 卷积窗口构造设计矩阵 X。只使用当前接收波形、合法 Adapt 符号、Pilot 估计的同步参数、状态先验及 acquisition 残差估噪。固定 1024 符号帧、116 符号记忆、224 个 Adapt 符号时，合法观测数为 108；不借用真实前帧 tail、Reward/Data 标签或当前真实信道。

在当前 Pilot CIR 更新前，用相位补偿观测 y 和预测状态 m、P 记录：

- `pilot_observations`：有效观测行数 N。
- `pilot_innovation_mse`：复残差功率 `||y-Xm||²/N`，不再除以 2。
- `pilot_innovation_variance_mean`：`mean(diag(X P Xᴴ)) + sigma²`，计算包含 P 的非对角项。

这些统计只作诊断，不回流状态或估噪。没有有效观测时返回 N=0、两项统计为 JSON null，避免以零或 NaN 伪装有效观测。

相位由同批 Pilot 估计，P 也未包含同步参数联合不确定性；记录的残差不是已证明满足标准分布的创新。因此，观察到残差与预测方差接近，不能直接宣称滤波校准、覆盖率或卡方检验成立。这里只比较能量均值，也未保存完整创新协方差或跨行相关结构。

## 保存契约

流式 schema 2 保存原 BER/成本/波形哈希，以及 prior/decode/posterior 三个 CIR 协方差迹、以上 Pilot 统计、实际估计噪声功率、更新次数和前向次数。三个协方差迹分别对应 Pilot 更新前、Data 解码时、可选 soft Data 更新后；它们仍是接收器近似模型中的不确定性，不是状态误差真值。

写盘前先验证整批记录包含必要字段，再打开 JSONL 追加；缺字段直接拒绝，避免静默丢弃诊断。JSONL 不写入 CIR 真值或 Data 标签数组，共享状态候选另保存 `shared_state_from`。主协议记录 schema 版本和诊断解释，续跑兼容性检查同时比较这些字段，防止混合新旧记录格式。

诊断计算位于接收步骤内，会计入相应新实验的 `elapsed_ms`；不能把当前 P6 未记录这些诊断的成本，直接作为新实现完整诊断运行的成本。
