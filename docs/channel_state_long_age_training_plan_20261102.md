# 一次 acquisition 的实际长会话年龄匹配训练

用户已明确数百秒会话只在开始 acquisition 一次，后续仅用每帧前缀 Pilot。
前面的长年龄与窗口结果说明部分晚期状态有可修正误差，但样本间不稳定；
不能把短年龄 checkpoint 的外推结果当作年龄匹配训练后的结论。
本轮固定一个小预算阶段，先检验匹配年龄能否改变这个边界。

- A/B 共同从 future B256 开始，SHA
  `751eaa8278cfaf32982f5371df842f9f4fdce0ab83dda5c19c6891dd88ea336e`。
  原网络和其余分支冻结，只离线继续训练神经状态 449 参数。
- offline_train 93000–93063，各 64 步，batch=1、outer lr=.001，四 SNR 轮换。
  当前更新年龄 0/127/1023/2047/4095 轮换；外层评分当前与当前+8 帧。
- A 两帧 BCE_all 等权平均；B 在相同监督暴露上再加两帧更新后 Data BCE。
  两分支 medium 内层均 .02、3 步、半径 .2、Adapt signal；不改 guard。
- 离线样本缓存在 `logs/channel_state_long_age_training_samples_20261102`。
  只保存目标帧、acquisition 估计和初始已知 tail；完整物理轨迹仍按相同 seed
  逐帧生成一次。缓存不保存模型输出、动作或策略，也不进入正式在线 runner。
  缓存键包含完整配置、seed、SNR、年龄与目标偏移，协议不符必须失败。
  A/B 复用完全相同离线样本，训练历史记录缓存键及输入 SHA。
  `scripts/prepare_transfer_samples.py` 可用 CPU 提前准备固定索引段；GPU 实验
  仍串行。进程独立临时文件原子发布，重复生成同一确定性样本不改变协议。
- 先做两步 CUDA smoke，A/B 的目标预算不使用 smoke 权重。smoke 产生的两个
  样本可供正式训练复用，但不改变监督样本或训练步数。
- 首关独立 heldout_edge 96001–96005、四 SNR，每条先推进 1023 帧物理历史，
  再评分 8 帧，接受后保留，共 160 当前上下文、320 条 A/B 记录。
  历史期间不做神经更新：这是约 105 秒处启动的机制实验，不是从首帧连续
  跟踪的最终验收。行中同时保存局部帧号和真实物理帧龄。
- 所有主结果先与自身 Frozen 配对，再与同波形原始 future B 源评分，避免
  通过 Frozen 退化放大适配差值。A/B 训练样本、源旧参数与测试波形须逐项核验。
- 若没有四 SNR 稳定收益，不自动把 64 步加到 256 或扩大同一留出矩阵；先
  在新的训练样本定位长年龄目标、方向和反馈是否匹配。若有机制证据，再
  注册独立连续 128 帧与完整数百秒窗口 RL/传统比较，不能跳过正式验收。

默认未启用缓存或历史评估的旧配置仍保持原协议。所有当前与未来 Data 标签
严格限于离线外层与仿真评分。报告实测研究耗时，不等同实时在线成本。

实现验证：定向 **91 passed，18.10 秒**；完整 CPU FFT
**783 passed，286.24 秒**，两者重叠。覆盖 A/B 缓存复用及错误协议拒绝、带历史
评估的物理帧龄与参数起点、旧零历史协议、未来目标与隐藏标签边界。
两步 CUDA post_adapt smoke 通过；正式 64 步从共同源重新开始。
