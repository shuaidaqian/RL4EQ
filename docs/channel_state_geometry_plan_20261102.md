# 长年龄 head 的可达方向与 Pilot 更新对齐诊断

长年龄匹配 B64 在独立短会话的 0/10/15 dB 有自身 Frozen 配对正区间，5 dB
仍不确定；B 的高 SNR Frozen 也弱于 A，源模型比较尚需完整核验。
不自动增加训练步数或留出 seed。先解释当前 17 参数 head 的真实作用族。

- 固定 long_age B64，SHA
  `919ca4c6e99c5c44519c1b381e44baa4b923e204c1daccc56da339b50a6ab71e`。
- 只读其原训练缓存，在每个 SNR×年龄 0/127/1023/2047/4095 选训练历史中
  第一个样本，共 20 上下文。它们不是独立验证样本，不统计泛化收益区间。
- 计算实际神经 CIR 对 17 参数 head 的实 Jacobian（复 CIR 拆成实/虚两部分），
  报告奇异值、有效秩和方向集中度。不能仅凭参数量推断有效自由度。
- 在同一个 CIR 输出点，分别计算合法 Adapt 前向信号 loss 梯度与离线 Data
  BCE 梯度，报告 Data 梯度在可达空间的能量比例，以及两种梯度投影的夹角。
- 唯一实际候选仍由 Adapt 产生，medium .02、3 步、半径 .2；记录实际 CIR
  步长对 Data 梯度的方向导数和事后 BCE 变化。绝不由 Data 梯度生成更新、
  搜索动作或选取在线规则，不构造 Data 标签候选。
- 使用 CPU，不重复生成轨迹；缓存键、当前波形 SHA 与训练记录核对。基础
  权重和缓存保持只读，显式标记所有 Data 导数仅作离线解释。
- 若 Data 方向大部分不可达，下一步先在训练范围验证更合适的神经状态表示；
  若可达但 Pilot 方向不一致，则先处理目标与反馈；若实际步长受投影影响，
  则单独验证有界优化几何。任何一个指标不能独自替代 BER 验收。

诊断需核验 Jacobian 的有限差分、参数不改写及 Data 不影响实际候选。正式
窗口 RL、传统主比较和数百秒连续验收仍按原最终标准执行。
