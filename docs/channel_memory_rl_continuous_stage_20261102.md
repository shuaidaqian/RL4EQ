# 210 秒单轨迹后段出现收益，尚需独立 seed 复核

按[预设计划](channel_memory_rl_continuous_plan_20261102.md)，实际环境 seed 100013、offline_train、10 dB、2048 帧从首帧连续运行完成。会话 **209.7152 秒**，物理帧龄 0–2047，开始 acquisition 一次；固定原 checkpoint、动作、Reward、8 帧窗口、32 帧 PPO 间隔与 FFT 后端。同波形独立 Frozen 与 RL 共4096条记录，未引入跨帧额外接收窗口。

**单轨迹全程和后段均出现正描述值，但不能生成独立 seed 区间，也不能完成四 SNR 主目标。** 完整[配对机器结果](results/channel_memory_rl_continuous_2048f_10db_20261102.json)保存波形 SHA、物理年龄审计、来源指纹、分段与耗时。

## 真实控制过程

256个窗口、**64次PPO更新、144个正Reward窗口、4次窗口回滚**；148个窗口选择记忆动作，其余为identity或旧rollback别名。动作帧数为identity824、MAP small448、MAP medium696、signal small16、signal medium24、rollback_identity40。

验收后最大累计记忆范数 **0.800000072**，处于float32投影容差内。[纯Pilot反馈记账](results/channel_memory_rl_continuous_reward_accounting_20261102.json)重建全部256个窗口的既有reward；本轮没有正Pilot收益被成本抵消的窗口。没有根据Data改变成本系数、动作、checkpoint或更新规则。

同时确认一个状态管理边界：`rollback_identity`是恢复identity调制的历史别名，**不会把已保留的复记忆重置为零**。5个此类窗口结束后的记忆范数仍非零，例如frame104为.09326、frame928为.71340。真正的窗口回滚只恢复当前窗口起点的参数。这是现有语义，不应把它描述成完整的过期记忆刷新机制；本轮没有静默改变它。

## 耗时、验证与接续

完整研究进程墙钟 **1145.51秒（约19.09分钟）**，包含初始化、两方法、诊断前向、仿真评估和日志；不是部署时延。当前`latency_ms=0`仍是历史占位值，实时能力未验收。

核心接入全量807项通过；后续配对汇总与纯Pilot诊断21项定向通过。长会话汇总拒绝缺帧、重复方法、波形不同、错误物理年龄、信息边界失败和非独立Frozen替代，不为单seed捏造置信区间。

下一步按[独立复核计划](channel_memory_rl_continuous_confirmation_plan_20261102.md)，保持当前整帧接收边界，使用三个新的heldout_edge seed、10 dB、各2048帧，检验全程与后期改善区间。没有通过前，不扩大为四SNR正式主矩阵。跨帧额外接收窗口属于尚待用户明确的独立协议分支，不阻塞现有协议复核，也不混入已完成结果。
