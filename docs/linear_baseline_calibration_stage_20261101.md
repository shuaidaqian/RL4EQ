# 传统线性接收机校准与独立核验

本阶段确认：传统接收机的同步、正则和块边界会明显影响对照强度，不能把旧
实现的较弱 BER 当作神经/RL 方法成功的充分证据。同时，更长的时域滤波器在
有限前缀 Pilot 下不保证更好。新增线性块参考目前仍只用于校准诊断，主方法组
没有变化；本阶段不作神经方法与传统方法的配对性能结论。

## 固定选择与独立核验

按照[预先记录的计划](linear_baseline_calibration_plan_20261101.md)，校准仅使用
offline_train、seed=36000–36002、每条 4 帧。15 个候选共 720 条记录，不读取
神经模型结果。按各 SNR 的校准平均 BER 选择 FIR/DFE；频域和块参考不调参。

冻结选择见[配置记录](results/linear_baseline_frozen_selection_20261101.json)：
FIR 的 ridge 倍率均为 224，0/5 dB 长度为 41，10/15 dB 长度为 117；DFE 在
所测两档中均选择原 41+5。随后仅在 heldout_edge、seed=46001–46005、每条
8 帧执行冻结的六个设置，共 960 条记录。没有在留出集重新搜索参数。

所有方法均使用 acquisition CIR/CFO 估计和当前 Adapt Pilot 公共相位，历史
由各自接收估计产生。Reward 符号不作为已知输入；Data 标签在所有接收更新
结束后才用于离线评分。线性块参考可固定已知 Adapt 坐标，这是合法 Pilot 信息。

下表是同一批确认轨迹上的平均 Data BER，单位为百分数。不能与另一批 seed

|---:|---:|---:|---:|---:|---:|---:|
| 0 dB | 20.8008% | 22.7539% | 20.2246% | 21.1556% | 19.3555% | 22.5781% |
| 5 dB | 10.7650% | 11.3281% | 5.6087% | 5.1172% | 5.0195% | 3.9616% |
| 10 dB | 5.2376% | 5.1172% | 1.1849% | 0.8138% | 0.7064% | 0.3809% |
| 15 dB | 2.1061% | 2.9362% | 0.5176% | 0.1465% | 0.1042% | 0.0684% |

以 seed 为统计单位，零填充 FDE 相对循环 FDE 的 BER 改善为：

- 0 dB：−0.9310 pp，95% 区间 [−8.3854, +6.5234]，不能确认改善。
- 5 dB：+0.4915 pp，[+0.1649, +0.8182]。
- 10 dB：+0.3711 pp，[+0.0906, +0.6516]。
- 15 dB：+0.3711 pp，[+0.1255, +0.6167]。

实 BPSK 线性先验相对复数线性先验，在 5/10 dB 分别改善 +1.0579 pp 和
+0.3255 pp，配对区间均为正；0 dB 均值反而较差，15 dB 差异区间跨零。
因此不能把“利用实先验”写成各 SNR 均优。同步和 CIR 估计误差仍会限制它。
复数线性块 MMSE 相对零填充近似的四个配对区间都跨零。

## 实现和验证

`baseline/linear_mmse.py` 独立求无 CP、已知 Adapt 坐标约束的传统线性估计。
复数先验正规方程使用 HᴴH+sigma²，实先验使用 Re(HᴴH)+sigma²/2。CG 最多
128 步，求解后直接重算正规方程残差；独立核验的全部 320 个块求解均通过收敛检查。
这里没有硬判决反馈、局部 bit 搜索、DD CIR 更新、神经网络或 RL。

测试覆盖独立稠密 Toeplitz 最优解、非零历史、Pilot 约束、未知发送符号污染、
direct/FFT、116 长回波和校准/留出隔离。全量回归 **661 passed，250.26 秒**；
之后新增的冻结设置守卫包含在 **6 项定向测试**中通过，后者与全量有重叠，不能
相加成 667 项。脚本 smoke、720 条校准和 960 条独立核验全部完成。

机器可读结果、所有单方法区间、配对区间和原始文件 SHA256 见
[精简摘要](results/linear_baseline_calibration_stage_20261101.json)。原始逐帧文件
留在 Git 忽略的 `logs/`；复现命令见计划。

## 结论边界和下一步

本轮只校准预设网格，不代表所有传统算法或超参数已经充分优化。尤其 DFE
还没有系统校准 RLS 先验和遗忘因子，不能从所测长反馈失败推出长 DFE 无效。
5 个确认 seed、8 帧也不能替代正式长期主比较。

正式比较前，应明确冻结传统方法集合及同步/边界协议，并接入统一 `compare.py`
入口，以相同轨迹、Pilot 预算和逐帧状态审计比较。新增参考尚未提升为主 baseline；
既有 Perfect-CSI 和 Fixed CG-BPSK-DD 仍保持诊断身份。神经调制结构的下一轮
研究应以这里确认的对照强度为约束，不能靠恢复较弱同步或错误循环边界获得优势。
