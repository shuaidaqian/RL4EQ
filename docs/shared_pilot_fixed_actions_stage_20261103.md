# 同波形固定动作的持续迁移归因

这是[正式共同状态RL的128帧检查](shared_neural_pilot_stage_20261103.md)的配对消融。那次平均与后期区间均跨零，而且384帧仅40帧执行small，没有执行medium。短窗四臂证据来自3步medium更新，所以需要把动作可迁移性与策略选择分开。

## 固定协议

实际环境seed110090–110092、10 dB、每条128帧，与已完成RL逐帧复现完全相同的当前和116样本后缀。独立fixed identity、fixed small、fixed medium三条分支从同一个普通监督64步checkpoint开始，状态独立，均使用8帧Adapt历史。开始一次acquisition，此后只用每帧前缀Pilot，整帧非因果块均衡不变。

固定选择器精确输出指定已有动作，不通过给学习策略设置大logit来近似。策略优化间隔设置为大于完整会话长度，逐帧断言没有PPO更新且动作未变化。small保持既有学习率.005、1步、窗口半径.2；medium保持学习率.02、3步、窗口半径.8；轨迹半径同为.8，梯度裁剪1。Reward Pilot逐帧守门和8帧窗口回滚均复用正式runner；没有取消回滚或改用Data选择动作。

每条分支的Data在本帧控制结束后才评分；其他分支事后算出的Data指标不传入控制。固定动作脚本把`uses_rl`与`policy_learning_enabled`明确记录为false，禁止计入主结果。identity必须复现原独立Frozen的逐帧BER；当前与后缀hash必须复现原比较波形。这些是已有会话上的归因消融，不是新的独立确认集。

评分仍以seed为单位：全会话Frozen−fixed BER、前后各42帧的后期减早期改善、记忆保留范数与窗口回滚。不按结果挑选seed或改变预设动作参数。

## 判断含义

- 若固定动作有持续收益而RL没有，才有依据优先检查策略选择、探索与合法反馈的学习；不能宣称固定动作已证明RL价值。
- 若固定动作也没有持续收益，短窗更新和持久记忆的迁移仍是问题，不能通过调PPO来回避；下一步需在训练范围分解持久状态、窗口年龄与Reward守门。
- 即使某个固定动作在本组三seed通过，仍需新的独立确认、四SNR覆盖、数百秒会话、新窗口传统校准与RL归因，不能登记总体完成。

脚本 `scripts/diagnose_shared_pilot_fixed_actions.py` 的多窗口单元测试覆盖精确固定动作、无PPO更新、Data标签毒化前后reward/守门/回滚/记忆一致。新诊断与正式共同状态相关30项定向回归通过（12.21秒）；此前全量862项、后续144项定向回归均通过，测试批次有重叠，不相加报告。

## 完整结果与结论

三个会话已全部完成，1152条记录，诊断主体墙钟540.296秒。[机器结果](results/shared_pilot_fixed_3s128f_10db_20261103.json)归档原始日志、配对RL日志与checkpoint SHA256，以及完整结束后的波形、固定identity、无PPO、标签隔离、半径审计。当前及后缀hash全部复现原RL输入，固定identity的逐帧BER全部复现原独立Frozen。

small与medium在全部三个seed的点估计都为正，但改善主要来自seed110091。small在三个seed分别改善+.02340/+.28178/+.02747 pp；medium为+.00814/+.28076/+.00814 pp。所有平均与后期区间仍跨零，不能替换为只报告正点估计，也不能换统计方法来追逐显著性。

small/medium分别2/3次窗口回滚，最大保留范数.30869/.57052，未触及全局.8半径。逐帧守门接受305/288帧（每臂384帧）；接受率不是Data收益的替代。固定动作没有PPO更新，也不具有RL方法地位。

固定动作的平均收益点估计高于本组RL，但这里没有为固定减RL额外建立成功门槛；既不能宣称RL优于固定动作，也不能由本组区间跨零断言固定更新无效。结果支持继续研究合法历史方程和神经记忆，却仍不足以扩大正式数百秒主矩阵。

下一步先在**训练范围**做持久状态有效期诊断：从一次acquisition开始推进真实连续轨迹，分开记录共同状态更新的即时Reward、下一窗口Reward和离线事后Data变化，核验“当前拟合有益”能否预测“保留到后续帧仍有益”。同时比较重复使用历史作为有限窗口优化目标与新信息递推的含义，不把滑动窗口优化误称为贝叶斯滤波。只有这一关系清楚后，才固定离线序列外层目标、预算和新的独立确认集。主方法仍为神经块均衡与离散安全RL，未更换成传统信道估计器。
