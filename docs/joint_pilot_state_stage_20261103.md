# 共同物理状态的后验等价性成立，历史 Pilot 预测出现迁移证据

总体目标尚未完成。这个阶段只回答[上一轮历史聚合失败](cross_frame_pilot_history_stage_20261103.md)留下的两个问题：多帧是否能约束同一个物理状态，以及联合 MAP 应如何计入先验。没有修改正式 PPO、没有重新训练 checkpoint，也没有用传统估计替换主方法。

## 从基本方程定义状态

对第 k 帧完全已知的 Adapt 行，观测是 `y_k = D(phi_k, f_k) X_k h_k + noise_k`。`X_k` 只包含已知 Adapt 发送符号；当前及后缀中混有未知 Data 回波的行不被冒充为已知方程。CIR 与公共相位存在旋转不唯一性：同时将 CIR 乘 `exp(i alpha)`、公共相位减 alpha，物理观测不变。因此聚合需要先声明以 acquisition 为锚的共同相位坐标，不能把各帧任意选取的复数坐标直接相加。

短历史内采用静态共同 CIR 近似时，复高斯后验的信息矩阵和信息向量是：

```text
Lambda = P0^{-1} + sum_k X_k^H X_k / noise_variance_k
eta    = P0^{-1} m0 + sum_k X_k^H y_corrected_k / noise_variance_k
h_MAP  = solve(Lambda, eta)
```

同一次 acquisition 的先验只出现一次。对每帧都带先验的目标求和或平均会重复该先验；行数和噪声不等时，还需要区分似然的归一化。对于时变状态，先按真实帧间距预测均值、协方差，再消费新的 Pilot 似然；不能把同一滑动窗口的观测再次当成独立新信息。

## 已完成的合成和隔离检查

新增 `evaluation/joint_pilot_state.py` 与 `scripts/diagnose_joint_pilot_state.py`，仅用于离线诊断：

- 117 复 tap、每帧108行、8帧的合成方程满列秩。一次先验的批量解与逐帧递推均值误差约 `3.08e-16`，协方差误差约 `1.90e-19`。
- 同时对观测与设计矩阵作一致的行相位变换，后验不变；只旋转观测却不处理物理相位，会破坏共同状态假设。
- 同一合成样本中，一次先验与重复8次先验的 CIR MSE 为 `1.37461e-4` 和 `1.64438e-4`，两解范数差 `.06914`；未校正相位时 MSE 为 `.02110`。这些是真值只供离线代数核验的反例，不是实际接收收益。
- 额外单元测试用不等行数、不等噪声和非对角先验核验静态等价；带 AR 漂移和跳帧的递推，与整段轨迹正规方程的最后状态边缘一致。
- 毒化历史/当前 Data、Reward 隐藏符号与非 Adapt 接收样本、仿真真实 CIR 后，Adapt 方程与神经记忆映射不变；模型权重不变。

相关124项回归通过（31.45秒）。这是早于后续共同神经目标新增测试的验证批次，不能把不同批次数字相加作为全量数量。

## 下一步已固定的神经状态消融

只诊断同一个神经记忆能否利用这类历史方程，不修改正式方法。实际环境 seed110080–110082，四个主 SNR，帧龄1023之后各8帧，窗口8；继续使用相同普通监督64步 checkpoint、3步AdamW、学习率.02、梯度裁剪1、记忆半径.8。

四臂为原单帧 MAP、旧8帧逐帧目标平均、共享当前神经 CIR但重复8次先验、共享当前神经 CIR且仅一次先验。后两臂将所有历史合法 Adapt 方程统一约束当前网络输出的同一个物理 CIR。梯度仍只更新现有神经记忆，不直接写入解析 MAP 解；Proposed 的神经块均衡与离散 RL 路线保持不变。

每个候选从同一 Frozen 出发，只在模型副本上优化。四臂的更新和当前 Reward Pilot BER/loss守门全部完成以后，才首次评分 Data，不按 Data 反选候选，不持久提交参数，不运行PPO。单帧的新目标须与现有 MAP 的值、梯度和更新后输出一致；历史 Data/Reward 隐藏标签毒化不得改变 Adapt 更新。

只有新目标出现可迁移证据后，才设计匹配的离线更新后训练和正式离散安全动作；不能从 Pilot 预测改善直接跳到数百秒主比较。新窗口传统重新校准、四SNR独立多seed主比较、连续后期优势与RL归因仍未完成。
