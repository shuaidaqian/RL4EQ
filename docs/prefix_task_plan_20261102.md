# Pilot 短窗任务的组件验证计划

神经符号残差改善了部分 SNR 的离线 Frozen，但全帧 Adapt 更新仍无可靠增量。
本轮只改变更新与验收的任务，不改变网络、权重、优化器强度或主配置。

## 运行前固定

- 源为符号残差 A256，SHA256：
  `605281acef3e9efe61e8d8354f6feb61b3324737eabff0a5ba3f75f43a6b7ecc`。
  选普通监督分支用于机制研发，不能把先前测试用于新确认。
- 配置 `configs/eme_long_memory_v2_symbol_transfer.json`，offline_train 新
  seed=47000–47002，各 4 帧，四主 SNR，48 上下文、4 组合共 192 记录。
- 更新任务：原整帧输入的 Adapt BCE；或截到 Adapt 末端的真实 224 点接收窗，
  只评分位置 116–223 的 Adapt BCE，避开前帧未知历史的直接贡献区。
- 验收任务：原整帧输入的 Reward；或截到 Reward 末端的真实 256 点接收窗，
  仍只评分 224–255 的 Reward 标签。条件估计始终仅来自 acquisition 和 Adapt。
- 两种更新分别复用给两种验收，候选只更新同一 17 参数神经 head，lr=5e-4、
  一步、半径 .05。每帧重置，不更新原权重，不累计、不执行 RL。
- 所有逐符号输入字段真正缩短，H/H^H 和覆盖率由实际输入长度构造。后部样本
  不零填充；Data 标签与发送符号不用于更新或验收。最终 Data 推理使用完整帧。
- 记录每组合相对同 Frozen 和原完整任务组合的 BER 增量、候选收益及有害验收。
  按 seed 计算探索性区间；无稳定收益则不扩大同配置留出矩阵。

短窗 Pilot 只模拟了有限接收窗覆盖，不等价于所有 Data 尾部误差。其头部历史、
条件估计及样本数量仍有差别。若出现收益，后续需要与此任务匹配的离线训练和
独立核验，不能直接纳入正式 RL 主结果。
