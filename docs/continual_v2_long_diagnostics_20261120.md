# P8 长程状态与同步机制诊断

P6 未保存状态和同步轨迹，P7 的 64 帧无法定位约 1200 s 会话内的 BER 回升。后续先补齐诊断，再以新登记 seed 观察长程行为。当前没有据此修正接收参数，也没有宣称研究目标完成。

## 合法统计与事后评分

比较入口新增显式 `--long-diagnostics`，流式 schema 为 3；未启用时仍为 schema 2。协议声明版本与命令不匹配会直接拒绝，不能将缺失诊断静默写盘。

- schema 2 的合法 Adapt 残差、预测能量、协方差迹、噪声和更新次数全部保留。
- 原本只在内存计算的 CIR 复标量对齐误差、仅相位对齐误差、估计与真实范数、Data BCE/Brier、高置信错误数现完整落盘。
- 从实际解码输入快照读取软 tail 功率、合法 phase0/CFO 和 CIR；不依据真值重建接收输入。
- 接收完成后，用实际逐符号相位和真实发送信号计算同步误差、有效信噪比、物理信道频谱平坦度、噪声实现功率，以及实际解码条件下的无噪声波形失配和观测残差。

只保存评分标量，不保存 Data 标签、真实 CIR 或相位数组。评分模块不被接收机导入；所有评分结果不回流状态、噪声、模型、tail 或下一帧处理。schema 3 的接收步骤时间不包含事后评分和落盘开销，不能据此作端到端实时验收。

## 相位规范及实际解码预处理

设解码 CIR 为 m，物理 CIR 为 h。公共相位可以被 CIR 吸收，因此不能直接将 Pilot phase0 减去物理相位当同步误差。先用 `arg(mᴴh)` 确定对齐规范，再合并真实逐符号相位和解码器实际校正。

实际校正通过冻结 eval 模型对单位复信号重算相同的相位预处理得到；包含 checkpoint 已学习的相位偏移与缩放，不使用只含 Pilot 特征的简化公式。不调用完整解码前向，不改变前向计数。当前不支持训练态、额外在线相位适配器或解码器内部 CIR 更新，以免评分遗漏处理环节。

在该规范下报告 Data 区的圆周残余相位均值、包裹角 RMS 和去公共相位后的 RMS。CIR 严重失配或内积接近零时，规范本身不稳定，必须结合波形失配判断，不能将单个相位评分独立解释为可归因同步误差。

无噪声波形失配使用实际 CIR、真实发送序列、实际逐样本相位，以及接收时快照的 CIR、软 tail 与相位校正。它同时包含状态和同步失配，不是将两者独立分解的因果证据。频谱平坦度仅描述信道形状，不是 BPSK 最优 BER 下界，不能据此宣布目标不可能。

## 验证与实验顺序

全量测试 **264 passed in 40.39s**。定向验证覆盖：CIR 相位规范变化、非零已学习相位偏移与缩放、幅度失配保留、从实际接收到 schema 3 的完整保存、缺字段拒绝；污染事后真值不改变模型、接收状态、调用计数和下一次解码输出。

先按 [P8a 短会话协议](protocols/continual_v2_long_diagnostic_smoke_dev_20261120.json)，使用新 seed 236001、CPU、四 SNR、8 帧、三臂验证实际入口，共 96 行。此步骤仅验证诊断链路与运行资源，不按 BER 选择或调节方法。完成后冻结长程诊断协议，保留 acquisition Frozen、当前 Pilot 和修复 AR(1)；同一会话持续处理全部帧，不能以稀疏抽帧替代实际递归轨迹。

长程开发只能用于机制判断。四 SNR 自身 BER 改善、相对优势增长至饱和并保持、离线神经协同和新独立确认仍分别需要证据。
