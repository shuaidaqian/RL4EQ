# P8 长程状态与同步机制诊断

P6 未保存状态和同步轨迹，P7 的 64 帧无法定位约 1200 s 会话内的 BER 回升。后续先补齐诊断，再以新登记 seed 观察长程行为。当前没有据此修正接收参数，也没有宣称研究目标完成。

## 合法统计与事后评分

比较入口新增显式 `--long-diagnostics`，流式 schema 为 3；未启用时仍为 schema 2。协议声明版本与命令不匹配会直接拒绝，不能将缺失诊断静默写盘。

- schema 2 的合法 Adapt 残差、预测能量、协方差迹、噪声和更新次数全部保留。
- 原本只在内存计算的 CIR 复标量对齐误差、仅相位对齐误差、估计与真实范数、Data BCE/Brier、高置信错误数现完整落盘。
- 从实际解码输入快照读取软 tail 功率、合法 phase0/CFO 和 CIR；不依据真值重建接收输入。
- 接收完成后，用实际逐符号相位和真实发送信号计算同步误差、有效信噪比、物理信道频谱平坦度、噪声实现功率，以及实际解码条件下的无噪声波形失配和观测残差。

只保存评分标量，不保存 Data 标签、真实 CIR 或相位数组。评分模块不被接收机导入；所有评分结果不回流状态、噪声、模型、tail 或下一帧处理。schema 3 的接收步骤时间不包含事后评分和落盘开销，不能据此作端到端实时验收。

## 相位规范及实际解码预处理

设解码 CIR 为 m，物理 CIR 为 h。公共相位可以被 CIR 吸收，因此不能直接将 Pilot phase0 减去物理相位当同步误差。先用 `arg(mᴴh)` 确定对齐规范，再合并真实逐符号相位和解码器实际校正。

实际校正通过冻结 eval 模型对单位复信号重算相同的相位预处理得到；包含 checkpoint 已学习的相位偏移与缩放，以及已审计的确定性 `OnlinePhaseTrendAdapter`（加载器默认挂载恒等版本），不使用只含 Pilot 特征的简化公式。不调用完整解码前向，不改变前向计数。当前不支持训练态、未知额外相位适配器或解码器内部 CIR 更新，以免评分遗漏处理环节。

在该规范下报告 Data 区的圆周残余相位均值、包裹角 RMS 和去公共相位后的 RMS。CIR 严重失配或内积接近零时，规范本身不稳定，必须结合波形失配判断，不能将单个相位评分独立解释为可归因同步误差。

无噪声波形失配使用实际 CIR、真实发送序列、实际逐样本相位，以及接收时快照的 CIR、软 tail 与相位校正。它同时包含状态和同步失配，不是将两者独立分解的因果证据。频谱平坦度仅描述信道形状，不是 BPSK 最优 BER 下界，不能据此宣布目标不可能。

## 验证与实验顺序

初版全量测试 264 passed；真实入口发现加载器默认挂载恒等相位适配器，被初版诊断过度拒绝。修正评分以覆盖该确定性旋转，并增加恒等及非零适配器测试后，全量测试 **268 passed in 31.09s**。定向验证还覆盖：CIR 相位规范变化、非零已学习相位偏移与缩放、幅度失配保留、从实际接收到 schema 3 的完整保存、缺字段拒绝；污染事后真值不改变模型、接收状态、调用计数和下一次解码输出。

首次 [P8a 短会话协议](protocols/continual_v2_long_diagnostic_smoke_dev_20261120.json) 使用 seed 236001，在首次事后评分时失败，0 条性能记录。失败结果与 seed 保留，不覆盖或重跑。修复后按[新入口协议](protocols/continual_v2_long_diagnostic_smoke_v2_dev_20261120.json)改用独立 seed 236002，CPU、四 SNR、8 帧、三臂，共 96 行。此步骤仅验证诊断链路与运行资源，不按 BER 选择或调节方法。完成后冻结长程诊断协议，保留 acquisition Frozen、当前 Pilot 和修复 AR(1)；同一会话持续处理全部帧，不能以稀疏抽帧替代实际递归轨迹。

长程开发只能用于机制判断。四 SNR 自身 BER 改善、相对优势增长至饱和并保持、离线神经协同和新独立确认仍分别需要证据。

## 完成后分析工具补充

P8 运行期间只修改未被接收入口导入的离线分析工具，不改其算法源码。`audit_long_diagnostics.py` 现先逐帧计算仅相位对齐 CIR 绝对平方误差、Pilot 残差/预测能量比，以及使用真实总功率和噪声的全能量宽松额外信息下界，再按预登记窗口平均。不能用窗口平均 NMSE 乘平均功率代替平均平方误差，不能把平均能量之比当成平均逐帧能量比，也不能在平均功率上计算非线性下界冒充平均下界。

该补充通过四项定向测试，并用已完整完成的 P8a 重建审计成功；没有分析 P8 中途 BER，也没有更改其在线步骤。新增下界未计帧末截断，明确不能称精确帧内边界。Pilot 比值同样不具有已证明的卡方校准解释。

P8 全部完成后的统一命令为 `scripts/report_long_mechanism.py --result <主结果JSON>`。程序先要求结果 completed，再重新执行完整审计，按全部预登记会话/窗口输出配对 JSON 和 Markdown。所有相邻窗口分别保留 ΔOnline、Δ基线和 Δ增益，满足 Δ增益=Δ基线−ΔOnline；不把 Frozen 退化解释为自身改善。包裹相位均值不跨会话算术平均。缺会话、缺窗口、重复汇总或实验未完成会拒绝输出，分析源码指纹另行保存。该流程只用已完成的 8 帧 P8a 核验，没有分析运行中 P8；五项新增防误判测试通过。
