# 正式 RL 窗口机制可执行，128 帧在线与后期收益未通过

按[固定协议](channel_memory_rl_protocol_plan_20261102.md)完成实际环境 seed 100010–100012、四 SNR、各 128 帧的开发验证：**1536 个同波形配对帧、7680 条五方法记录**。只有会话开始一次 acquisition，随后每帧 prefix256（Adapt224 / Reward32）。来源、原始日志 SHA、冻结传统协议和进程耗时完整保存在[机器摘要](results/channel_memory_rl_protocol_128f_3s_20261102.json)。

结论是：正式离散记忆 RL 确实执行并保留过更新，但没有建立四 SNR 的在线 BER 增益，短会话后期优势也未通过。不扩大同一短矩阵来追逐显著性，不根据 Data 改动作、阈值或 checkpoint。

## 与独立 Frozen 的配对结果

Frozen 与 RL 使用同一固定控制 checkpoint，SHA256 `153ccc68515fe77996f822924f0056d25a283ca0fd7b185c19a030bfe2871f08`，固定 34 个尺度和其余离线权重，在线只允许记忆动作更新 234 个参数。窗口 8 帧、PPO 更新间隔 32 帧，累计半径 0.8。

BER 为百分数，改善为百分点；正值表示 RL 优于独立 Frozen。95% 区间以三个独立信道 seed 的会话均值为单位，用配对 t 区间计算。这是训练范围的开发诊断，不能替代新的独立留出主验证。前/后各取 42 帧。

|SNR|Frozen BER|RL BER|平均改善 [95% CI]|后期减早期改善 [95% CI]|
|---|---:|---:|---:|---:|
|0 dB|18.89513%|18.87750%|+.01763 [−.07158, .10684]|+.05374 [−.23177, .33924]|
|5 dB|3.29725%|3.30811%|−.01085 [−.13216, .11045]|−.01240 [−.22845, .20365]|
|10 dB|.31094%|.31365%|−.00271 [−.02926, .02383]|−.01963 [−.03567, −.00360]|
|15 dB|.08070%|.08477%|−.00407 [−.01944, .01130]|−.00930 [−.04932, .03072]|

四 SNR 平均改善区间均跨零；10 dB 的后期差值在该开发矩阵中为负。不能用“有正 Reward 窗口”替代 Data 泛化，也不能把比传统方法更好的离线基础性能写成在线微调的功劳。

## 控制链路与信息边界

- 每 SNR 执行 12 次 PPO 更新，总计 **48 次**。192 个动作窗口中，29 个为记忆动作；232 次逐帧记忆尝试中，111 次通过当帧验收。
- **11 个正 Reward 窗口、18 个窗口回滚**；逐帧接受不等于窗口结束后继续保留。验收后最大累计范数为 0.800000012，处于 float32 投影容差内。
- 新[窗口记账诊断](results/channel_memory_rl_reward_accounting_128f_3s_20261102.json)从 Pilot 日志精确重建全部 192 个 reward。4 个窗口的正 Pilot 净收益被成本抵消；没有据此修改成本系数，也没有把这些候选当成已知有 Data 收益。
- 同帧五方法接收波形 SHA 相同；传统方法冻结协议一致，不使用神经网络、RL 或隐藏标签。RL 显式声明整帧接收波形可用于 Reward 判决，但 Data 发送符号/标签不进入在线控制。真实隔离性质由跨两个 PPO 窗口污染测试支撑。

正式核心全量回归 **807 passed，416.82 秒**；后来新增/更新的汇总与诊断定向 **21 passed，4.76 秒**，两者重叠，不相加冒充新的全量测试数。

## 耗时与接续

完整有效研究进程分别为 **467.58 秒**（一个 seed）和 **905.34 秒**（另两个 seed），合计 **1372.92 秒**，包含模拟、五方法、重复诊断前向、评估和写文件；不是部署每帧时延。明确使用既有 FFT 后端；修复前的旧运行和未完成 direct 运行均未混入统计。`latency_ms=0` 仍是历史占位字段，不可作为实时证据。

128 帧仅覆盖 13.1072 秒，相对 1200 秒相干时间，不能单凭该短时段推断数百秒跟踪。按[已登记的持续探测计划](channel_memory_rl_continuous_plan_20261102.md)，下一步固定新 seed 100013、10 dB、2048 帧（209.7152 秒）从首帧持续运行，同轨迹配对独立 Frozen；不改变反馈规则。它是限定问题的机制探测，不能替代四 SNR 主比较，也不能把单 seed 描述值写成独立 seed 显著收益。
