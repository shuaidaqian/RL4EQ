# 在线微调独立确认判据草案（2026-11-05）

> **已被[confirmation_criteria_v4_draft_20261106.md](confirmation_criteria_v4_draft_20261106.md)取代（2026-11-06）。** 本文件保留原语义；v4 草案加入了统计功效、最小 session 数、软边缘化数据似然与 S-DANSA 阶段的设计输入。两者均未冻结，不能用于正式确认。

## 目的与当前状态

本草案把研究的核心假设写清楚：在线微调必须比同一离线预训练网络的冻结版本获得更好的均衡性能，才能支持研究主张。“不能更差”只是必要的安全约束，单独满足它不代表研究成功。本草案不是已批准的正式预注册，也不授权运行独立确认实验；正式确认仍需冻结统计方法、会话协议、样本量和停止规则。

## 已确认要求

- 核心对照为**同源离线预训练网络的冻结版本**；冻结网络与在线网络使用相同合法观测、Pilot预算、接收窗口、acquisition、同步补偿及物理状态跟踪。
- 在线分支只能用合法接收波形及Adapt/验证Pilot更新、选择、验收或回滚；不得使用Data标签或仿真隐藏信道真值做在线控制。
- 0/5/10/15 dB四点均保留并完整报告，不根据开发结果选择或删点。
- 在线微调的BER不可比冻结网络差。以每个SNR的配对绝对BER差定义：

  `差值_snr = BER_online_snr - BER_frozen_snr`

  允许的最大退化量为 **0**。负值表示在线微调较好，正值表示退化。
- 核心成功还必须有统计证据证明在线BER优于冻结网络。零退化约束只是护栏；若只证明“不劣”或结果没有显著差异，结论应是“在线增益未证实”，不能称研究目标完成。

## 建议的统计操作化（待正式冻结）

建议以独立信道/完整会话为统计单位，预注册在线相对冻结网络的主要优越性效应及其检验。由于0/5/10/15 dB均为主要运行点，一个可审查的候选主效应是四点等权平均的绝对BER改善 `mean(BER_frozen - BER_online)`，并要求单侧置信下界大于0；同时逐SNR报告效果，并把零退化作为每点安全约束，使用预先指定的多重比较方法检验。此为统计设计建议，等权聚合、置信水平及多重比较方法尚待正式冻结。若主效应不能证明大于0，即使四点都未观测到退化，也只能判为“增益未证实”，不能判为核心成功。

每SNR零退化界限是严格护栏：当某个SNR真实效果接近相等、错误极少或会话间差异较大时，可能需要很大样本量才能把退化上界压到0以下。15 dB尤其要按独立会话中的实际错误数和目标精度估样本量，不能把bit数或帧数当独立重复。若实验预算无法达到所需精度，应报告证据不足，不能事后放宽界限。超越冻结模型的主效应检验也必须有足够功效；“未显著变差”不等于在线更好。

## 仍待冻结的内容

1. “确有改善”的主效应定义：整体四SNR配对效应如何聚合，以及是否要求特定SNR单独证明优越。
2. 单侧置信水平、逐SNR与整体检验的多重比较控制方法。
3. 会话长度、信道seed/独立会话定义、漂移轨迹及稳态/恢复窗口。
4. 每个SNR所需独立会话数及样本量/精度计算方法，特别是高SNR低误码场景。
5. 停止、无效运行、重测规则，checkpoint冻结方式及计算资源预算。
6. 应用频段、带宽、目标吞吐/BER及物理标定。它们决定结果的应用范围，但不能用于事后修改本轮仿真里的零退化要求。

## 决策边界

在以上项目冻结前，只能继续开发集机制设计、实现检查和样本量规划；不得查看新的独立确认结果来选模型、调阈值或修改规则。所有0/5/10/15 dB结果、逐seed/会话表现、有害更新和计算成本均需报告。若任何SNR的确认结果不能满足零退化要求，在线微调方案即未通过当前核心验收；应回到离线表示、更新目标或在线更新机制重新设计。
