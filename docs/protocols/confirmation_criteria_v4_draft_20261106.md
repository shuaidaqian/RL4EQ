# 正式确认判据草案 v4（2026-11-06）

> 状态：**草案，未冻结**。本文件只给出可执行的候选方案与必须补齐的空缺；在主要区间、效应量、统计方法、样本量、会话/漂移定义、停止规则和 checkpoint 冻结前，不启动独立确认集。

## 1. 目标与范围

在 Level B `eme_long_memory_v2`（116 符号记忆、1024 符号帧、prefix Pilot=256：Adapt=224、Reward=32、0/5/10/15 dB、准静态 1200 s）上，检验：

2026-11-06 用户决策后，当前确认的是**物理在线适配主张**：

- **H1（核心优越性）**：四个主要 SNR 等权平均的配对 BER 改善
  `Δ = mean_s(BER_frozen,s − BER_bayes,s)`
  显著大于 0。Frozen = 同源 checkpoint + acquisition CIR + 同一 dd_soft tail；Bayes = 同一 checkpoint + 贝叶斯递归 CIR 后验。神经权重两臂冻结。
- **H2（安全护栏）**：每个主要 SNR 的配对差 `δ_s = BER_bayes,s − BER_frozen,s` 不显著大于 0；允许退化量为 0。
- **H3（持续增长）**：同一会话内，固定窗口的 `gain_w = BER_frozen,w − BER_bayes,w` 总体随帧龄增加；会话级斜率与末窗减早窗为正。
  - 10×64 开发筛查：5/10/15 dB 的 first16→last16 增长；0 dB 点估计大但 last16 略低于 first16，增长假设在 0 dB 不成立/不稳定。确认时逐 SNR 报告，不用四 SNR 平均掩盖。

**神经参数微调子主张（独立）**：在共享 Bayes CIR 下，Online 额外更新神经参数；其相对 Bayes Frozen 的增量另行检验，不与上述物理确认混合。

统计单位是独立 session；帧、bit、窗口不得冒充独立样本。H1/H2/H3 均需完整报告四个 SNR，不按开发结果删点。

## 2. 设计

- **对照**：同源 checkpoint、同一 acquisition CIR、同一 dd_soft tail 规则、同接收窗口、同 Pilot 预算、同 acquisition 与同步补偿。
- **Bayes**：贝叶斯递归 CIR（acquisition 先验 → Pilot 后验 → Data soft 后验）；神经权重冻结；后验协方差跨帧持久。
- **会话**：每个 session 至少 128 连续帧；同一 session 内 Frozen 与 Bayes 使用完全相同波形、seed、信道实现与 tail 规则。
- **数据角色**：Adapt Pilot 更新；Reward Pilot 动作后门控/验收；Data 标签只用于离线外层、离线选择/校准与事后评分。在线分支不得读取 Data 标签、真实 CIR/相位/CFO。
- **归因**：物理主张的 A/B 是 acquisition CIR（Frozen）与 Bayes CIR（Online）；神经子主张的四臂是共享 Bayes CIR 下的 Frozen/Online × A/B 训练，同数据、同预算。不把 Bayes CIR 的物理增益写成神经参数增益。

## 3. 统计方法（候选）

### 3.1 主效应 H1

- 每个 session 计算四个 SNR 的 `Δ_i`（等权平均）；以 session 为独立单位。
- 主检验：单侧配对 bootstrap 或单侧 t 检验（`H0: Δ ≤ 0` vs `H1: Δ > 0`），α=0.05。
- 若方差/分布明显非正态，使用 session 级 bootstrap（至少 10,000 次）并报告中位数与 BCa 区间。
- 效应量：绝对 ΔBER 与相对下降；同时报告每 SNR 的 `Δ_s`。

### 3.2 安全护栏 H2

- 每个 SNR 计算 `δ_s` 的会话级均值与单侧上置信界。
- 预注册"实际等价/允许退化"界：当前契约为点估计不退化（`δ_s ≤ 0`）；统计上建议用单侧 95% 上界不超过 0，或预先声明一个非零但可忽略的等价界（需用户冻结）。
- 多重比较：四个 SNR 用 Holm 或 BH 控制；H2 与 H1 分开报告，不用平均掩盖单点退化。

### 3.3 增长 H3

- 固定窗口长度（候选 16 帧；需在 P3 前冻结），每 session 内计算 `gain_w`。
- 会话级斜率：对窗口索引做最小二乘/稳健回归；报告斜率、末窗减首窗、末窗 `gain`。
- 汇总：混合效应模型（session 随机截距/斜率）或 session 级斜率的单侧检验；四 SNR 分别报告，并给出等权平均。
- 允许随机误码导致局部窗口回升；不以逐帧严格单调为门槛，但"全程平均"不能掩盖增长趋势失败。

## 4. 样本量

依据[功效与错误构成](../results/power_error_composition_20261106/README.md)（α=0.05 双侧、80% power、session 级配对 t 检验、128 帧/session）：

| SNR | 建议独立 session | 可预注册最小 ΔBER | 备注 |
|---:|---:|---:|---|
| 0 dB | 30–35 | 1e-3 | 设计效应约 90.7；1e-4 需约 1,500–3,200 session，不可行 |
| 5 dB | 10–15 | 5e-4 | 1e-4 需约 76–209 session |
| 10 dB | 20–25 | 2e-4 | 1e-4 需约 11–23；1e-5 需约 795–2,074 |
| 15 dB | 10–15 | 1e-4 | 1e-5 需约 141–626 |

通用下限：至少 10 个独立 session，每 session 至少 128 帧。n=3 时 df=2、t 临界值 4.303，即使标准化效应 d≈2.4 也只有约 58% 功效；不得用 3 session 做确认。

**10×64 开发筛查更新（2026-11-06）**：观测效应量为 0/5/10/15 dB `+0.0351/+0.00575/+0.00155/+0.00013`，10 seed 描述性 95% 区间均不跨零，远大于上表的最小目标。确认样本量可按观测方差重算；建议首轮 10–15 独立 session × 128 帧覆盖四 SNR，0 dB 视方差扩到 20–30。最终值在 P3 冻结。

最终样本量需在 P3 开发筛查后用观测到的 session 级方差重算，并在 P4 前冻结。若真实目标仍是 1e-5，必须在协议中明确"0/5 dB 不可判定"，或先接受更大的预注册效应。

## 5. Checkpoint 与停止规则

- **冻结**：P3 结束、P4 开始前冻结配置、checkpoint、状态超参数、门控、窗口长度、主效应与统计方法；确认集 seed 与开发 seed 严格隔离。
- **停止/回退**：若 P1 机制 smoke 无可重复正点估计，不扩 P2/P3；若 P3 主效应不显著或任一 SNR 点估计退化，不启动 P4；若确认集出现失稳/有害更新，按预注册规则停止并报告，不调参重跑。
- **选择偏差**：不得在确认集上选择 checkpoint、阈值、窗口或 SNR；开发集不得反复当作确认集。
- **重测**：只允许一次预注册确认；失败后若改方法，必须重新走 P1–P3，不能在同一确认集上重测。

## 6. 必须报告

- 四 SNR 的逐 session BER、配对差、绝对/相对改善、置信界。
- 窗口 `gain_w`、会话级斜率、末窗减早窗、稳态 BER、漂移后恢复。
- CIR NMSE（Frozen/Bayes/真实 CIR oracle）、后验协方差迹/条件数、每帧使用的 Data 行数与有效权重。
- Bayes 超参数：acquisition 先验 ridge、过程噪声 `Q`、Data 行噪声尺度；不得按真实 SNR 调度，只能用合法估计/置信度。
- 计算量、每帧延迟、内存；Frozen 与 Bayes 的实际计算差异。
- 标签隔离证据：在线分支未读 Data 标签/真实状态；Data 只用于离线与事后评分。
- 神经子主张另行报告实际神经参数数、每帧更新次数、参数位移/累计半径、接受/拒绝/回滚次数。
- 失败/异常会话、失稳、OOM、数值异常；不用计划代替未运行的结果。
