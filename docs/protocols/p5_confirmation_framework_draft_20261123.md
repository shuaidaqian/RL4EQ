# P5 独立确认框架（草案，2026-11-23）

状态：**草案，未冻结，未分配任何新 seed**。本文只整理待用户确认的协议要点，不替换[研究路线](../研究点二_第一性原理审视与研究路线_20261119.md)，也不构成确认。所有数值窗口、效应阈值与样本量在冻结前均需用户确认。

## 1. 主张与估计量

每个 SNR 分别报告，不做等权平均：

| 主张 | 估计量（session 级） | 成功条件 |
|---|---|---|
| 自身改善 | `own_gain = O_平台 − O_早期` | 配对均值的双侧置信区间完全低于 0，且超过预设最小实质效应 |
| 优势增长 | `adv_gain = G_平台 − G_早期`，`G=F−O` | 配对均值区间完全高于 0，并单独报告 F 与 O 曲线 |
| 与匹配当前 Pilot 的增量 | `(B−O)_平台 − (B−O)_早期` | 区间完全高于 0；B 为匹配老化当前 Pilot |
| 饱和/保持 | 晚窗与平台窗的差 `O_晚−O_平台`、`G_晚−G_平台` | 双侧 TOST 在预设等价边界内，并维持预定时长 |

- **相对 Frozen 的优势不能替代自身改善**：Frozen 后段退化会放大 G；三项主张分开报告。
- 绝对与相对估计量同时报告，并附错误数；10/15 dB 以相对/错误计数为主，绝对量的“小 n”不作成功依据。

## 2. 会话与轨迹设计

1. 统计单位是独立 session（一个 seed 一条接收轨迹）；帧不是统计单位。
2. 真实信道轨迹由 seed 决定且跨 SNR 共享；P11 的 6 条轨迹中 4 条晚段 ESNR 下降、2 条上升，说明单组轨迹会把信道变化误读为方法变化。
3. **预登记多轨迹**：在任何 BER 产生前，用冻结的生成器/动力学文件为候选 seed 计算轨迹描述（分窗真实 CIR 范数、有效 ESNR、频谱平坦度），按晚段走向分层并平衡；选择只依据信道生成器，不依据 BER、NMSE 或任何接收结果。
4. 候选 seed 必须先在 `docs/protocols/continual_v2_seed_registry.json` 中登记；已用于开发或确认的 seed 不得复用。
5. 每个 SNR 的 session 数由功效规划确定（见 §4），不得看到中间曲线后增减。

## 3. 窗口与时间行为

- 窗口必须在开发阶段冻结，确认阶段不得搜索或更改。
- 草案候选：早期 `[64,256)`，平台 `[1024,2048)`，晚窗 `[4096,8192)` 与 `[8192,11719)`；观察长度 11,719 帧（约 1,200 s）。
- 同时报告首帧、细早期窗口和完整窗口曲线；累计曲线只作展示。
- 增长、饱和与保持分别判定：相对优势继续扩大但自身已平台，不能写成共同饱和。

## 4. 最小实质效应与样本量（待确认）

用 P11 六个开发 session 的方差估计（[功效规划](../results/continual_v2_p5_planning_20261122/README.md)）：

| SNR | own_gain 观测均值 | 观测效应所需 session | 0.005 绝对边界所需 | 建议最小效应候选 |
|---:|---:|---:|---:|---|
| 0 dB | −0.00713 | 134 | 269 | 0.005 绝对 + 10% 相对 |
| 5 dB | −0.00255 | 260 | 69 | 0.005 绝对 + 10% 相对 |
| 10 dB | +0.00002 | 40,125 | — | 10–20% 相对 + 错误计数 |
| 15 dB | +0.00008 | 53 | — | 20% 相对 + 错误计数 |

- n=6 的方差很宽；若用 80% 置信上界，所需 session 约 ×2.1。
- 若某 SNR 的可行样本量不足以检出预设最小效应，应**预先**降低主张强度或宣布该 SNR 不可确认，不能事后挑选窗口或轨迹。
- 10/15 dB 需要更长会话（更多帧）或更多 session；不得用绝对边界把“几乎为零的变化”包装成等价。

## 5. 统计与停止规则

1. 配对 session 统计；报告均值、sd、双侧 95% 区间与错误数。
2. 固定样本量与固定窗口；禁止基于中间 BER、诊断或运行速度的停止/延长。
3. 多重性：4 个 SNR × 3 项主张需要在开发阶段选择层级门控或 Holm 校正并冻结。
4. 饱和用 TOST，等价边界与检验方向预先写死；不得把“不显著”当作等价。
5. 允许单会话、单帧随机波动；不允许删除不利 session 或 SNR。

## 6. 报告与信息边界

- 必须报告：每 SNR 每 session 的 F/O/B 曲线、own/adv 量、错误数、真实有效 ESNR（仅事后诊断）、轨迹分层标签。
- 在线信息契约不变：在线只使用已接收波形、Adapt Pilot 已知符号、模型 soft 输出及其派生的 CIR/CFO/相位/tail；真实 CIR/ESNR、Data 标签、Reward 内部回流、未来帧标签一律不进入接收链路。
- 轨迹分层所用的真实描述只用于设计和事后报告，不进入任何在线输入。

## 7. 未决事项（需用户确认）

1. 三项主张的最小实质效应数值，以及 10/15 dB 的相对边界。
2. 每 SNR 可接受的 session 数上限；若功效不足，选择降低主张还是延长会话。
3. 轨迹平衡的具体规则：分层变量、层数与每层配额。
4. 窗口与观察长度是否沿用 11,719 帧。
5. 多重性控制方式与确认集一次性运行的组织方式。

在上述事项冻结前，不登记 P5 确认 seed、不启动任何确认运行。
