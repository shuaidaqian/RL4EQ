# 复数状态记忆的固定诊断计划

本阶段继续“离线训练适应信道，在线微调均衡”，不是正式 RL 成功证据。共同源为长年龄 B64，SHA256 `919ca4c6e99c5c44519c1b381e44baa4b923e204c1daccc56da339b50a6ab71e`。

## 基本事实与待证假设

旧 17 参数 gate 的 CIR 响应能量集中在一个方向；增加参数只能扩大可达空间，不能自动解决 108 个已知复卷积行对 117 个复 tap 的辨认问题。新 head 保存 117 个复残差，在线共 234 参数，离线尺度映射 34 参数。记忆严格零初始化，任何尺度改变均应保持源 Frozen 输出逐项相同。旧 gate 与全部旧权重冻结。

假设是：用合法 Adapt 构造的受限复记忆候选能产生实际收益，再由离线更新后目标学习尺度。不能用 Data 导数生成或选择在线候选，也不能靠降低 Frozen 制造在线增益。

## 固定顺序

1. 完成隔离、严格迁移、实际 AdamW 对照及当前/未来二阶有限差分测试；CUDA 两步 smoke。
2. 复用原长年龄训练缓存，固定每 SNR/年龄第一个样本，共 20 个，明确不是独立泛化。只检查容量和合法候选，不根据 Data 选择动作。
3. 两个目标分别为 signal、MAP；两个预定动作：small（lr .005，一步，raw 半径 .2）与 medium（lr .02，三步，raw 半径 .8）。输出尺度 .25；报告真实 CIR 步长，不能把 raw 参数半径当物理步长。
4. Reward 只用动作后的 Reward Pilot BER/信号 loss，沿用现有 guard，不含 MAP prior penalty；四个候选独立从同一个零记忆起点产生，不挑事后最佳者。
5. 容量筛查有作用才进入新 offline_train seed 验证及固定预算离线尺度学习；若失败，先定位 Pilot 辨认/目标问题，不直接增加留出 seed 或 RL。

所有运行保留一次会话开始 acquisition、后续仅前缀 Pilot 的边界。缓存包含离线标签，但候选函数不读取隐藏标签；Data 只在所有 guard 决策完成后用于评分。每个样本独立重置记忆；本诊断不验证持续学习。A 是固定尺度控制，普通未更新监督对尺度的梯度为零，不描述成能够学习的普通监督对照。

正式门槛仍是四 SNR 逐配置优于校准传统 baseline、相对同 checkpoint Frozen 独立 seed 正区间、持续会话后期优势更明显，并最终接入离散安全窗口 RL。
