# 现有神经相位分支的实际作用范围

本说明根据代码推导，不使用新留出测试结果选择方案，也不修改网络或正式动作。
研究目标和信息边界保持不变。

## 参数个数不等于可修正的状态维度

`UnfoldedEqualizer._apply_phase_correction` 对固定一帧条件 z 执行的校正为：

```text
b(z; theta) = median_j(phi_hat_j + f_j(z; theta))
nu(z)      = median_j(nu_hat_j)
psi(t)     = a * [b(z; theta) + 2*pi*nu(z)*t]
y_corr(t)  = y(t) * exp(-i*psi(t))
```

其中 f 是已有相位 MLP，a 是 `phase_correction_scale`。本轮相位特征来自
acquisition CFO 与当前 Adapt Pilot；各块使用相同全局相位和 CFO 估计，附加
局部残差方差及能量。没有用真实 CFO、真实 CIR 或 Data 标签构造条件。

在固定条件、median 选中分支不变的局部，MLP 参数对整帧校正角的导数是常数；
只有 a 的导数包含随时间线性变化的项。因此，此分支的逐帧相位修正始终属于
`span{1,t}`，局部有效维度至多为 2。即使 median 选中分支变化，有限变化后的
校正轨迹仍是仿射直线。6469 个参数可以学习复杂的条件到系数映射，但不等于
6469 个独立的逐帧相位修正方向。

该分支并非完全不能修改 CFO：当 nu 非零时，a 同时改变公共相位和 CFO；
MLP 又可改变公共相位，所以两者联合可能提供两个局部方向。准确的限制是：
MLP 本身没有独立的 CFO 输出；当 nu=0 时，整个分支不能产生非零斜率校正。
非线性的帧内相位创新、CIR 支持误差和历史尾误差也不在此校正族内。

## 这对实验判读意味着什么

相位组比 head 更能改变 Data 连续输出，只证明作用位置不同。要证明适配成立，
还需证明该位置覆盖实际主误差，且 Adapt 的更新方向能外推到 Data。低维物理
作用本身不是缺点：前缀 Pilot 有限，可辨认的状态也可能低维；关键是作用族与
可观测误差是否匹配。

既有中位数在并列点不可微；autograd 使用选定坐标的导数。当前有限差分核验
覆盖外层相位尺度，不能把它表述成对所有 MLP 参数和所有中位数切换点的证明。
真实 AdamW 候选逐参数数值对照验证的是更新复现，不是所有高阶导数的全局正确性。

## 若现有分支的固定预算实验失败

先停止扩大同一配置的矩阵，保留失败结果。结构选择确定后，下一轮先在训练范围
的新 seed 上比较可见信息与实际神经调制的作用方向，再决定实现：

1. 区分当前 Pilot 可估的公共相位、斜率偏差与前缀之后新增的随机相位创新。
   后者不能仅靠增大 PPO 预算变成可预测信息。
2. 若主要误差是可估的公共相位/斜率，评估独立系数的神经 Adapter/head；
   若主要误差是 CIR 或未知历史，则相位分支不足，应评估对应神经残差位置。
3. 若改变输出族，先固定同 checkpoint Frozen 和普通监督对照、训练预算、
   新的独立 seed 与失败退出条件；不得沿用已看过的留出结果挑选结构。
4. 有稳定单次迁移后，再进行跨帧累计与离散安全 RL 的窗口调度消融。

这只是有条件的重新设计顺序，不声称新结构必然成功，也不把纯物理两个标量的
更新结果替代神经 PEFT 的机制证据。
