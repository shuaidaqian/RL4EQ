# 长期状态下 Adapt/Reward 窗口的两因素诊断

长期年龄诊断的 5 dB 最晚年龄存在两个 Data 有益候选，被 32 bit Reward 增加
一个错误拒绝；但信号 loss 本身也曾排序失配。不能据此直接移除 BER guard。
下一步在新训练轨迹，分离梯度降噪与反馈降噪，检验最终窗口动作所需前提。

- 固定 future B256、主信道及全部 impairment 参数，不重新训练、不更换 guard。
- 新 offline_train 92000–92002、四 SNR，连续生成 4096 帧，只在
  127/1023/2047/4095 帧评分，共 48 当前上下文。
- 预先固定 2×2：Adapt 窗口 1/8，Reward 窗口 1/8。窗口都截至当前帧、只含
  已接收历史；两种候选都从离线参数起点，用相同 medium .02、3 步、半径 .2。
  同一候选参数作用于其 Reward 窗口中的所有帧；Reward 平均 BER 与平均
  前向信号 loss 使用原 guard，不改阈值和优先级。
- Reward Pilot 不进入梯度。每个年龄重置参数，不是连续神经会话。窗口读取
  整帧接收波形，未知发送符号和 Data 标签始终隔离。
- 四种规则全部先完成决策，然后只在同一个当前帧评分 Data，保持窗口间配对。
  共 192 行候选/验收记录。额外历史 Data 标签不进入控制或梯度。
- 逐 SNR×年龄报告全部四格，并报告仅改 Reward、仅改 Adapt 的配对差值；
  独立 seed 为统计单位。不根据 Data 挑一个规则替换正式控制器。
- 若 Reward 聚合不能改善排序，不扩大相同留出矩阵；如有线索，还需训练范围
  重复确认与匹配长年龄离线训练，再预注册独立连续跟踪和正式离散 RL。
- checkpoint 的长年龄外推仍是限制。当前诊断不能替代数百秒完整会话、传统
  baseline 比较或最终成功标准。

脚本记录总研究耗时与 SHA；它包括大量物理模拟及多候选前向，不等于生产延迟。

实现验证：定向 **86 passed，16.77 秒**；完整 CPU FFT 回归
**778 passed，277.17 秒**，两者重叠。覆盖历史/当前 Data 标签与发送符号隔离、
Reward 不进入候选、基础权重不改写、窗口连续性，以及窗口 1 与原 medium
候选/验收数值一致。
