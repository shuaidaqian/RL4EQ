# DFE 已知 Adapt 符号反馈核查计划

此前先验/遗忘因子网格没有获得可靠留出改善；本轮不继续扫参，只核查接收逻辑。
代码检查发现：训练反馈使用已知 Adapt 符号，但最终判决递推重新硬判决所有
Adapt 位置。传统 DFE 可以在这些位置直接使用接收端已知符号，避免已知前缀
的判决错误传播；这不需要神经网络、RL、Reward 标签或 Data 标签。

在读取本轮实验输出之前固定：

- Level B、prefix、0/5/10/15 dB，配置沿用
  `configs/eme_long_memory_v2_phase_transfer.json` 的信道和 Pilot。
- 原参考 41+5 taps、遗忘因子 .995、初始逆协方差 10，不新增网格。
- 仅比较原递推和强制已知 Adapt 符号反馈；训练规则、同步补偿不变。
- offline_train 新 seed=43000–43002，各 4 帧，48 个上下文、96 条记录。
- 各协议自身 tail 递推；输入波形必须匹配，Data 标签只作事后评估。
- 此为诊断可选开关，不修改正式默认传统协议，不纳入主结果。
- 若没有可靠改善，不扩大该设置的留出矩阵；若有，则先冻结独立核验计划。

本轮不能解决神经候选迁移、Reward 饱和或正式信息边界选择；它用于消除后续
公平比较中一个具体、合法的传统接收规则疑点。
