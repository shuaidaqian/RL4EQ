# 神经符号残差四臂结果：离线收益成立，在线增量尚未成立

依据冻结错误定位设计的新分支，在相同接收波形上改善了部分 SNR 的离线
均衡性能，但 17 参数 head 的在线更新没有可靠额外收益。不能把新结构的
Frozen 改善称为在线适配成功；整体目标未完成。

## 固定协议与工程核验

[计划](symbol_transfer_plan_20261101.md)在读取本轮结果前固定：从 full_rx A256
源模型出发，仅训练新增 1153 参数分支；A 为普通 BCE_all，B 为 BCE_all +
更新后 Data BCE。各 256 步，seed=46000–46255，外层 lr=1e-3。
在线仅微调 17 参数的 head，Adapt BCE、AdamW lr=5e-4、一步、半径 0.05。
整帧波形可见，在线未知发送符号和 Data 标签隔离。网络和测试计划见 `4d4e156`。

两步 smoke 通过。初次迁移测试将可微与纯推理 attention 路径混作逐 bit 对照，
出现约 1.9e-6 的舍入差；修正为同一推理模式后精确一致。有限差分测试另以
非零外层导数验证，未用零梯度掩盖高阶链路。正式训练未从 smoke checkpoint 接续。

## 下一步

新分支不是通过损坏原 Frozen 制造增量：它在 5/10 dB 已有明确离线收益，
说明输出作用位置值得保留。普通前缀 Pilot 更新仍未迁移，下一步应检查
监督任务与 Data 帧尾的观测覆盖差异，不立即增大网络、训练矩阵或 PPO 预算。

可验证的候选是将已接收的前缀构造成真正缩短的观测窗，让已知 Pilot 在该窗
末端经历类似 Data 帧尾的覆盖不足，再更新同一神经 head。必须同步缩短物理
算子和所有输入字段，不可把后部波形置零后仍按完整观测求解。Reward 标签
仍只用于动作后验收，Data 标签不参与该过程。该路径尚未验证，不预先声称成功。

本轮不扩大同配置留出矩阵，不进入累计与正式 RL，不比较不同 seed 的传统
数字。所有原始结果指纹、协议和区间见
[机器摘要](results/symbol_transfer_stage_20261101.json)。原始日志位于
`logs/symbol_transfer_four_arm256_5s8f_20261101/` 和
`logs/symbol_transfer_source_reference_5s8f_20261101/`。
