# 匹配整帧输入的四臂结果：0 dB 有在线增益，更新后目标没有额外优势

用户明确允许在线读取整帧已接收波形后，本轮完成已有 phase 神经参数组的匹配
离线训练与独立四臂验证。0 dB 的两个分支均相对自身 Frozen 有正向区间，但
新增更新后 Data 目标的 B Online 比普通监督 A Online 更差。5/10 dB 收益仍
不确定，15 dB 未接受更新。整体目标未完成，不将本轮纳入正式主平均。

## 协议、来源与实现

[实验前计划](full_rx_transfer_plan_20261101.md)固定 A/B 各 256 步、batch=1、
offline_train seed=44000–44255、四主 SNR 轮换；内循环为 phase 组、Adapt BCE、
AdamW lr=5e-4、一步、半径 0.05；外层 lr=1e-4。两分支都使用整帧接收输入，
更新标签仍仅为 Adapt，动作验收标签仍仅为 Reward。网络结构没有改变。

A 继续 BCE_all；B 使用 BCE_all + 更新后 Data BCE，权重均为 1。
它们从同一源 `pretrained/phase_transfer_post256_20261101/model_best.pt` 开始，
源 SHA256 为 `305ea6f636cf5f0619649489a7d2e5ed5ce9138334e37e731bf24246a78fe010`。
继承的历史训练开销不能省略。两步 GPU smoke 未作为正式训练起点。

| 分支 | 256 步用时 | 固定终点 checkpoint SHA256 |
|---|---:|---|
| A 普通监督 | 203.734 秒 | `2f7bb615409bdd5ec90ce549b83f3c6cff38a26caf3c89062c552b7b76cbfeb4` |
| B 更新后目标 | 252.125 秒 | `ba93d534d0be8d8ccf83db7785e4f911612551ba6a6a55445fc02afe7c7f982a` |

checkpoint 为固定预算终点，没有按测试或训练日志挑选中间模型。

## 独立四臂证据

heldout_edge seed=60001–60005，各 8 帧、四 SNR；每帧重置参数。
共有 160 个配对接收上下文、320 条分支记录。两分支的同帧接收波形 SHA256
完全一致；每个分支分别使用自身同 checkpoint Frozen，不能要求两分支 Frozen
相同。所有在线 Data 标签使用标志均为 false，更新与验收整帧波形标志均为 true。

下表为 `100 × (Frozen BER − Online BER)`，单位为百分点，正值表示改善。
区间以 5 个独立信道 seed 的帧均值计算；它们是探索性 t 区间，未作多重比较
调整，且未覆盖多次离线训练初始化的不确定性。

0 dB 的 A Frozen/Online BER 为 19.16016%/18.95833%，B 为
19.40430%/19.20898%。两个分支的 5 个信道 seed 都有在线改善，但 B 的基础模型
和更新后绝对表现均未超过 A。B 与 A 的适配收益差在所有 SNR 均没有正向区间。

| SNR | A 接受帧 / 40 | A 有害接受帧 | B 接受帧 / 40 | B 有害接受帧 |

15 dB 的 Online 等于自身 Frozen；A 与 B 的绝对 BER 差来自离线模型差异，
不能算作在线增益。零宽区间只表示这批样本没有在线变化。

补充汇总了每帧验收前候选的 Data BER 改善，标签只用于事后评分、不参与选择。
除了 0 dB，两个分支的候选收益区间也都跨零，因此不能把失败全部归因于
Reward 门槛过严。本轮没有记录 Reward 绝对 BCE，不把旧 checkpoint 的饱和
数值套用到新模型；可以确认的是本批 15 dB 的 80 个候选都未获接受。

## 成立范围与后续决策

本轮得到的是固定更新规则在 0 dB 的局部迁移证据，没有完成下列目标：

- 四主 SNR 的可靠在线改善；
- 更新后离线目标优于普通监督；
- 跨帧累计、后期优势增长及正式 RL 调度的额外价值；
- 同轨迹、逐配置超过校准传统基线。

本轮各帧参数重置，因此即使某些早晚段均值不同，也不能据此声称学到了累计
适应。还没有相同训练预算的严格输入 B 对照，不能将结果单独归因于“取消遮罩”。
与此前不同 seed 的实验不能作配对显著性比较。

按照事先退出条件，不扩大此配置留出矩阵，不追加同权重 Data 重加权分支来
解释一个尚不存在的 B 优势，也不因部分正均值或接受率而放松 Reward 阈值。
输入范围已经获得用户答复，不再是待确认项。下一阶段需要先定位中高 SNR 的
可修正误差及现有神经调制的覆盖范围；若需要改变调制位置或结构，另一项研究
选择仍待用户答复。任何新方案都需固定新训练范围筛查与独立确认计划。

完整协议、checkpoint 指纹、训练记录指纹、所有逐 SNR 区间与候选诊断见
