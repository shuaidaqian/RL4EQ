# 物理解码器的数值收敛与软输出含义

本审查只检查源码和确定性线性方程，不读取P8中途性能，不生成仿真会话，不改变接收器。它提出需要隔离验证的近似，不能解释为已经定位长程BER变化的原因。

## 固定八次迭代不保证已解出线性松弛

`UnfoldedEqualizer._real_bpsk_known_adapt_logits`在实值未知符号子空间解正规方程。已知Adapt和tail先从观测中扣除，令剩余设计矩阵为U，噪声功率为σ²，则当前目标为

\[
 [\operatorname{Re}(U^H U)+\tfrac{\sigma^2}{2}I]z
 =\operatorname{Re}(U^H y_{\rm residual}).
\]

这是实高斯符号先验下的线性后验均值，不是离散BPSK的精确后验。固定八次共轭梯度进一步引入数值近似。较小σ²使正则化减弱，求解可能需要更多迭代；是否影响实际BER须独立验证，不能由数值残差单独推出。

确定性核验入口为 `scripts/verify_physics_solver_convergence.py`，结果为 `results/continual_v2_solver_math_20261120/equation_examples.json`。它构造1024符号、117tap、224已知Adapt的有限帧矩阵，保留帧尾截断。使用显式符号 `sign(sin(17k+0.2))`、零tail、无噪声波形；σ²只作为正则化参数，不是一次接收性能实验的SNR。模板为直达、0/70位置等幅双径、确定性117tap指数包络复相位。没有调用信道生成器、研究seed或神经初始化。

独立参考解由float64显式矩阵求得，全部12个方程的相对残差小于1e-10。生产实现使用float32 FFT算子，比较8/16/32/64次迭代，共48项。下表为长弥散模板的截断后logit RMS差及符号差；参考是精确线性松弛解，**符号差不是BER**。

| 正则化噪声参数σ² | 8次 RMS差 | 64次 RMS差 | 8次/64次与参考的800个未知符号判决差 |
|---:|---:|---:|---:|
| 1 | 0.003180 | 0.00000146 | 0 / 0 |
| 0.316228 | 0.101578 | 0.00001252 | 1 / 0 |
| 0.1 | 1.039024 | 0.00019089 | 3 / 0 |
| 0.031623 | 3.055400 | 0.00337889 | 4 / 0 |

直达模板全部迭代设置与参考的最大logit差小于1e-5。双径模板也存在数值误差，但本组无噪声右端项的判决差为零。64次仍不等于一般性精确保证：生产实现的固定迭代、float32精度与分母下限都保留，且logit有±40截断。未截断参考位置的相对均值误差另存，参考全部截断时为null，不生成NaN。

## 当前输出不能直接解释为校准的BPSK LLR

源码以 `2*z/σ²`生成soft输出。该映射保留线性估计的符号，但没有计算逐位置后验方差。即使在线性高斯松弛内部，若后验边缘为N(m_j,v_j)，将高斯近似在±1处求密度比得到的log比是 `2*m_j/v_j`，不是一般性的 `2*m_j/σ²`。从该近似除去单位高斯先验后，先验在±1处密度相等，密度比仍相同；这不使它成为多径BPSK真实后验。

最简单的实BPSK直达链路 `y=x+n`、`n~CN(0,σ²)`中，精确LLR为 `4*Re(y)/σ²`。当前高斯均值为 `m=Re(y)/(1+σ²/2)`，输出 `2*m/σ²`，与精确LLR不相等。高斯边缘方差为 `v=σ²/(2+σ²)`，此特例中 `2*m/v`恰好恢复精确LLR。多径、CIR误差、同步误差和tail不确定性下不能照搬该特例为精确性结论。

因此，物理判决较好不代表soft信息已校准。soft-tail、后续Data反馈和离线BCE都会受到幅度映射影响；P8三臂使用同一规则，这一事实不取消其配对比较，但限制soft输出的概率解释。已有Brier/BCE和高置信错误可辅助诊断，不能仅凭接口名称把输出称为真实后验。

## 后续验证顺序

先按原协议完成并归档P8，再整合已准备的匹配老化先验对照。若继续检查求解误差，应以新协议、新seed比较迭代数或合法残差停止，同时记录每帧数值残差、判决变化及成本。更精确地解线性松弛不保证BER单调更好，不能预先宣布胜出。软输出校准须另做可归因比较，不能与迭代数同时变化后把收益归给某一个因素。

这些确定性检查既没有完成四SNR增长至饱和目标，也没有证明该目标不可达；离线神经贡献、协同和新独立确认仍待研究。
