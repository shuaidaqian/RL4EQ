# 重构调制位置前的冻结错误定位

用户要求按建议继续推进，结合上一轮明确提出的结构调整建议，本轮可以调整
神经调制位置或结构；既有 Level B、prefix、安全离散 RL 与标签隔离契约不变。
先检查实际残余错误，避免仅因相位组失败而无依据增加网络。

运行前固定：使用普通监督 full_rx A256 终点，SHA256：
`2f7bb615409bdd5ec90ce549b83f3c6cff38a26caf3c89062c552b7b76cbfeb4`。
选择 A 是根据此前开发阶段对照结果作出的后续研发选择，不能再将该选择在旧
留出数据上的表现当成新的独立确认。本轮仅用新的 offline_train 样本。

- seed=45000–45004，各 8 帧，四主 SNR，共 160 个上下文。
- 冻结模型，不生成更新候选，不优化、不执行 RL、不注入真实 CIR 或真实 tail。
- 先完成全帧推理和物理分支输出，再读取标签统计错误。
- 固定区域：Adapt 前记忆区、Adapt 内部、Reward，以及 Data 首 116、
  中间、尾 116；Data 三段互斥覆盖。按 bit 数报告错误率，不能直接比较错误数。
- 统计神经分支修复/引入错误、错误 logit 绝对值、绝对值≥5/20 的错误数、
  物理分支饱和错误数，以及神经残差实际幅度。
- 这些是描述性定位指标，不是新方法 BER 优势、物理误差真值归因或 Data Oracle。

若错误集中于边界，优先检查边界状态和有效观测；若主导物理分支留下神经残差
难以改变的错误，再评估把低维神经调制移到符号估计或物理迭代内部。
若错误较低置信且已有神经分支能修复，则先检查更新目标与反馈，不贸然改结构。
