# 当前 head 的响应高度集中，仍需区分可达与可辨认

按[固定计划](channel_state_geometry_plan_20261102.md)，只读 long_age B64 的原训练
缓存，每个 SNR×五年龄取首个样本，共 20 上下文。它们参与过训练，不是独立
泛化证据；本轮只解释模型数学结构与局部损失方向。

## 已确认的局部结构

- CIR 拆为实/虚后是 234 维，head 是 17 参数；20 个 Jacobian 在相对阈值
  1e−5 下均为 17 秩，所以“所有参数方向失效”不成立。
- 第一奇异方向占 Jacobian 能量 **97.47%–99.30%**，实际响应严重集中；满秩
  不能等同于 17 个方向都同样容易更新。
- 离线 Data BCE 梯度落在这 17 维可达空间的能量比例为 **4.38%–18.01%**。
  这支持检查表示的作用族，不构成所有未来输入上的不可改善定理。
- Adapt 与 Data 的投影梯度夹角在不同条件下有正有负。当前 0 dB 的五个样本
  投影余弦均为负；5 dB 的早期三个为负，2047/4095 为正。Adam 的预条件与
  有限步长又可能改变实际方向，因此夹角不能独自预测 BER。

实际 medium 候选始终只由 Adapt 产生。部分样本的局部 Data 方向导数与有限
更新后的 BCE 变化并不一致，说明还存在有限步长与非线性影响，不能把梯度
一阶近似充作成功。完整数值保留在机器摘要，未用 Data 导数选动作或更新。

## 推导与下一步

反复训练当前标量 gate 的 head，仍只能沿其依赖的 Pilot 后验方向调制；增加
参数步长不能创造其余复 CIR 方向。下一步先检验能够存储受限复数状态残差的
神经 Adapter，并让“未更新时的输出”保持原 Frozen 精确不变，以免再次通过
离线退化扩大适配差值。

另一方面，当前 Adapt 只有 108 个完全已知复卷积行，CIR 有 117 个复 tap。
更大的表示不自动解决可辨认性和噪声过拟合；必须保留 acquisition 先验或
等价安全约束，先做合法 Pilot 候选及 Data 事后验证，再训练更新表示，最后
才推进正式离散 RL。可达性、Pilot 方向和反馈排序仍是三个不同前提。

## 验证

CPU 只读研究耗时 **13.20 秒**，没有重新生成物理轨迹。Jacobian 有限差分、
改变 Data 标签不影响实际候选、原模型参数不改写测试通过。定向
**93 passed，19.31 秒**，全量 CPU FFT **785 passed，245.73 秒**。

[机器摘要](results/channel_state_geometry_stage_20261102.json)包含训练样本来源、SHA、
局部 Jacobian 与梯度指标。它不是 Data 标签更新器，也不是主结果或最终成功。
