## 验证与后续

总研究诊断耗时 **576.48 秒**，包含 49152 帧物理模拟和多窗口前向/梯度，不是
生产每帧时延。定向 **86 passed，16.77 秒**，完整 CPU FFT
**778 passed，277.17 秒**；覆盖历史和当前 Data 标签隔离、Reward 不进入候选、
窗口 1 与原 medium 的一致性。192 行完整组合、同一当前波形和统计重算核验通过。

当前 checkpoint 最大训练评分年龄 135，后期是年龄外推；每年龄重新生成参数，
也不是连续神经更新。用户现已明确最终数百秒会话只在开始 acquisition 一次，
后续仅每帧前缀 Pilot。因此后续先匹配该年龄分布做固定预算离线 A/B，保留
原单帧机制与窗口对照，再决定是否进入独立连续窗口 RL。不能将本诊断当作
长年龄匹配训练后的失败或直接声称正式 RL 已有效。
