较大作用幅度已得到实际验证，但所有档位的 BER/BCE 改善区间仍包含零，
10/15 dB 多数点估计还为负，不能仅靠放宽半径宣布解决。已训练 gate 均值
约 1.48–1.56，非全零、也没有全部达到 ±2 的边界。

一个尚未验证的目标缺口是：后验方向使用了 acquisition 先验，但在线目标只
最小化信号残差，可能推动 gate 放弃相同的先验约束、趋向当前 Pilot 拟合。
应先在新训练轨迹上比较加入相同先验的 MAP 目标，再决定是否改训练；这只是
待验证假设，不是将本轮失败归因为唯一原因。

259.72 秒**；随后幅度诊断定向 **66 passed，14.81 秒**。幅度研究脚本总耗时
43.23 秒，包含多个候选、参照与统计，不等于生产接收机延迟。
