改善区间同样包含零；当前数据不支持“增加历史平均即可解决方向噪声”。

尾部梯度余弦会随样本和窗口变化：10 dB 从单帧 −0.0277 到四帧 +0.2204，
八帧又回到 +0.0167；15 dB 分别 +0.2975/+0.2406/+0.1733。
局部方向变化没有可靠转换成实际 BER 改善，不能根据某一余弦挑选窗口。
这批样本与前轮不同，15 dB 余弦符号不同也提示不能把小样本均值解释成结构定理。

## 结论与下一步

匹配短窗离线训练、单帧候选跨帧保留、历史平均三个环节都未建立稳定在线迁移。
因此下一步不继续堆当前 17 参数输出 head 的训练或 PPO 预算，应重新核对：
被适配的参数是在修正可由 Pilot 辨认的信道状态，还是在拟合不同边界和不同符号
的判决残差。后者即使有连续损失梯度，也不保证对新 Data 泛化。

这不证明原目标不可达，也不证明任何历史聚合无效。后续结构/目标变化应先在
新的训练轨迹上做单次机制验证，保留同 checkpoint Frozen、原模型代价参照及
普通监督对照。正式离散安全 RL、校准传统比较、数百秒验证仍是未完成工作。
部署实时性约束正在向用户确认；研究脚本包含重复参照推理，不能将其总耗时
直接当作生产接收机延迟。

代码支持历史上下文的平均 Adapt 损失及其只读梯度解释；Data 标签污染不改变
候选、Adapt/Reward 指标或模型权重的测试通过。最新定向 **57 passed，11.85 秒**；
此前完整回归 748 passed，271.96 秒，未声称本次诊断扩展后再次全量回归。
