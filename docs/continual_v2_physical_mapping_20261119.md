# 第一研究点与持续均衡等效模型的映射

状态：P0 物理来源审计与等效定义。本文明确已落实的抽象和剩余验证，不宣称复用了第一研究点全部仿真，也不修改冻结信道。

## 1. 来源与可追溯性

第一研究点论文《宽带EME通信信道的建模与特性分析-拟录用》在 Git 中的 DOCX 内容标识为 `2de4838b9d70c61da15459e4da0eaa336729bfb2`。工作区文件此前已删除，审计通过 `git cat-file blob` 内存解包正文与表格完成，未恢复文件。

论文正文描述路径损耗统一积分、阴影衰落、准镜面/漫散射分段多径和轨道多普勒模型。链路仿真表列 BPSK、7 阶 m 序列扩频、14 阶 m 序列同步、100 条径、最大时延 10 ms、符号速率 1000 符号/秒。正文指出短时延能量集中、边缘漫散射产生拖尾，毫秒级时延使传统均衡面临强 ISI；多普勒频移与扩展需要区分。

当前[配置](../configs/eme_long_memory_v2_online_dd_tail_v1.json)使用 BPSK、10000 符号/秒、一符号一采样、1024 符号帧、最大时延 11.6 ms、116 符号记忆、12–24 强径与弥散分量。它是独立 EME-inspired 算法信道类，不能直接称论文原参数复用。

历史雷达来源为 Evans 1965 Fig.8 的 3.6 cm/68 cm 曲线。0–10 ms 由人工稀疏读图，11.6 ms 为未直接观测的支撑延伸；[来源清单](../data/eme/reference_manifest.json)明确不宣称目标频段精确 PDP。

## 2. 等效链路及当前保留内容

| 层次 | 物理或系统内容 | 当前均衡模型的处理 | 结论边界 |
|---|---|---|---|
| 大尺度传播 | 路损、天线与阴影 | 初始 CIR 能量归一；后续物理 CIR 允许功率波动；固定单位符号能量 Es/N0 噪声 | 不评价绝对链路预算和真实设备可达数据率 |
| 波形 | 扩频、脉冲成形、采样与匹配滤波 | 当前采用未编码符号率 BPSK 线性卷积 | 不是第一研究点扩频波形的直接端到端接收验证 |
| 多径 | 准镜面主能量与漫散射拖尾 | 包络约束强径与复弥散分量，固定时延网格和支撑 | 需要比较最终采样 PDP 与第一研究点统计形状；不能把生成器候选参数称实测 |
| 时延离散化 | 连续传播时延 | 10000 Hz × 0.0116 s = 116，包含零时延共 117 tap | 脉冲成形/分数时延尚未覆盖；边界验证需依据所选处理域 |
| 时间变化 | 月面散射与相对运动 | 帧内 CIR 固定，帧边界固定支撑 AR(1) | 不代表路径出生消失、时延迁移或显著帧内扩展 |
| 同步 | 运动载频偏移与残余相位 | 公共 CFO＋相位随机游走，acquisition 估 CFO，Adapt 估当前相位 | 公共 CFO 不等于独立各径多普勒扩展 |
| 帧间干扰 | 前帧尾部持续影响接收 | 116 个模型 soft-tail 递推；首帧来自已知 acquisition | 普通帧真实 tail 不进入接收机 |
| 接收噪声 | 热噪声与其他扰动 | 独立复 AWGN；新接收机估计 acquisition 残差功率 | 当前不覆盖任意色噪声/突发干扰，估噪残差还可能含同步失配 |

## 3. 状态、幅相与噪声约定

新开发接收机估计未归一化的有效复 CIR，而非每次投影到单位球面。初始 CIR 可以吸收 acquisition 的公共相位。后续由 Adapt 估计相对当前 CIR 参考的公共相位，CFO 起点由 acquisition 估计。真实 CIR 的绝对相位不作为在线参考。

观测波形保持接收尺度，不额外执行 AGC；若后续引入 AGC，CIR 幅度、协方差和噪声方差均须同步变换。固定发送符号 ±1，生成噪声是单位符号能量下固定 Es/N0，并非按每帧实际接收功率重设。信道功率波动不应通过重新定义噪声掩盖。

估噪首先沿用 acquisition 最后 908 个完整已知卷积行，在未归一化 LS 拟合上估计。细化 CFO 减少粗网格失配，但同批数据选 CFO 及相位随机游走意味着自由度修正不再严格保证无偏；开发实验需记录偏差。

## 4. 信道动态与过程噪声的量级核查

配置帧长 0.1024 s、相干时间 1200 s，对应 \(\rho=\exp(-0.1024/1200)\approx0.99991467\)。128 帧约 13.1072 s。相干时间是当前建模参数，尚不能称从第一研究点时间序列拟合得到。

生成器按基准各 tap 功率 \(p_l\) 产生创新，条件创新协方差的量级为：

\[
Q_{\mathrm{generator}}=(1-\rho^2)\operatorname{diag}(p_l),\qquad
\operatorname{tr}(Q_{\mathrm{generator}})\approx1.71\times10^{-4}
\]

其中使用初始基准总功率为 1 的约定。历史滤波器采用 \(10^{-4}I_{117}\)，迹为 0.0117，约为上述创新总量的 68.6 倍。该差异不直接证明历史超参数错误：它还可能补偿 soft、同步与观测模型失配，但不能把该 Q 直接称为物理创新协方差。

P1 先固定现有 Q 量级，以隔离估噪、时序和状态尺度；后续依据创新统计检验均匀 Q、基于 acquisition 合法估计功率的结构化 Q 及失配膨胀。禁止把仿真真实 tap 功率传给主接收臂。

## 5. 当前不足与后续动作

1. 第一研究点的分段 PDP 与当前生成器最终 PDP 缺少数值映射。应从归档公式/已有代码恢复可计算参数或用公开包络作有边界的替代，明确来源。
2. 第一研究点表中的 1000 符号/秒与扩频码片/采样率关系尚不能仅由表格推定。当前 10000 符号/秒等效模型保持，不能将 10 ms 简单按信息符号率换算后称同一波形。
3. 帧内恒定 CIR 与 1200 s 时间尺度暂作慢变近似；若要映射到特定载频、几何和扩展，需要额外依据。技术上可先用无量纲帧长/相干时间比报告范围。
4. 先通过 A/B/C/D 匹配实验检查实际瓶颈。只有证据表明分数时延、同步或状态演化失配改变方法排序时，才新增相应边界协议。

本轮审计未发现必须改动冻结信道才能开始 P1 的事实；缺失的物理精确映射保留为未完成工作，不以同名 EME 标签替代。
