# 跨帧离线外层目标：固定预算检验

目前已确认的缺口是训练与保留行为不一致：原 post_adapt 只优化当前帧更新后的
Data，而在线接受参数后会跨帧复用。128 帧结果没有确认后期优势，首帧有效期
诊断也没有支持统一的 Pilot 过滤规则。二者不能证明跨帧目标必然有效；本轮
明确检验这一假设，不继续扩大量相同的留出样本或直接增加 RL 预算。

实现使用 `post_target_frame_offsets=[0,8]`：当前帧 Adapt 做一次 medium 动作，
其参数同时用于当前和后 8 帧离线 Data loss。各帧条件由各自合法 Adapt 生成；
未来上下文只用于离线外层，绝不进入当前内循环、正式 observation 或 reward。
这是未来泛化目标，不是跨帧状态递推训练，也不声称覆盖数百秒。

- 配置 `configs/eme_long_memory_v2_channel_state_future_transfer.json`。
- A/B 同源 symbol A256，SHA
  `605281acef3e9efe61e8d8354f6feb61b3324737eabff0a5ba3f75f43a6b7ecc`，
  新状态 head 零初始化，只训练新 449 参数，原网络冻结。
- offline_train 90000–90255，各 256 步，batch=1，outer lr=.001；四 SNR 轮换，
  更新帧龄 0/7/31/63/127 轮换，评分帧龄为当前与当前+8，权重均等。
- 内层 lr=.02、3 步、累计/单次半径 .2、17 参数 channel_state_head、Adapt signal。
- A 的 BCE_all 在两个目标帧等权平均；B 用相同 BCE_all 加两个目标帧更新后
  Data BCE 的平均。相同离线标签暴露、种子、源参数与条件，不能把更多标签
  暴露误当作元训练作用。两分支均不做测试集 checkpoint 选优。
- 完成两步 CUDA smoke 和定向测试后再训练；OOM 则只调整同一目标的内存计算
  方式，不能静默减少目标帧或更换监督边界。
- 第一关固定 heldout_edge 95001–95005、四 SNR、各 8 帧，接受参数跨帧保留，
  共 160 个同波形当前上下文、320 条 A/B 记录。早晚按原 summarizer 的前后
  各 2 帧，不能据短会话解释长期优势。
- 报告所有配置的 Frozen/Online、B 相对 A 适配交互，以及 B Online 对 A Online。
  原 Frozen 如因训练退化，不能以增大适配差值宣称成功；必要时同波形与源比较。
- 若四 SNR 仍没有稳定增益，不自动扩大同配置 128 帧矩阵；先在新训练轨迹
  核查未来目标的梯度与有限动作作用族是否匹配。通过机制关后再预注册独立
  128 帧、正式窗口 RL、传统校准比较和数百秒会话。

统计按独立 seed 给 95% 配对 t 区间，明确多重探索限制。训练/诊断耗时实测，
不等同生产帧延迟。任何工程通过均不替代最终四 SNR 和后期优势门槛。

实现验证：定向 **83 passed，15.26 秒**；完整 CPU FFT 回归 **775 passed，270.34 秒**，
两者重叠。包括当前内循环不读取未来上下文、A/B 相同帧标签暴露、未来目标的
有限差分梯度、偏移协议校验和 checkpoint 兼容。两步 CUDA post_adapt smoke 通过，
没有减少目标帧或降低精度。
