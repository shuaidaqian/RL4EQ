# 现有神经相位校正参数组的作用能力诊断

## 待验证的问题

当前 head 更新在 Data 上影响很弱。现有网络还包含 `phase` 参数组，即神经
相位校正 MLP 及其尺度，前向直接作用于物理 warm-start 的输入。它已经存在于
模型和 PEFT Registry 中，尚不是当前正式 RL 动作。本轮只诊断该现有分支的
作用能力，不调整结构、不注册新动作、不把它当作正式 proposed。

前缀前 116 个接收样本依赖历史 tail，当前严格 Pilot 状态递推不覆盖未知帧尾。
因此预先设置后记忆区间评分，用来区分作用位置与历史边界影响，避免看到结果后
再任意修改 Pilot 长度或优化器。

## 固定三臂

三臂从同一已固定的 head post-adapt 256 步 checkpoint 开始，不再训练模型：

1. head/BCE，Adapt 全区间评分，从 0 开始；作为本轮同轨迹作用幅度对照。
2. 现有神经 phase/BCE，Adapt 全区间评分，从 0 开始。
3. 现有神经 phase/BCE，仅对位置>=116 的 Adapt 评分；整帧输入视图仍然保留
   全部 Adapt 接收样本，不能把评分窗与输入窗混为一谈。

三个候选均为 AdamW、lr=5e-4、1 步、总增量上限 0.05；参数维度不同，实际更新
范数可能不同，不能称为完全相同的计算或步长预算。各帧从固定参数起点重置。
统一 Reward Pilot 验收；所有 Pilot 决定结束后，才用 Data 标签做事后梯度及 BER
分析。事后分析不选择该帧动作或更新参数。

使用原 Level B、1024/116、prefix=256、Reward=32、原 CFO/相位范围。仅取
offline_train 新 seed=35010–35012，每条 4 帧、四主 SNR；三臂共 144 条记录。
同帧接收波形 SHA256 必须一致，不在 heldout_edge 上选择候选。

## 判读边界

首先核验候选与既有通用 PPO 更新函数数值一致，以及隐藏波形/标签污染不变。
再分别报告连续作用幅度、修复/引入错误、候选和验收后 BER 改善、梯度方向。
作用更强不能自动判定更好；某一 seed/SNR 的正均值不能当作主目标成功。
若现有 phase 分支也不能稳定迁移，将其作为下一轮调制位置/结构选择的证据，
不继续盲目放大学习率或自动接入正式动作。

用户此前的调制位置/结构选择问题仍待回复。本轮只检查现有模型，不据此决定
结构变更；正式动作、主 checkpoint 和原方法组保持既有状态。
