# 合法信道状态候选：0 dB 有信息，神经适配尚待验证

按[预设计划](pilot_state_transfer_plan_20261102.md)完成 75000–75002、16 帧、
四 SNR 的训练分布诊断。108 当前上下文、216 候选，checkpoint 固定 symbol A256。
只用完全已知的 Adapt 卷积方程，结合 acquisition 先验构造候选 CIR，替换冻结
神经均衡器的 CIR 条件；不读真 CIR、不训练神经权重、不注册主方法或主 baseline。

## 结果

候选与 Reward 验收后改善均为 Frozen−候选 BER，单位百分点。
每格 27 当前帧、3 个独立 seed；区间为 seed 级 95% 配对 t 区间，属于探索性结果。

## 含义与后续

合法 Pilot 波形在本样本中含有能改善冻结网络输出的信道信息，值得设计与该
状态对应的神经调制。它不证明物理候选就是 proposed，也没有替代在线微调、
正式 RL 或传统比较。不能将固定的条件更新当作神经权重适配成果。

下一步候选为神经信道状态残差：以合法后验残差为方向特征，由小神经网络学习
逐 tap 的有界调制，离线训练其泛化，在线仅更新低维 head。在线训练损失先用
Adapt 的前向复数信号残差，避免直接把不同边界的 bit 判决梯度视作同一状态。
Reward 前向信号损失只在动作后验收；Data 标签仍不进入在线控制。
新分支须零初始化保留原 Frozen、冻结旧权重，并用普通监督/更新后训练四臂
比较，才能区分新表示的离线改善与在线增量。

完整研究脚本耗时 **68.83 秒**，含 acquisition、多个候选和参照前向及统计，
不是部署接收机延迟。59 项定向测试通过，20.58 秒，覆盖隐藏波形/标签与未知
tail 隔离、零残差保留先验、可辨认合成增益修正及模型权重不变。
用户已确认先验证统计收益并报告耗时，实时优化在机制成立后进行。
