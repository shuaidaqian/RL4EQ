# 匹配前缀短窗的离线训练计划

目标是检验离线表示能否学会让前缀边界更新迁移到完整 Data，而非把验收率当作收益。
本实验仍为机制实验，不替代离散安全 RL、传统 baseline 和长期优势验收。

- 源固定为 `pretrained/symbol_transfer_baseline256_20261101/model_best.pt`，SHA256
  `605281acef3e9efe61e8d8354f6feb61b3324737eabff0a5ba3f75f43a6b7ecc`。
- A 普通 BCE_all，B 为 BCE_all 加更新后完整 Data BCE；各 256 步，batch 1，固定终点。
- 训练 seed 72000–72255，offline_train；测试 82001–82005，heldout_edge，每条 8 帧，0/5/10/15 dB。
- 只训练已有符号残差分支的 1153 参数，原基础参数冻结；在线仅更新 17 参数 head。
- 外层 lr 0.001，内层 lr 0.005，一步 AdamW，投影半径 0.05；两分支严格配对。
- Adapt 真实接收窗截至 224，损失评分 116–223；Reward 真实接收窗截至 256，评分 224–255。
  物理算子和逐符号输入同步缩短；最终推理及离线外层损失仍在完整 1024 符号帧上。
- 内层及验收可读取各自窗内全部波形；更新只用 Adapt 标签，Reward 只验收，Data 只离线监督和事后评分。
- 学习率依据此前训练分布幅度诊断固定；相对旧实验同时改变任务和步长，不能单独归因于截窗。
- 同源 Frozen 在同波形作参照；source/source 重复行只取一支，不作为新增样本。
- 先 CPU 隔离和梯度测试、GPU 两步 smoke，再从原源重新启动正式训练。不得依据部分留出结果改预算或 guard。

按独立 seed 聚合，报告 Online−Frozen 的相反数（改善为正）、95% 配对 t 区间、
后期减早期优势、B 与 A 的适配增量交互，以及各 Frozen 相对源的离线变化。
只有在线机制有可信改善才进入累计更新与正式 RL；无效结果也完整记录，不能扩大同配置来寻找显著性。

实现验证：CPU 全量回归 746 passed，271.74 秒；CUDA 两步 post_adapt smoke 通过。
测试覆盖训练/评估任务路由、短窗真实算子、Data 标签污染不变、非零外层梯度有限差分，
以及 checkpoint 训练任务不匹配时拒绝评估。正式训练从指定源重新启动，不承接 smoke 权重。

## 四臂结果后的离线解释计划

四臂在线区间全部跨零后，新增一次只读梯度诊断，独立于主验收：固定使用 B 终点，
offline_train seed 73000–73002，每条 4 帧，四 SNR。候选仍只由 Adapt 生成。
计算 Adapt、Reward、完整 Data、Data 尾部和内部损失对同一 17 参数 head 的梯度，
报告方向余弦、梯度范数和固定候选的一阶损失改善预测。不根据 Data 梯度生成候选、
选动作、更新权重或调参；不构造 Data 标签上界。该诊断只能解释局部方向，
不能证明实际 BER、状态可辨认性或长期收益。
