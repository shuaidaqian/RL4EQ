# Reward 信号最小改善门控对照（2026-10-15）

## 目的与设置

本轮在 10 dB、Level B、gap=0、seed 77--81、每条 60 帧上复用
`formal_signal_guard_logitcap01_gap0_10db_seed77_81_60f` 的全部设置，只把
Reward 信号重构守门从“误差不增加”收紧为“误差至少下降 0.0005”。命令行中

没有使用 Data 标签，也没有改变离线 checkpoint 或 Adapt 更新目标。

## 判断

严格门控消除了本组的负收益 seed，但平均收益下降约 59%，并且两个 seed 完全冻结。
它适合作为安全止损规则，不能作为已经稳定产生明显在线增益的主方法。当前证据
把问题定位得更清楚：Adapter 更新路径有效，Reward Pilot 门控能减少风险，但
Reward Pilot 的连续改善仍不足以稳定预测 Data 硬 BER。

下一步不再继续枚举同类数值门限；应先做 Pilot-only 的候选排序校准，或者接受
当前方法只能作为“有老化时尝试、失败时回滚”的安全增量，而不能宣称四个主 SNR
都稳定超过离线训练。
