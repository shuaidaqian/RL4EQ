# 神经信道状态残差的配对训练计划

合法 Pilot 信道候选在 0 dB 有探索性信息，但不属于神经微调成功。本轮检验
与可见状态对应的神经表示及前向适配目标，不复用旧输出 head 的失败预算。

- 源固定 symbol A256，SHA256 `605281acef3e9efe61e8d8354f6feb61b3324737eabff0a5ba3f75f43a6b7ecc`。
- 新状态分支逐 tap 共享 MLP 9→16→16→1，共 449 参数；在线仅 17 参数 head。
  head 零初始化精确保留原 Frozen。旧网络和已训练符号分支全部冻结。
- 特征只来自 acquisition CIR、Adapt 前向方程、噪声、相干先验和已过帧数，
  不含真实 CIR、Reward 标签或 Data 标签。后验方向范数至多 0.5，神经 gate
  为 2*tanh(head)，总状态修正范数至多 1；这是表示边界，不是在线参数半径。
- 内循环一步 AdamW，lr=0.005，head 参数半径 0.05。损失仅为完全已知的
  Adapt 卷积行前向残差 MSE/noise；不以 Data 波形或标签形成梯度。
- Reward 前向残差仅作动作后 loss 验收，Reward BER 仍参与原安全 guard。
  Reward 符号不进入状态分支输入或 Adapt 梯度。
- 普通监督 A：完整 BCE_all；B：BCE_all 加更新后完整 Data BCE。
  各 256 步，batch 1，outer lr=0.001，固定预算终点，不留出选优。
- offline_train seed 76000–76255，轮换目标帧索引 0/7/31/63/127，覆盖
  0.1–13.1 秒信道年龄；每种年龄与四 SNR 交叉轮换，两分支逐项配对。
- heldout_edge 86001–86005，各 8 帧、四 SNR；每帧重置 head，先检验单次机制。
  同波形 symbol A 源 Frozen 作代价参照；重复 source/source 只取一支。
- 先零初始化、参数冻结、隐藏标签隔离、AdamW 一致性与外层梯度有限差分测试，
  再 CUDA 两步 smoke；正式 A/B 均从原源重启。

此轮相对旧分支同时改变状态表示、适配目标、Reward loss 和信道年龄训练分布，
因此若有收益不能单独归因于某一项。A/B 只比较同新协议下更新后训练的额外作用。
正式 RL 短窗口选择、128 帧累计、数百秒连续跟踪及校准传统对照仍须后续独立验证。
统计单位为 seed，分别报告离线 Frozen 变化、Online 相对自身 Frozen、A/B 适配
交互与后期减早期优势。本轮每帧重置，后期差值不解释为累计学习曲线。

实现验证：65 项定向测试通过（14.10 秒），757 项完整回归通过（259.72 秒），
CUDA 两步 post_adapt smoke 通过。正式训练从源重新启动，不续接 smoke。
新分支目前只接入本机制实验，不作为已接入正式窗口 RL 的结果；后续正式入口
需一致传递帧龄、信号适配目标和 Reward 目标后另行验证。
