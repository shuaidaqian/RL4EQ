# EME 类 Level B 信道参数与文献依据

## 1. 研究定位

第二研究点不复用第一研究点中的具体 EME 信道实现，而采用独立的 EME 类极端长记忆信道。信道设计只保留能够由公开月面雷达延迟-功率资料和长时延通信接收机问题共同支持的结构：多符号相对时延、跨帧 ISI、稀疏强回波、弥散长尾，以及同步后残留的 CFO 和慢相位扰动。

这里的 Level B 是一个受公开资料约束的建模工作区，不宣称等同于某次实测 EME 链路。公开文献用于约束延迟支撑和功率包络，具体离散 tap 数量、弥散能量比例和慢状态参数通过传统均衡器独立校准后冻结。

## 2. 冻结的主配置

| 参数 | Level B 主值 | 含义 |
|---|---:|---|
| 最大相对时延 | 0.0116 s | 主实验覆盖 116 个符号的长记忆支撑 |
| 采样率/符号率 | 10 kHz / 10 kHz | 每符号 1 个复采样 |
| 帧长 | 1024 symbols | 单帧 0.1024 s，尾部跨越后续帧 |
| 强路径数 | 12--24 | 稀疏显著回波数量范围 |
| 弥散能量比例 | 0.20--0.35 | 强路径之外的长尾能量比例 |
| 相干时间 | 1200 s（主场景） | tap 增益慢漂移的时间尺度；120 s 只作压力测试 |
| 帧间相关系数 | 0.99991467 | 由 `exp(-0.1024 / 1200)` 得到 |
| acquisition 到数据间隔 | 0 s（主场景） | 主场景聚焦慢时变、跨帧 ISI 和残余同步扰动；30 s 只保留为老化压力测试 |
| 调制 | BPSK | 当前主实验不引入高阶调制 |
| SNR | 0/5/10/15 dB | 论文主矩阵固定层级 |
| Pilot | 前缀 128 symbols | Adapt 96，Reward 32 |
| residual CFO 限幅 | 0.0012 cycles/symbol | 只用于同步后残差和 Pilot 估计保护 |
| acquisition CFO 搜索限幅 | 0.004 cycles/symbol | 初始同步估计工作区 |

主配置使用 `cfo_phase_tiny`：tap 增益按慢状态递推，残留 CFO 和慢相位扰动同时存在。clean Level B 只作为 sanity check，不进入主平均；Level C 只作为压力测试。

## 3. 状态模型

每个连续帧包含三个相互区分的物理状态：

1. CIR tap 增益状态：保持稀疏支撑和长尾结构，按慢时间尺度缓慢漂移。
2. residual CFO：以 cycles/symbol 表示，在主实验限幅内缓慢变化。
3. 慢相位状态：包含公共初相位和低频相位扰动，不假设同步后完全消失。

接收机在 acquisition 阶段获得初始 CIR/CFO，之后每个数据帧只允许使用 Adapt Pilot 进行物理状态跟踪；Reward Pilot 只用于动作后的验收、回滚和留出评估；Data 标签只用于离线训练和仿真结束后的 BER 统计。

## 4. 参数冻结流程

参数冻结不读取 Proposed 神经网络结果，顺序固定为：

1. 根据公开延迟-功率包络筛选延迟支撑候选。
2. 检查 tap 支撑稳定性、跨帧误差和帧间相关性。
3. 检查离散模型 PDP 与公开包络的相对功率 RMSE。
4. 只用传统非神经、非 RL 均衡器检查候选是否落入各 SNR 的预设难度区间。
5. 冻结 `eme_long_memory_v2` 的 Level B 主配置，再进行离线神经网络训练和在线均衡比较。

## 5. 公开文献依据

当前代码和配置保留以下公开 DOI 作为延迟-功率包络及早期月面雷达回波研究依据：

1. Evans, J. V. 的月面雷达观测资料，DOI: [10.6028/jres.069D.195](https://doi.org/10.6028/jres.069D.195)。该资料用于延迟-功率包络和长延迟回波支撑的约束。
2. 早期月面雷达回波/通信相关公开会议文献，DOI: [10.1109/WESCON.1958.1150219](https://doi.org/10.1109/WESCON.1958.1150219)。该资料用于说明月面回波具有明显延迟扩展和散射回波结构。

文献只支撑“长延迟、散射、回波包络和结构方向”，不直接给出本仿真的 12--24 条离散强路径、0.20--0.35 弥散比例或 120 s 相干时间。因此论文中应明确区分“公开测量约束”和“为研究在线均衡构造的离散工作区参数”，避免把模型候选写成 EME 实测定量结论。

## 6. 方法学边界

当前主实验不加入信道编码、信源编码、非线性、高阶调制、多载波、MIMO、RIS 或 Data Oracle。这些因素会改变均衡问题的主要矛盾，不能用于掩盖 CIR 老化、跨帧 ISI 和同步残差造成的在线状态恢复困难。
