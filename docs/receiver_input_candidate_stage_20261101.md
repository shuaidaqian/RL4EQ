# 接收输入四组合组件实验：输入匹配尚未转化为可靠 BER 收益

本轮完成了可选整帧接收输入的候选组件、标签隔离测试和预先固定的训练范围实验。
输入失配确实存在，但仅改变输入范围，没有使现有 checkpoint 获得可靠的在线
BER 收益。正式控制器仍使用原默认输入，没有新增 RL 动作或改变网络结构。
整体目标未完成，不启动同配置更大留出矩阵。

## 固定协议与完整性

[运行前计划](receiver_input_candidate_plan_20261101.md)固定源 checkpoint 为
`pretrained/phase_transfer_post256_20261101/model_best.pt`，SHA256：
`305ea6f636cf5f0619649489a7d2e5ed5ce9138334e37e731bf24246a78fe010`。
沿用 Adapt BCE、AdamW、lr=5e-4、一步、增量上限 0.05；head/phase 分别更新。

offline_train seed=42000–42002，各 4 帧、四主 SNR，共 48 个上下文。
两个更新输入（Adapt-only / 整帧接收）分别交叉两个验收输入（Pilot-only /

每帧重置；历史 tail 沿用原规则。实验不含跨帧参数累计或 PPO。

核验了每个上下文恰有 8 组合、接收波形哈希和 Frozen 指标完全相同；同一候选
复用两种验收时，其候选 BER/BCE、增量范数、Adapt loss 和修复/引入错误一致。
Data 标签使用标志全部为 false。所有候选及验收结束后才进行 Data 仿真评分。
整帧输入可以使用 Data 位置的已接收波形，不能使用该位置的标签或未知发送符号。

原始结果位于被 Git 忽略的 `logs/receiver_input_candidates_3s4f_20261101.json`。

## 单次更新结果

下表的改善定义为 `100 × (Frozen BER − 验收后 BER)`，单位是百分点；正值较好。
每格为均值及 seed 级 95% 区间。两列 phase 使用同一基础模型与同一接收帧。

| SNR | 原严格输入 phase | 整帧更新及验收 phase | 整帧更新及验收 head |
|---:|---:|---:|---:|
| 0 dB | +0.31467 [−0.33894, +0.96828] | +0.30382 [−0.34477, +0.95241] | −0.02170 [−0.19003, +0.14663] |
| 5 dB | +0.02170 [−0.07167, +0.11507] | +0.01085 [−0.11267, +0.13437] | 0 [0, 0] |
| 10 dB | −0.01085 [−0.05754, +0.03584] | 0 [0, 0] | 0 [0, 0] |
| 15 dB | 0 [0, 0] | 0 [0, 0] | 0 [0, 0] |

四组合相对原严格组合的 BER 增量也均未出现正向区间。phase 在 0 dB 的
整帧组合接受 10/12 帧，其中 3 帧有害；合计修复 36 个、引入 8 个 Data 错误。
原严格组合接受 9/12 帧，其中 2 帧有害；修复 36 个、引入 7 个错误。
整帧验收在此多接受了一个有害候选，不能把接受率提高解释成进步。

10 dB 的整帧验收拒绝所有 phase 候选，避免了严格验收引入的一个错误；它没有
创造更好的候选。所有 head 组合在 5/10/15 dB 均没有修复或引入判决错误。
部分 BCE 指标有改善，也不能替代 BER 门槛。

## 验收信息量仍是独立瓶颈

每个 SNR 的 12 帧共 384 个 Reward bit，更新前统计如下：

| SNR | Pilot-only Reward 错误数 | 整帧 Reward 错误数 | 整帧 Reward 零错误帧 |
|---:|---:|---:|---:|
| 0 dB | 83 | 69 | 0/12 |
| 5 dB | 24 | 10 | 5/12 |
| 10 dB | 8 | 2 | 10/12 |
| 15 dB | 2 | 0 | 12/12 |

15 dB 的整帧 Reward 平均 BCE 为约 4.14e-13。该样本中它几乎不能通过
损失进一步下降提供可靠的动作排序信号。原验收还对损失改善扣除增量代价，
因此本轮 15 dB 所有候选均被拒绝。没有为获取接受率而放松阈值。

这批结果不能推出整帧输入没有价值：源 checkpoint 的历史可微内循环仍使用
严格输入，尚未完成与新输入匹配的离线训练；样本也只有 3 seed。
同样，它不能支持“只要匹配离线训练就一定有效”。当前候选本身的 BER 改善
没有可靠区间支持，不能把全部问题归因于验收。

## 工程验证与下一步

`context_logits` 新增明确的 `full_rx` 别名；可微候选与真实 AdamW 函数都新增
显式可选输入参数，默认仍为 `adapt_only`。未将该参数接入正式 runner 或主配置。
非 BCE 的整帧更新在修改模型前拒绝。

测试覆盖两种输入下的逐参数 AdamW 一致性、head/phase 外层有限差分、未知标签
和发送符号污染、基础权重不变、八组合端到端配对及错误协议拒绝。
定向测试 **32 passed，9.32 秒**；最终版本全量回归 **713 passed，266.34 秒**。
两批测试有重叠，不相加。全量回归使用 CPU、FFT 后端及单线程环境，真实组件
实验使用本机 CUDA；工程回归通过不代表研究收益门槛通过。

下一步先确定此前已提出的正式接收信息边界与调制结构选择：

1. 若允许整帧接收波形，先固定匹配输入的普通监督 / 更新后训练对照计划，
   同时明确 Reward 饱和时的可识别性检验；不直接扩展 PPO 预算。
2. 若坚持仅用 Pilot 接收样本，应实现并训练匹配缺失观测的物理算子与表示，
   不能继续把其余接收位置置零当作等价处理。
3. 若允许调整调制结构，应先核对 Pilot 可观测误差与调制输出族；结构变更仍需
   新训练范围机制筛查、同 checkpoint Frozen 和普通监督对照。

上述选择待回复，沉默不视为同意。后续只有稳定单次迁移成立，才进入累计适配、
离散安全 RL 窗口选择和校准传统 baseline 的独立主比较。
