# 跨帧 116 样本共同接收窗口协议

## 已确认的接收约束

用户已授权：当前帧完整接收后，所有神经与传统方法可再等待 `11.6 ms`，读取下一帧开头 `116` 个已接收复样本。当前配置采样率为 `10 kHz`、最大时延为 `116` 样本，因此接收后缀时间与最大信道记忆长度一致。各方法获得同一复数接收窗口；不增加 Pilot，不向在线 observation、梯度、reward、动作选择或参数更新暴露 Data 发送符号或标签。

当前长会话确认数据仍严格采用当前帧 `1024` 个接收样本，没有这段等待或后缀，不能并入新协议结果。

## 从信号模型推导的输入

对帧 `t`，新接收视图为 `y_t[0:1024]` 与紧随其后的 `y_{t+1}[0:116]` 拼接。后 116 个接收样本包含帧 `t` 尾部符号经长回波到达接收端的能量，也包含帧 `t+1` 的即时符号贡献。因此它们是合法接收观测，但不能被误当成单独的“尾部测量”或忽略下一帧干扰。

实现时必须明确当前要判决的符号范围仍是帧 `t`；把相邻帧接收样本作为额外观测行纳入估计。传统均衡器和神经均衡器都需要使用同样的扩展观测。若模型一次只支持 1024 点输入，则应增加经过单元测试的扩展观测算子，而不是把样本截断或填充到当前帧内部。

## 在线时序与信息隔离

1. 帧 `t` 收满后缓存其接收波形，等待帧 `t+1` 的前 116 个接收样本。
2. 拼成共同窗口后，各接收方法判决帧 `t`；Adapt Pilot 可提供已知训练符号，Reward Pilot 仍只用于该动作窗口之后的 reward 和留出评估。
3. Proposed 只对帧 `t` 的 Adapt Pilot 计算梯度；Data 接收波形可进入均衡器输入，但其发送符号与标签不可进入任何在线控制路径。
4. 传统 baseline 可使用相同接收窗口及允许的 acquisition/Adapt Pilot 和传统更新规则，不使用神经网络或 RL。
5. 帧 `t+1` 的接收前缀不能泄露该帧任何已知发送符号；除非它本身按既定协议属于 Pilot，否则接收机只看到波形。

## 验证门槛

- 构造直接卷积基准，验证扩展观测的前向算子、对信道 tap 的梯度/伴随关系及边界索引；覆盖最大 tap、稀疏 tap、复数输入和非零跨帧历史。
- 验证每个方法的接收输入 hash 完全一致，并验证后缀恰为下一帧前 116 个样本，没有额外样本或重排。
- 用替换/毒化下一帧 Pilot 发送标签和 Data 标签的测试，证明帧 `t` 的在线状态更新、梯度、reward 和动作不依赖这些标签；只允许可见接收波形及帧 `t` Adapt Pilot 影响控制。
- 保持实际逐帧连续信道、CFO/相位、噪声与 Pilot 规则；窗口构建不得重置环境或偷看未来超过 116 个样本。
- 先在小帧数和单独合成边界样例做单元/机制验证，再固定 checkpoint、种子、配对和统计规则进行独立复核。不要用 Data BER 调整跨帧协议或在线奖励。

跨帧窗口只解决观测边界问题，不保证 BER 改善。通过机制检查后仍需验证独立 Frozen、正式 RL、固定动作归因消融及传统 baseline，最终成功标准仍是 Level B 主配置四个 SNR 逐配置优于校准传统 baseline，并且在线收益相对同 checkpoint Frozen 有独立 seed 区间支持、后期更明显。
