# 错误定位：高 SNR 的 Data 帧尾与 Adapt 前边界存在明显差异

本轮冻结普通监督 full_rx A256，使用 offline_train 新 seed=45000–45004、
每条 8 帧、四主 SNR，共 160 个接收上下文。运行前条件见
[计划](error_geometry_plan_20261101.md)。源 SHA256 为
`2f7bb615409bdd5ec90ce549b83f3c6cff38a26caf3c89062c552b7b76cbfeb4`。

每帧划分六个互斥区域，共 960 条记录；覆盖与波形核验通过。接收机先输出，
随后才用标签评分；不优化参数、不产生候选、不注入仿真真实 CIR 或真实 tail。
这些是描述性错误定位，不能替代新方法的独立收益验证或确定物理误差的唯一成因。

## 错误位置

下表为区域 BER。每个 SNR 的 Adapt 前区/内部/Reward 分别含 4640/4320/1280 bit；
Data 首段/中段/尾段分别含 4640/21440/4640 bit，不直接比较不同长度区域的错误数。

| SNR | Adapt 前 116 | Adapt 内部 | Reward | Data 首 116 | Data 中段 | Data 尾 116 |
|---:|---:|---:|---:|---:|---:|---:|
| 0 dB | 21.0129% | 20.8102% | 19.7656% | 20.8621% | 22.0896% | 23.9871% |
| 5 dB | 5.1940% | 3.2639% | 3.8281% | 3.7716% | 4.1138% | 6.0776% |
| 10 dB | 1.4871% | 0.1389% | 0.3125% | 0.1724% | 0.3172% | 1.1207% |
| 15 dB | 0.7112% | 0% | 0% | 0% | 0.0140% | 0.4957% |

15 dB 的 Data 共有 26 个错误，其中 23 个位于最后 116 个符号，即 88.46%
的错误集中在 15.10% 的 Data 位置。Adapt 的 33 个错误全在前 116 个位置，
其内部和 Reward 均无错误。前者可能受未知历史项影响，后者的 CIR 列能量
因帧尾接收窗截断而降低；这些边界机制不同，不能直接把前缀误差梯度外推到帧尾。

## 分支贡献和置信度

15 dB Data 尾部错误的绝对 logit 均值为 7.3380，原神经残差绝对值均值为
0.2276；尾部 23 个错误中 12 个绝对 logit≥5，2 个≥20。中段 3 个错误的
相应均值为 5.3694 与 0.2214。原神经残差在该 SNR 没有修复或引入 Data 错误。

但四 SNR 的 Data 错误都没有落在物理分支的 ±40 截断点附近。15 dB 只有
Adapt 前区的 2 个错误满足该条件。因此“硬截断普遍阻塞错误梯度”不是本批
Data 错误的解释，不能仅移除截断便宣称解决问题。原神经分支幅度较小也是
一个作用范围线索，并非放大该分支必然有效的证据。
