# 新训练轨迹尚未确认收益，尺度目标存在可微作用

复数记忆的固定尺度在新训练轨迹上仍未建立可靠在线收益。本轮不进入正式 RL，也不增加同一矩阵的 seed；下一步用固定预算检验离线学习尺度这一新假设。

## 新训练轨迹复核

按[首轮记录](channel_memory_capacity_stage_20261102.md)中已冻结的协议，offline_train 97000–97002，四 SNR，评分年龄127/1023/4095，每个上下文独立从零记忆生成候选。只在开始 acquisition 一次；历史仅推进物理轨迹，未持续学习。共36上下文、144候选，small/medium、signal/MAP 均完整报告，不据事后 Data 选动作。

下面为 medium 经 guard 后 Data BER 的改善，单位百分点，区间以独立 seed 为单位、先对各 seed 的三个年龄求均值：

|---|---:|---:|---:|
|0|−.39062 [−2.26120, 1.47995]|+.14468 [−.87438, 1.16374]|4|
|5|−.14468 [−.76717, .47781]|+.02894 [−.03331, .09118]|5|

所有16项平均改善区间和48项逐年龄改善区间均包含零。medium MAP 的四个正均值不是成功门槛，退化 signal 候选被拒后出现的零也不是无风险证明。完整 small/medium、候选与验收后指标见[机器摘要](results/channel_memory_fresh_stage_20261102.json)。研究墙钟 **436.44秒**，包含长轨迹模拟，不是生产端到端时延。

## 只读离线尺度导数

为区分“尺度完全没有学习通路”与“有通路但效果待证”，复用原长年龄训练缓存的20个样本，额外读取当前与未来+8的离线标签，只对34个尺度参数求导，不应用导数、不生成或选择任何在线动作、不改写模型或 `.grad`。

- 40个目标/上下文的普通未更新监督梯度范数均严格为零，符合零记忆保持 Frozen 的结构。
- 更新后平均当前/未来 Data BCE 对尺度有非零有限导数，两个目标均可微；它证明存在训练通路，不证明泛化或 BER 必然改善。
- signal 的当前/未来梯度余弦在大部分样本为正，MAP 有多处为负；只优化当前也未必改善未来。
- MAP 的不同年龄/seed 导数也存在冲突，不能把跨样本平均方向当在线真值。

本轮 CUDA只读研究耗时 **29.47秒**。[导数机器摘要](results/channel_memory_meta_gradient_stage_20261102.json)保存40项范数、余弦与34维导数。Data 导数严格属于离线解释，不进入 observation、reward 或候选更新。

增加只读导数诊断后，定向文件 **103 passed，19.52秒**，包含二阶有限差分和不改写在线状态测试；前一实现的全量回归为793项，本阶段新增测试单独及定向覆盖，不将它们相加声称新全量总数。

## 决定与限制

下一步是[固定64步尺度学习实验](channel_memory_scale_training_plan_20261102.md)。不把当前固定尺度候选未通过的结果藏起来，也不把离线可微等同于在线成功。A是固定尺度控制，B只允许通过离线更新后目标学习尺度；两者未更新 Frozen 必须精确相同。这个设计直接排除“靠改变 Frozen 制造适配差值”，并把是否学得有用交给新的配对机制实验判断。

正式窗口 RL、校准传统主比较、从首帧开始的128帧和数百秒持续跟踪，以及四SNR逐配置最终验收仍未完成。
