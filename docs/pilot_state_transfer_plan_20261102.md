# Pilot 信道状态信息的合法候选筛查

用户已明确先验证统计收益并报告耗时，机制成立后再优化实时性；本轮不增加实时门槛。
匹配短窗训练、128 帧保留参数及 1/4/8 帧梯度聚合均未确认稳定迁移，不能继续
默认当前输出 head 的梯度是可迁移的状态估计。先检验另一种信息表示是否值得设计神经分支。

固定 `symbol_transfer_baseline256_20261101/model_best.pt`（SHA256
`605281acef3e9efe61e8d8354f6feb61b3324737eabff0a5ba3f75f43a6b7ecc`），
offline_train 75000–75002，各 16 帧，0/5/10/15 dB、Level B、prefix。
第 0–6 帧积累历史，第 7–15 帧比较 1/8 帧方程，共 108 当前上下文、216 候选。
不更改 checkpoint，不使用真 CIR，不训练神经参数，不注册主方法或主传统 baseline。

1. 只取 Adapt 接收位置 116–223，对应的 117 个卷积输入全部是当前已知 Adapt。
   不使用 soft tail 补未知历史，不使用 Reward 或 Data 构造拟合方程。
2. 使用原神经均衡器的合法相位条件校正 Adapt 波形，得到共同相位规范下的前向方程。
3. acquisition CIR 为先验均值。先验方差固定为 acquisition 噪声行数估计，加配置
   rho_frame 对应的对角过程增量；不看 Data 或真 CIR 选择正则，不归一化真功率。
4. 单次后验解构造候选 CIR，仅替换当前神经均衡器条件里的 CIR，保持相位条件固定。
   不累计候选状态，避免与历史长度效应混淆。
5. 用当前完整接收帧的 Reward Pilot 比较更新前后 loss/BER，沿用原安全 guard。
   所有候选和验收固定后，才用 Data 标签事后评分。

该路径是物理状态可见信息的诊断，**不是神经 PEFT 或 RL 成功**。即使有收益，仍须
设计可学习神经状态残差、离线训练其受限参数和在线微调，再通过 Frozen、普通监督、
独立 seed、后期优势及正式 RL/传统比较。若无收益，也不能把结果推成不可辨认性定理，
因为相位估计误差、对角先验和条件分布偏移都可能限制该候选。

按 seed 统计候选与验收后 BER 改善、BCE 改善，记录方程行数、偏移范数和运行耗时。
不据部分结果改窗口、先验或 guard。
